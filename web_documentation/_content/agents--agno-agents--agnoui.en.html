Get Started with Agent UI

To clone the Agent UI, run the following command in your terminal:


npx create-agent-ui@latest

Enter y to create a new project, install dependencies, then run the agent-ui using:


C:\Users\schit>cd agent-ui


C:\Users\schit\agent-ui>npm run dev

Open http://localhost:3000 to view the Agent UI, but remember to connect to your local agents.

Local: http://localhost:3000
Network: http://10.5.0.2:3000

Minimal setup


import os
from dotenv import load_dotenv

#os.environ["AGNO_TELEMETRY"] = "false"
#AGNO_TELEMETRY = os.getenv("AGNO_TELEMETRY")

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.os import AgentOS

load_dotenv()

assistant = Agent(
    name="Assistant",
    model=OpenAIChat(id="gpt-4.1-mini"),
    instructions=["You are a helpful AI assistant."],
    markdown=True,
)

agent_os = AgentOS(
    id="my-first-os",
    description="My first AgentOS",
    agents=[assistant],
)

app = agent_os.get_app()

if __name__ == "__main__":
    # Default port is 7777, change with port=...
    agent_os.serve(app="minimal_setup:app", reload=True)
