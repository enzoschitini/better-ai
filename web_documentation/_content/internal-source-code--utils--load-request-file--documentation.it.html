Panoramica

La classe LoadRequestFile è stata sviluppata per facilitare il processo di caricamento e validazione dei file inviati nelle richieste tramite FastAPI. Garantisce che il file ricevuto abbia un'estensione e un tipo MIME consentiti, oltre a verificare che la sua dimensione rientri in un limite configurato, evitando problemi come upload indebiti o file troppo grandi che possano compromettere il sistema.

In pratica, questa classe può essere utilizzata per controllare in modo sicuro quali file un'applicazione accetta per l'elaborazione, proteggendo il backend da input inattesi o malevoli. Ad esempio, può essere usata in API in cui gli utenti caricano immagini, documenti o altri file, assicurando la compliance con le regole definite.

Flusso di Esecuzione

  1. Viene creata un'istanza della classe passando l'oggetto UploadFile della richiesta e, opzionalmente, elenchi di estensioni e tipi MIME consentiti, oltre alla dimensione massima consentita.
  2. Il metodo load() viene chiamato in modo asincrono per leggere il contenuto del file della richiesta.
  3. Durante il caricamento, la classe calcola la dimensione del file in byte e megabyte e mantiene una copia del contenuto in un oggetto BytesIO, facilitando l'accesso futuro.
  4. In seguito, il file viene validato rispetto agli elenchi di estensioni e tipi MIME consentiti, oltre a verificare che la sua dimensione non superi il limite configurato.
  5. Se una validazione fallisce, viene sollevata un'eccezione HTTP 400 con un messaggio chiaro sul motivo.
  6. Se tutte le validazioni passano, viene restituita l'istanza con le informazioni e il contenuto del file, pronta per l'uso successivo nel flusso dell'applicazione.

Punti Importanti dell'Architettura e Spunti

  • La classe incapsula completamente la logica di caricamento e validazione, promuovendo il riutilizzo e una chiara separazione delle responsabilità.
  • L'uso del modulo BytesIO permette di lavorare con il contenuto del file in memoria senza doverlo salvare su disco, aumentando l'efficienza.
  • Il design usa validazioni specifiche e solleva direttamente eccezioni HTTP, integrandosi facilmente nel flusso di gestione degli errori di FastAPI.
  • Dipende da configurazioni esterne per le estensioni e i MIME type consentiti, dando flessibilità per gli aggiustamenti senza modificare il codice sorgente.
  • L'architettura modulare permette una semplice estensione, ad esempio aggiungendo altre validazioni senza modificare l'interfaccia pubblica.

Descrizione della Classe e dei Metodi

Classe LoadRequestFile

Descrizione

LoadRequestFile rappresenta un'utilità per gestire i file inviati tramite richiesta HTTP con FastAPI. È responsabile di caricare il file ricevuto, estrarre informazioni come estensione, MIME type e dimensione, oltre a validare che il file rientri negli standard consentiti configurati per il sistema.

Argomenti del Costruttore

ArgomentoTipoDescrizioneValore Predefinito
fileUploadFileFile inviato nella richiesta da caricare e validare.Nessuno (obbligatorio)
allowed_extensionslist[str]Elenco delle estensioni consentite per la validazione.ALLOWED_EXTENSIONS
allowed_mimetypeslist[str]Elenco dei tipi MIME consentiti per la validazione.ALL_MIMETYPES
max_size_mbfloatDimensione massima consentita per il file in megabyte.10

Metodi

1. __init__

Descrizione

Inizializza un'istanza della classe con il file ricevuto e le configurazioni di validazione, preparando gli attributi per il caricamento e le validazioni successive.

Argomenti

  • file (UploadFile): File inviato nella richiesta.
  • allowed_extensions (list[str]): Estensioni consentite. Default: ALLOWED_EXTENSIONS.
  • allowed_mimetypes (list[str]): MIME type consentiti. Default: ALL_MIMETYPES.
  • max_size_mb (float): Dimensione massima consentita (in MB). Default: 10.

Valori di ritorno

  • Non restituisce alcun valore.

Raises

  • Nessuna.

Esempi


# Criar uma instância para validar arquivo recebido e configurar limites
loader = LoadRequestFile(file, max_size_mb=5)

2. load

Descrizione

Metodo asincrono che carica l'intero contenuto del file, ne calcola la dimensione in byte e megabyte, memorizza i dati in memoria ed esegue tutte le validazioni stabilite (estensione, MIME type e dimensione).

Argomenti

  • Nessuno.

Valori di ritorno

  • LoadRequestFile: restituisce la stessa istanza con i dati caricati e validati.

Raises

  • HTTPException: se una validazione fallisce, con status 400 e un messaggio informativo.

Esempi


# Uso assíncrono: carregar e validar arquivo recebido na requisição
loader = await LoadRequestFile(file).load()
print(loader.to_dict())
# Exemplo de saída:
# {
#   "filename": "photo.jpg",
#   "extension": "jpg",
#   "mimetype": "image/jpeg",
#   "size_bytes": 152000,
#   "size_mb": 0.15
# }

3. to_dict

Descrizione

Genera un dizionario con i principali metadati del file caricato, facilitando l'ispezione e l'eventuale registrazione o risposta all'API.

Argomenti

  • Nessuno.

Valori di ritorno

  • dict: contenente filename, extension, mimetype, size_bytes e size_mb arrotondato.

Raises

  • Nessuna.

Esempi


# Obter informações resumidas sobre o arquivo carregado
info = loader.to_dict()
print(info["filename"])  # ex: "document.pdf"
print(info["size_mb"])   # ex: 2.45
