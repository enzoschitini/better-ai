Panoramica

Il file definisce due classi. RequestProcessor valida ciò che arriva dalla richiesta (configurazione in JSON e immagini inviate). ImageGenerate esegue il flusso di generazione di immagini usando ImageGeneratorService e PayloadBuilder, e salva il risultato.

L'endpoint di generazione in src/web_services_network/routes/davinci.py usa entrambe le classi.

RequestProcessor

Riceve la configurazione come testo JSON (config) e la lista di file (files), entrambi opzionali. Il metodo asincrono process() restituisce un dizionario con le chiavi config (dizionario) e image_bytes (lista di byte).

PassoRegolaErrore
_process_configConverte il testo di config con json.loads. Senza config, non viene fatto nulla.HTTPException con status 400 quando il JSON non è valido.
_process_filesAccetta solo image/jpeg e image/png, con limite di 10 MB (max_mb=10), tramite FilesPayloadBuilder.RuntimeError con il messaggio "Erro ao carregar as imagens".

ImageGenerate

Il costruttore riceve user_input (obbligatorio), instructions, config e image_bytes. I metodi sono:

MetodoDescrizione
generateCrea un ImageGeneratorService, costruisce le parti e la configurazione, chiama il modello ed esegue il parsing delle risposte.
build_payloadsUsa PayloadBuilder con un jobId generato da IDGenerator.timestamp(prefix="job_") e restituisce mongo_payload, storage_payload e response_payload.
save_to_mongoDBSalva il mongo_payload in DATABASE_NAME / COLLECTION_NAME con DocumentStore.
save_to_supabaseInvia ogni immagine dello storage_payload al bucket con StorageRepository.upload_to_supabase, usando l'id dell'immagine come nome del file.
save_results_localSalva le immagini generate nella cartella locale img_test, per i test. Non fa parte del runner.
runnerEsegue il flusso completo e restituisce il response_payload.

Flusso del runner

  1. generate: genera le immagini e aggrega le risposte.
  2. build_payloads: separa il risultato in tre payload.
  3. save_to_mongoDB: salva il record (senza i byte delle immagini).
  4. save_to_supabase: salva i file immagine.
  5. Restituisce il response_payload, con text_response e la lista di URL in images.

Esempio d'uso


from src.image_generation.module import ImageGenerate

# Crea il generatore con il prompt e la configurazione opzionale
generator = ImageGenerate(
    user_input="Uma borboleta no estilo de Da Vinci",
    instructions=None,
    config={"aspect_ratio": "16:9", "number_of_images": 2},
    image_bytes=None,
)

# Esegue il flusso completo e riceve gli URL
response = generator.runner()
print(response["images"])

Osservazioni

Errori generici. build_payloads, save_to_mongoDB e save_to_supabase catturano qualsiasi eccezione e sollevano un RuntimeError con messaggio fisso, senza concatenare la causa originale.

I moduli di supporto sono documentati in Image Generator Service, Payload Builder e Config.
