1. Panoramica

La classe FilesPayloadBuilder agisce come un filtro di sicurezza e trasformatore di dati nel livello di ingresso della tua API. Quando un utente invia file tramite FastAPI, questi arrivano come oggetti UploadFile.

Questa classe garantisce che i file non "rompano" il server perché troppo grandi o perché hanno formati malevoli o non supportati. Dopo la validazione, trasforma i dati grezzi in un dizionario Python (payload) facile da manipolare da altre parti del sistema, come servizi di elaborazione delle immagini o database.

2. Flusso di Esecuzione

Il flusso di elaborazione di un file segue questo percorso logico:

  1. Ricezione: L'API riceve un elenco di file tramite modulo (Multipart).
  2. Lettura Asincrona: Il contenuto del file viene letto dalla memoria o dal disco temporaneo in modo non bloccante (await f.read()).
  3. Verifica del Tipo: Il sistema controlla che il content_type (es: image/png) sia nell'elenco dei tipi consentiti.
  4. Verifica del Peso: La dimensione totale dei byte letti viene confrontata con il limite configurato (es: 10MB).
  5. Strutturazione: Se tutto è corretto, i dati vengono organizzati in un dizionario. Se qualcosa fallisce, viene sollevata immediatamente un'eccezione HTTP, interrompendo il processo per proteggere il server.

4. Architettura e Spunti

  • Sicurezza Reattiva: Validando dimensione e tipo MIME subito all'ingresso, eviti attacchi di "Denial of Service" (DoS) tramite upload di file giganti.
  • Uso di Set per le Prestazioni: La variabile allowed_types viene convertita in un set. In Python, verificare se un elemento esiste in un set è molto più veloce che in una list o tuple, soprattutto se l'elenco dei formati cresce.
  • Integrazione con FastAPI: L'uso di HTTPException permette di restituire gli errori di validazione direttamente all'utente finale con i codici di stato appropriati (400 Bad Request), senza bisogno di blocchi try/except aggiuntivi nella rotta dell'API.

5. Dettaglio della Classe

Classe FilesPayloadBuilder

Descrizione
Responsabile di validare l'integrità dei file inviati tramite upload e di prepararli per l'elaborazione interna. Centralizza le regole su "cosa può entrare" nel sistema in termini di file multimediali.

Argomenti

  • max_mb (int): La dimensione massima consentita per ogni singolo file in Megabyte.
  • allowed_types (Iterable[str]): Una collezione di stringhe che rappresentano i tipi MIME accettati (es: ["image/jpeg", "application/pdf"]).

Metodi

1. build_images_payload

Descrizione
Questo è il cuore della classe. Scorre ogni file inviato, ne legge il contenuto binario e verifica che soddisfi i requisiti di sicurezza definiti nel costruttore.

Argomenti

  • files (List[UploadFile]): Un elenco di oggetti file provenienti da un endpoint FastAPI.

Valori di ritorno

  • list[dict]: Un elenco di dizionari, dove ogni dizionario contiene:
    • filename: Nome originale del file.
    • content_type: Formato del file.
    • size_bytes: Dimensione reale in byte.
    • bytes: Il contenuto binario grezzo.

Raises

  • HTTPException (400): Sollevata se il formato del file non è consentito.
  • HTTPException (400): Sollevata se il file supera il limite di Megabyte configurato.

Esempi


builder = FilesPayloadBuilder(max_mb=2, allowed_types=["image/png"])

# Em uma rota FastAPI
@app.post("/upload")
async def upload_image(files: List[UploadFile]):
    payload = await builder.build_images_payload(files)
    return {"status": "sucesso", "arquivos_processados": len(payload)}
