Overview

The PineconeRetriever class is a service specialized in retrieval operations on vectors stored in a Pinecone index. It serves as an abstraction layer to make vector similarity searches and metadata-based queries easier, encapsulating the direct interaction with the index and the embeddings mechanism.

This component is crucial for applications that work with vector data, such as recommendation systems, semantic retrieval or text similarity analysis, because it guarantees a simple and safe API to perform complex queries on Pinecone. It can be used in natural language processing pipelines, search systems or any application that needs to retrieve nearby vectors from text queries or metadata filters.

Execution Flow

  1. Initialization: Creates a PineconeRetriever instance, optionally receiving a configured Pinecone client. If none is provided, a default client is created internally; during this phase, essential components such as index, embeddings and namespace are initialized.
  2. Similarity Search (similarity_search):
    • Receives a query text, a maximum number of results (k) and optional filters.
    • Validates the parameters and generates the text embedding.
    • Builds Pinecone-compatible filters for the query.
    • Runs the vector query on the index, retrieving similar vectors.
    • Normalizes and formats the response, returning a list of documents with text, metadata and scores.
  3. Retrieval by Metadata (get_all_docs_by_metadata):
    • Accepts a key and value (or list of values) for metadata filtering, plus pagination parameters.
    • Uses a "dummy" vector to satisfy the Pinecone API, which requires a vector, performing the search using only the filter.
    • Runs paginated queries to retrieve all the vectors that satisfy the filter.
    • Returns a complete list of the vectors with metadata and ids, but the score has no semantic meaning here.

Important Architecture Points and Insights

  • Separation of Responsibilities: The class acts exclusively as a query service, decoupling the embedding logic and communication with Pinecone via a specialized client.
  • Use of a Decorator for Tracing: The @trace decorator is applied to public methods to standardize logging and exception capture, ensuring traceability and easy debugging.
  • Normalization and Abstraction: Pinecone's raw results are transformed into a uniform format consumed by the application, hiding the index's complexities.
  • Explicit Pagination: Retrieval by metadata implements manual pagination to ensure that all results are obtained, working around Pinecone API limitations.
  • Dynamic and Flexible Filter: Support for simple filters from a dictionary, translated to Pinecone's $eq and $in operators, making parameterized searches easier.
  • Dependencies Used: The class uses PineconeClient (for access to the index and embeddings) and PineconeVectorStoreConfig (for batch and dimension settings).

Class and Methods Description

PineconeRetriever Class

Description

PineconeRetriever is responsible for performing efficient and safe queries on vector indexes managed by Pinecone. It provides mechanisms both for text similarity searches, turning text into vectors and querying the index, and for metadata-based retrievals, with automatic pagination and compatible filtering.

Constructor Arguments

ArgumentTypeDescriptionDefault Value
clientOptional[PineconeClient]Pinecone client instance already configured with index, embeddings and namespace; if omitted, creates a default client automatically.None

Methods

1. __init__

Description

Initializes a PineconeRetriever instance, setting up the essential dependencies such as index, embeddings and namespace, using the PineconeClient provided or creating a default one. It also loads settings such as batch size (batch_size) and vector dimension.

Arguments

  • client (Optional[PineconeClient]): Configured client object; can be None.

Returns

  • Does not return a value.

Raises

  • ValueError: if the client is None and the default cannot be created.

Examples


# Criando retriever com cliente padrão
retriever = PineconeRetriever()

# Criando retriever com cliente customizado
client = PineconeClient()
retriever = PineconeRetriever(client)

2. similarity_search

Description

Runs a vector similarity search from a query text, returning the most similar documents in the Pinecone index, with the option of applying metadata filters to restrict the results.

Arguments

  • query (str): Base text for the similarity search.
  • k (int): Maximum number of results returned. Default: 5.
  • filter_search (Optional[Dict[str, Any]]): Dictionary for metadata filtering, e.g.: {"file_id": "abc"} or {"file_id": ["abc", "def"]}.

Returns

  • List[Dict[str, Any]]: List of dictionaries containing id, text ('text' field of the metadata), other metadata and score.

Raises

  • ValueError: If query is empty or k <= 0.
  • RuntimeError: Failure in generating the embedding, in the query or in processing the results.

Examples


results = retriever.similarity_search(
    query="Como funciona o sistema de recomendação?",
    k=3,
    filter_search={"category": "tutorial"}
)

for doc in results:
    print(f"ID: {doc['id']}, Score: {doc['score']}")
    print(f"Texto: {doc['text']}")

3. get_all_docs_by_metadata

Description

Retrieves all the vectors from the Pinecone index that match a metadata filter, performing paginated queries. This function does not do similarity search, uses a "dummy" vector as required by the API and returns the raw filtered results.

Arguments

  • batch_size (int | None): Limit of results per page. Controls memory and latency. Uses the configured value if None.
  • dimension (int | None): Vector dimension (needed to create the dummy vector). Uses the configured value if None.
  • target_key (str): Metadata key to filter on (e.g. "file_id"). Default: "file_id".
  • target_value (Union[str, List[str]]): Value or list of values for the filter.

Returns

  • List[Dict[str, Any]]: List containing id, metadata and score of the vectors that satisfy the filter.

Raises

  • ValueError: If target_value is empty.
  • RuntimeError: Failure in the paginated retrieval.

Examples


all_vectors = retriever.get_all_docs_by_metadata(
    batch_size=100,
    target_key="user_id",
    target_value=["user1", "user2"]
)

print(f"Total vetores recuperados: {len(all_vectors)}")
for vector in all_vectors:
    print(vector["id"], vector["metadata"])
