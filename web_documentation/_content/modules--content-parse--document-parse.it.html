Panoramica

La classe DocumentParse ha come obiettivo orchestrare l'intera pipeline di elaborazione dei documenti, dall'estrazione del contenuto grezzo del file fino al salvataggio dei dati elaborati in un database NoSQL. È responsabile di far convergere diverse fasi fondamentali per trasformare i file digitali in dati strutturati pronti all'uso, automatizzando il flusso di parsing con validazioni, calcoli dei costi e integrazione con i sistemi di archiviazione.

Questo componente è fondamentale nei sistemi che devono interpretare documenti elettronici (come PDF, TXT, ecc.) ed estrarre informazioni specifiche secondo uno schema predefinito. In pratica, può essere utilizzato in pipeline di machine learning, API di conversione di documenti e applicazioni che dipendono dall'estrazione automatizzata di dati.

Con questa classe, lo sviluppatore può inviare un job contenente un file e le sue configurazioni, e ricevere in cambio i dati strutturati del documento con i costi computazionali calcolati, oltre ad avere il risultato archiviato per consultazioni future.

Flusso di Esecuzione

  1. Creazione dell'istanza della classe: Inizializzazione con job_id, metadata JSON, schema JSON, contenuto del file (in byte), estensione del file e configurazioni opzionali per il parsing.
  2. Chiamata del metodo run(): Questo metodo esegue l'intero flusso interno, ed è responsabile del coordinamento delle fasi.
  3. Caricamento e validazione dei dati: Il metodo privato _load_schema_and_config() deserializza i JSON di metadata e schema, oltre a unire le configurazioni predefinite e quelle personalizzate.
  4. Estrazione del contenuto del file: _extract_file_content() utilizza FileContentExtractor per ottenere il testo grezzo del file in base alla sua estensione.
  5. Parsing del contenuto estratto: _parse_content() invoca ContentParsingAgent, che mappa il testo estratto nella struttura definita dallo schema.
  6. Calcolo dei costi: _calculate_costs() determina il costo di elaborazione in base al modello di linguaggio usato e ai token consumati, convertendo i valori nella valuta locale.
  7. Costruzione della risposta: _build_response() crea il payload che verrà inviato dall'API e il payload che verrà salvato nel database.
  8. Persistenza dei risultati: _save() salva i dati elaborati nel database NoSQL configurato.
  9. Valore di ritorno: run() restituisce la risposta pronta per l'API contenente il contenuto estratto e strutturato.

Variabili d'Ambiente

Nessuna variabile d'ambiente esplicita è richiesta direttamente in questa classe. La configurazione predefinita e le informazioni del database sono ottenute tramite DocumentParseConfig, che può avere una propria gestione delle ENV (non mostrata qui).

Punti Importanti dell'Architettura e Insights

  • Incapsulamento e netta separazione delle responsabilità: La classe organizza ogni fase del flusso in metodi privati, facilitando manutenzione e test.
  • Uso della composizione: La classe utilizza altre classi per responsabilità specifiche, come FileContentExtractor per l'estrazione, ContentParsingAgent per il parsing e DocumentStore per la persistenza, seguendo il principio di responsabilità unica.
  • Gestione robusta degli errori: Usa eccezioni HTTP per validare i JSON forniti, garantendo che il flusso prosegua solo con dati validi.
  • Calcolo dinamico dei costi: Si integra con servizi esterni per il calcolo del costo basato sui token elaborati e sulla conversione di cambio attuale, adatto a sistemi a pagamento in base all'uso.
  • Flessibilità nella configurazione: Consente una configurazione personalizzata tramite JSON che viene unita alla configurazione predefinita per adattare il comportamento del parsing.

Descrizione della Classe e dei Metodi

Classe DocumentParse

Descrizione

Classe che gestisce l'elaborazione completa dei documenti per l'estrazione di contenuto strutturato. Riceve il contenuto del file, i metadati, lo schema e le configurazioni. Esegue l'estrazione del testo, il parsing secondo lo schema, il calcolo dei costi operativi e l'archiviazione del risultato elaborato. Fornisce una risposta pronta per l'uso da parte delle API.

Argomenti del Costruttore

ArgomentoTipoDescrizioneValore Predefinito
job_idstrIdentificatore univoco del job di elaborazione-
metadatadict/str JSONMetadati associati al documento (è attesa una stringa JSON)-
schemastrStringa JSON che definisce lo schema dei dati attesi-
file_bytesBytesIOContenuto binario del file da elaborare-
file_extensionstrEstensione del file (esempio: '.pdf', '.txt')-
configOptional[str]Stringa JSON contenente la configurazione personalizzata per il parsingNone

1. __init__

Descrizione

Inizializza l'oggetto DocumentParse con le informazioni essenziali per l'elaborazione del documento, configurando i parametri e caricando le configurazioni predefinite del sistema.

Argomenti

  • job_id (str): Identificatore del job di elaborazione.
  • metadata (dict/str): Metadati in formato stringa JSON.
  • schema (str): Schema JSON per la strutturazione dei dati.
  • file_bytes (BytesIO): Byte del file.
  • file_extension (str): Estensione del file.
  • config (Optional[str]): Configurazione personalizzata come stringa JSON (opzionale).

Valori di ritorno

  • Non restituisce alcun valore.

Raises

  • Nessuna.

Esempi


document_parse = DocumentParse(
    job_id="job123",
    metadata='{"author": "John Doe"}',
    schema='{"type": "object", "properties": {"title": {"type": "string"}}}',
    file_bytes=BytesIO(b"conteudo do arquivo"),
    file_extension=".txt",
    config=None
)

2. run

Descrizione

Esegue la pipeline completa di elaborazione del documento, dalla validazione dei dati all'estrazione, al parsing, ai calcoli e all'archiviazione, restituendo il risultato finale pronto per l'API.

Argomenti

  • Nessuno.

Valori di ritorno

  • dict: Risposta formattata per l'API contenente il job_id e il contenuto elaborato.

Raises

  • HTTPException: in caso di JSON non validi nei dati forniti.

Esempi


response = document_parse.run()
print(response)
# Exemplo de saída:
# {
#   "job_id": "job123",
#   "content": {...dados extraídos e formatados...}
# }

Uso


if __name__ == "__main__":
    # Exemplo de uso
    job_id = "job_123"
    metadata = """{"user_id": "user_456"}"""

    schema = """
    {
    "summary": {
        "type": "str",
        "description": "Resumo do conteúdo do arquivo"
    }
    }
    """
    config = """
    {
    "model_provider": "OpenAI",
    "model_id": "gpt-4.1-mini",
    "max_input_tokens": 1000000,
    "debug_mode": true,
    "instructions": "Extraia dados do texto",
    "description": "Leia o texto e extraia as informações relevantes conforme o esquema definido. Retorne um JSON estruturado com os dados extraídos. Caso não encontre alguma informação, retorne null para aquele campo."
    }
    """

    with open("src\\content_parse\\module\\example.pdf", "rb") as f:
        file_bytes = BytesIO(f.read())

    parser = DocumentParse(
        job_id=job_id,
        metadata=metadata,
        schema=schema,
        config=config,
        file_bytes=file_bytes,
        file_extension="pdf"
    )

    response = parser.run()

    print("\nResposta do parser:")
    print(json.dumps(response, indent=2))
