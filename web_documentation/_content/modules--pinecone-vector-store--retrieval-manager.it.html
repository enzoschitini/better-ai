Panoramica

La classe RetrievalManager è uno strumento di gestione dei documenti recuperati, pensato per scenari di ricerca e analisi di dati testuali. Facilita il filtraggio dei documenti basato sugli score (punteggi), la generazione di contesti testuali compatti da usare nei modelli di linguaggio e l'estrazione organizzata dei metadati dei file.

Nelle applicazioni pratiche, questa classe può essere usata per controllare grandi volumi di documenti restituiti dai sistemi di recupero delle informazioni, garantendo che vengano considerati solo i più rilevanti (con score sopra una certa soglia o sopra la media). Inoltre, con la generazione di contesti formattati, diventa più efficiente la federazione di questi contenuti verso gli LLM o altre analisi testuali.

Flusso di Esecuzione

  1. Inizializzazione: Quando crei un'istanza di RetrievalManager, fornisci un elenco di documenti, opzionalmente uno score minimo e se desideri che il filtraggio per score venga eseguito automaticamente. Se il filtraggio automatico è attivato, l'elenco interno dei documenti sarà già pre-filtrato.
  2. Filtraggio per Score: È possibile filtrare i documenti per mantenere solo quelli il cui score sia maggiore o uguale allo score minimo desiderato, usando get_by_score.
  3. Filtraggio per Media: Per un'ulteriore raffinazione, filter_by_mean_score permette di filtrare un insieme di chunk, mantenendo solo quelli con score maggiore o uguale alla media dell'insieme.
  4. Generazione di Contesto Compatto: generate_context trasforma i documenti in una stringa formattata riga per riga, mostrando score e testo in forma compatta per facilitarne l'uso.
  5. Estrazione dei Metadati dei File: Tramite il metodo get_files, i file associati ai documenti vengono identificati e organizzati per facilitare l'accesso a identificazione, nome, estensione e score massimo ottenuto.

Punti Importanti dell'Architettura e Spunti

  • Immutabilità parziale: La classe modifica il proprio elenco interno di documenti solo se il filtraggio automatico è attivato, preservando l'input iniziale quando desiderato.
  • Gestione robusta delle eccezioni: Tutti i metodi che eseguono elaborazioni critiche catturano le eccezioni e sollevano RuntimeError con messaggi chiari per facilitare il debug.
  • Struttura flessibile dei documenti: La classe presuppone che i documenti abbiano un formato standard con campi obbligatori come 'text' e 'score', e campi opzionali 'metadata' con informazioni sui file — il che permette l'adattamento a diverse fonti di dati.
  • Nessuna dipendenza esterna: Non usa altre classi ausiliarie, il che rende l'uso isolato e semplice, manipolando soltanto liste e dizionari.
  • Filtri distinti: Con metodi distinti per il filtraggio a soglia fissa e per il filtraggio per media, la gestione diventa più flessibile per diversi criteri di rilevanza.

Descrizione della Classe e dei Metodi

Classe RetrievalManager

Descrizione

Gestisce una collezione di documenti testuali con punteggi associati (score), permettendo molteplici operazioni importanti:

  • Filtrare i documenti in base agli score (fissi o relativi alla media del gruppo).
  • Creare una rappresentazione testuale compatta per l'integrazione con i modelli di linguaggio.
  • Estrarre metadati raffinati per l'associazione dei documenti ai file.

Serve per i casi che comportano recupero e manipolazione avanzata di testi organizzati per rilevanza.

Argomenti del Costruttore

ArgomentoTipoDescrizioneValore Predefinito
docsList[Dict[str, Any]]Elenco di documenti con i campi 'text', 'score' e opzionale 'metadata'-
score_minfloatValore minimo di score per il filtro iniziale dei documenti0.0
filter_by_scoreboolDefinisce se i documenti verranno filtrati per score all'inizializzazioneFalse

Metodi

1. __init__

Descrizione

Costruisce l'oggetto RetrievalManager con un elenco di documenti e configurazioni opzionali per il filtraggio iniziale per score minimo.

Argomenti

  • docs (List[Dict[str, Any]]): documenti da gestire
  • score_min (float): score minimo per il filtro iniziale
  • filter_by_score (bool): esegue il filtro automatico se True

Valori di ritorno

  • Non restituisce alcun valore.

Raises

  • Non applicabile.

Esempi


rm = RetrievalManager(docs=documents, score_min=0.3, filter_by_score=True)

2. get_by_score

Descrizione

Filtra l'elenco dei documenti per mantenere solo quelli il cui score sia maggiore o uguale allo score minimo dato.

Argomenti

  • docs (List[Dict[str, Any]]): Elenco opzionale di documenti da filtrare. Se omesso, usa l'elenco interno.
  • score_min (float): Score minimo per il filtraggio.

Valori di ritorno

  • List[Dict[str, Any]]: elenco filtrato di documenti.

Raises

  • RuntimeError: quando il filtro per score fallisce.

Esempi


filtered_docs = rm.get_by_score(score_min=0.35)

3. filter_by_mean_score

Descrizione

Riceve un elenco di chunk (documenti), calcola la media degli score e filtra per mantenere solo i chunk con score maggiore o uguale a tale media.

Argomenti

  • chunks (list[dict[str, Any]]): elenco di chunk con il campo 'score'.

Valori di ritorno

  • list[dict[str, Any]]: elenco filtrato oppure vuoto se l'input è vuoto.

Raises

  • RuntimeError: se si verifica un errore nel calcolo o nel filtraggio.

Esempi


chunks = [
    {"text": "A", "score": 0.5},
    {"text": "B", "score": 0.3},
    {"text": "C", "score": 0.7},
]
filtered = rm.filter_by_mean_score(chunks)
# filtered conterá chunks com score >= 0.5

4. generate_context

Descrizione

Genera una stringa compatta nel formato "Score: X | Content: testo" per ogni documento, sostituendo con spazi gli a capo nel testo per una migliore formattazione.

Argomenti

  • docs (List[Dict[str, Any]]): documenti da convertire in contesto. Usa quelli interni della classe se omesso.

Valori di ritorno

  • str: stringa concatenata con i documenti formattati riga per riga.

Raises

  • RuntimeError: in caso di errore nell'elaborazione della stringa.

Esempi


context_string = rm.generate_context()
print(context_string)
# Exemplo saída:
# Score: 0.38 | Content: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
# Score: 0.36 | Content: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

5. get_files

Descrizione

Estrae informazioni standardizzate sui file presenti nei metadati dei documenti, restituendo un elenco di file con id, nome, estensione e score massimo associato.

Argomenti

  • docs (List[Dict[str, Any]]): elenco di documenti da cui estrarre i metadati. Usa l'elenco interno se omesso.

Valori di ritorno

  • List[Dict[str, Any]]: elenco di dizionari che rappresentano i file filtrati per id e ordinati secondo l'ultima elaborazione.

Raises

  • RuntimeError: in caso di errore nell'estrazione dei metadati.

Esempi


files_info = rm.get_files()
print(files_info)
# [
#   {"id": "cucinare", "name": "LESSICO per CUCINARE.pdf", "ext": "pdf", "score": 0.38},
#   {"id": "tenerezza", "name": "TENEREZZA.pdf", "ext": "pdf", "score": 0.36}
# ]
