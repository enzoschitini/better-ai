Panoramica

La classe TestPineconeVectorStore offre un insieme di metodi per interagire in modo pratico con un database vettoriale gestito dalla piattaforma Pinecone. Incapsula operazioni comuni come l'inizializzazione del client, la generazione di embedding vettoriali a partire da testi, la ricerca per similarità e l'eliminazione di vettori basata su filtri sui metadati.

Questo insieme di funzionalità risolve il problema della complessità nella gestione diretta di Pinecone, fornendo un'interfaccia semplice e pronta per le operazioni tipiche in casi d'uso come la ricerca semantica nei documenti, l'organizzazione dei dati vettoriali e la manutenzione degli indici vettoriali.

In pratica, questa classe può essere usata per indicizzare documenti, eseguire ricerche intelligenti per testo e mantenere aggiornato il database vettoriale senza dover manipolare direttamente le risorse di più basso livello dell'API di Pinecone.

Flusso di Esecuzione

  1. Inizializzazione del Client
    Si chiama get_client() per creare e configurare un client Pinecone con l'indice e i namespace definiti (o predefiniti). Questo client viene memorizzato internamente per l'uso nelle operazioni successive.
  2. Generare e Salvare gli Embedding
    Tramite il metodo embedding(), si inseriscono testi (o si legge un file di esempio) che verranno elaborati per generare vettori di embedding. Questi vettori vengono inviati per l'archiviazione in Pinecone insieme ai metadati associati per facilitare le ricerche future.
  3. Ricerca per Similarità
    Si esegue retriever() per effettuare ricerche in Pinecone basandosi su una query testuale e su filtri applicati ai metadati archiviati. Il metodo restituisce i vettori più rilevanti in base alla similarità calcolata.
  4. Rimozione dei Vettori
    Infine, con il metodo delete() è possibile cancellare vettori specifici filtrati da un metadato (come source o file_id), garantendo la manutenzione e la pulizia dell'indice secondo le necessità.

Punti Importanti dell'Architettura e Insight

  • La classe utilizza la composizione istanziando oggetti di altre classi specializzate (PineconeClient, PineconeRetriever e PineconeEmbedding), separando chiaramente le responsabilità.
  • L'uso di namespace distinti (main_namespace e global_namespace) permette di organizzare i vettori in diversi "scope" all'interno dello stesso indice, facilitando la gestione.
  • La manipolazione dei metadati negli embedding e nei filtri rende possibili ricerche ed eliminazioni mirate, aumentando la precisione e il controllo sui dati.
  • I metodi implementano print con un ritorno JSON ben formattato per facilitare il debug e la verifica dei risultati, molto utile nei test.
  • C'è il supporto al fallback dei parametri usando valori predefiniti, il che riduce la necessità di configurazione iniziale.

Descrizione della Classe e dei Metodi

Classe TestPineconeVectorStore

Descrizione

Classe per facilitare l'integrazione e i test con il Pinecone vector store, fornendo metodi per connettersi al servizio, indicizzare vettori di testo, eseguire ricerche di similarità ed eliminare vettori in base ai metadati.

1. __init__

Descrizione

Inizializza l'istanza della classe definendo i nomi dell'indice, i namespace, il modello di embedding e le dimensioni dei vettori, con valori predefiniti se non forniti.

Argomenti

  • index_name (str): nome dell'indice Pinecone.
  • main_namespace (str): namespace principale.
  • global_namespace (str): namespace globale.
  • embedding_model_name (str): modello per gli embedding.
  • dimensions (int): dimensione dei vettori.

Valori di ritorno

Non restituisce alcun valore.

Raises

Nessuno.

Esempi


# Criar objeto com configurações padrão
tester = TestPineconeVectorStore()

# Criar objeto com parâmetros customizados
tester_custom = TestPineconeVectorStore(
    index_name="meu_indice",
    main_namespace="principal",
    embedding_model_name="modelo-custom",
    dimensions=1536
)

2. get_client

Descrizione

Inizializza e restituisce un client Pinecone configurato con gli indici e i namespace interni. Conserva internamente il client per il riutilizzo.

Argomenti

Nessuno.

Valori di ritorno

  • PineconeClient: oggetto client configurato per le interazioni con Pinecone.

Raises

Nessuno.

Esempi


cliente = tester.get_client()
# cliente pode ser usado para operações avançadas se necessário

3. retriever

Descrizione

Esegue una ricerca per similarità nell'indice Pinecone per recuperare i vettori/documenti più rilevanti in base al testo della query e ai filtri sui metadati.

Argomenti

  • query (str): testo per la ricerca di similarità.
  • filter_search (dict): filtri sui metadati per affinare la ricerca.
  • k (int): numero massimo di risultati da restituire.

Valori di ritorno

  • list: lista con i risultati più simili trovati.

Raises

Nessuno.

Esempi


resultados = tester.retriever(
    query="Quais arquivos existem na base?",
    filter_search={"source": ["example_text.txt"]},
    k=3
)
for r in resultados:
    print(r["metadata"], r["score"])

4. embedding

Descrizione

Genera vettori di embedding per un testo fornito (o per un file di esempio se non viene indicato nulla) e salva questi vettori con i metadati in Pinecone.

Argomenti

  • embedding_content (str): testo di cui generare l'embedding.
  • embedding_metadata (dict): metadati associati a questi vettori.

Valori di ritorno

  • dict: risposta di Pinecone che conferma lo stato del salvataggio dei vettori.

Raises

Nessuno.

Esempi


response = tester.embedding(
    embedding_content="Este é um exemplo de texto para embedding.",
    embedding_metadata={"file_id": "file_001", "user_id": "user_01", "source": "input.txt"}
)
print(response["status"])

5. delete

Descrizione

Rimuove vettori da Pinecone filtrando per uno specifico campo di metadato e il suo valore, all'interno di un namespace.

Argomenti

  • target_feature (str): campo del metadato per il filtro nell'eliminazione.
  • target_id (str): valore del campo usato per selezionare i vettori.
  • namespace (str): namespace per l'azione di eliminazione, usa quello principale se vuoto.
  • features (list): lista dei campi di metadati considerati nell'eliminazione.

Valori di ritorno

  • dict: risposta di Pinecone che indica il risultato dell'operazione.

Raises

Nessuno.

Esempi


delete_response = tester.delete(
    target_feature="source",
    target_id="example_text.txt",
    namespace="main_namespace",
    features=["file_id", "source"]
)
print(delete_response)
