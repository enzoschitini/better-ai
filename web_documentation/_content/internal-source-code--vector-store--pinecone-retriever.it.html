Panoramica

La classe PineconeRetriever è un'implementazione specializzata per interagire con il servizio di ricerca vettoriale Pinecone, facilitando il recupero efficiente di documenti in base alla similarità dei vettori e ai filtri sui metadati. Incapsula la connessione con l'indice Pinecone e il modello di embedding, fornendo metodi per eseguire ricerche per similarità di testo e query paginate complesse che filtrano i documenti secondo criteri specifici.

Il problema principale che risolve è l'astrazione della complessità della manipolazione diretta di Pinecone, rendendo semplice eseguire ricerche vettoriali con filtri, oltre a garantire una gestione adeguata degli embedding e della paginazione nei risultati. In pratica, può essere utilizzata per ricerche intelligenti in grandi basi di documenti, sistemi di raccomandazione o qualsiasi applicazione che dipenda da un recupero semantico efficiente.

Ad esempio, immagina un'applicazione che debba individuare documenti correlati a una domanda posta dall'utente, filtrando per categorie o altri metadati – questa classe facilita tale interazione con Pinecone, occupandosi dalla generazione dei vettori fino all'estrazione dei documenti rilevanti, senza che l'utente debba padroneggiare il protocollo di interrogazione di Pinecone.

Flusso di Esecuzione

  1. Inizializzazione dell'oggetto PineconeRetriever:
    • Riceve un'istanza opzionale di PineconeClient. Se non fornita, crea internamente una nuova istanza predefinita.
    • Recupera le configurazioni predefinite, come la dimensione del batch e la dimensione del vettore.
    • Inizializza le connessioni con l'indice Pinecone e il modello di embedding, oltre al namespace utilizzato.
  2. Esecuzione della ricerca per similarità (similarity_search):
    • Riceve il testo della query, il numero massimo di risultati (k) e un filtro opzionale sui metadati.
    • Valida i parametri, convertendo il testo della query in un vettore di embedding con il modello associato.
    • Costruisce la query di filtro per Pinecone, compatibile con la ricerca per uguaglianza o per più valori ($eq e $in).
    • Esegue la query sull'indice, richiedendo i metadati per ogni risultato.
    • Formatta i documenti restituiti, rimuovendo il campo "text" dal metadata e calcolando lo score di similarità.
  3. Recupero di documenti per metadati (get_all_docs_by_metadata):
    • Permette di cercare tutti i documenti che possiedono un determinato valore o una lista di valori in una chiave di metadata, gestendo grandi volumi tramite paginazione automatica.
    • Definisce un vettore dummy (zero vector) per eseguire la query, dato che l'obiettivo è filtrare per metadata.
    • Itera sulle pagine di risultati finché non ci sono più token di paginazione, aggregando i documenti.
    • Restituisce la lista completa dei documenti trovati, ciascuno con id, metadata e score.

Variabili d'Ambiente

Nessuna variabile d'ambiente viene utilizzata direttamente in questa classe.

Punti Importanti dell'Architettura e Insight

  • L'uso del pattern Dependency Injection, permettendo di ricevere un PineconeClient esterno, facilita i test e il riuso della connessione con Pinecone.
  • Internamente applica un forte incapsulamento, nascondendo i dettagli di configurazione, generazione degli embedding e del protocollo di interrogazione di Pinecone.
  • La gestione accurata delle eccezioni in tutti i metodi garantisce che gli errori siano facilmente identificabili e segnalati in modo adeguato.
  • Supporta filtri nel formato Pinecone ($eq e $in), ampliando l'espressività delle ricerche senza aumentare la complessità per l'utente.
  • Implementa una paginazione esplicita nella query per metadati, permettendo di lavorare con indici molto grandi senza esaurire la memoria.
  • Utilizza un'operazione di embedding per le query testuali che è offloaded al client, mantenendo il focus sull'orchestrazione del flusso.
  • La classe dipende da altre: PineconeClient, PineconeVectorStoreConfig e ApplicationTracing, seguendo un progetto modulare.

Descrizione della Classe e dei Metodi

Classe PineconeRetriever

Descrizione

Classe che gestisce l'interazione con il servizio Pinecone per eseguire ricerche vettoriali basate su embedding di testo e filtri sui metadati. Fornisce metodi per la ricerca di similarità semplice e il recupero paginato di documenti per metadati, utilizzando configurazioni personalizzabili per batch size, dimensione dei vettori e namespace.

Argomenti del Costruttore

ArgomentoTipoDescrizioneValore Predefinito
clientOptional[PineconeClient]Istanza del client Pinecone per indicizzazione ed embedding.None

Metodi

1. __init__

Descrizione

Inizializza l'oggetto PineconeRetriever configurando il client Pinecone, la configurazione del vettore (dimensione e batch size), l'indice e il namespace per le query.

Argomenti

  • client (Optional[PineconeClient]): Client Pinecone personalizzato.
  • Se non fornito, crea un nuovo client predefinito.

Valori di ritorno

  • Non restituisce alcun valore.

Raises

  • RuntimeError: Se l'inizializzazione fallisce per qualsiasi eccezione.

Esempi


retriever = PineconeRetriever()  # Cria retriever com configuração padrão
custom_client = PineconeClient(...)
retriever_custom = PineconeRetriever(custom_client)  # Usa client personalizado

2. similarity_search

Descrizione

Esegue una ricerca per similarità vettoriale a partire da una query testuale, restituendo i k documenti più rilevanti. Accetta filtri sui metadati per affinare i risultati.

Argomenti

  • query (str): Testo della query per la ricerca vettoriale.
  • k (int): Numero massimo di risultati da restituire.
  • filter_search (Optional[Dict[str, Any]]): Dizionario con il filtro per i metadati (es: {"category": ["finance","tech"]}).

Valori di ritorno

  • List[Dict[str, Any]]: Lista di documenti contenenti id, text, metadata (senza il campo text) e score (similarità).

Raises

  • ValueError: Se query è vuota o k è minore o uguale a zero.
  • ValueError: Se il filtro filter_search non è valido.
  • RuntimeError: Se si verifica un errore nella generazione dell'embedding o nella query a Pinecone.

Esempi


results = retriever.similarity_search(
    query="How to bake a cake?",
    k=3,
    filter_search={"category": "recipes"}
)
for doc in results:
    print(doc["id"], doc["score"])

3. get_all_docs_by_metadata

Descrizione

Ottiene tutti i documenti nell'indice Pinecone che contengono un valore specifico o un insieme di valori per una chiave di metadati, usando la paginazione per gestire grandi volumi.

Argomenti

  • batch_size (int | None): Numero di documenti per pagina (valore predefinito configurato).
  • dimension (int | None): Dimensione del vettore dummy usato nella query (valore predefinito configurato).
  • target_key (str): Chiave del metadato per il filtro (es: "file_id").
  • target_value (Union[str, List[str]]): Valore o lista di valori da cercare nella chiave.

Valori di ritorno

  • List[Dict[str, Any]]: Lista di documenti contenenti id, metadata e score.

Raises

  • ValueError: Se target_value non è indicato.
  • RuntimeError: In caso di errore durante la query a Pinecone.

Esempi


all_pdfs = retriever.get_all_docs_by_metadata(
    batch_size=20,
    target_key="file_extension",
    target_value="pdf"
)
print(f"Found {len(all_pdfs)} PDF documents")

Uso


if __name__ == "__main__":
    import json

    pine_client = PineconeClient(
        index_name="backai-vectorstore",
        main_namespace="betterai-embeddings-dev",
    )

    retriver = PineconeRetriever(pine_client)

    # Similarity search
    similarity_results = retriver.similarity_search(
        query="What is the capital of France?",
        k=5
    )

    print("Similarity Search Results:")
    print(json.dumps(similarity_results, indent=2))

    # Metadata search
    metadata_results = retriver.get_all_docs_by_metadata(
        target_key="file_extension",
        target_value="pdf",
        batch_size=10
    )

    print("\nMetadata Search Results:")
    print(json.dumps(metadata_results, indent=2))
