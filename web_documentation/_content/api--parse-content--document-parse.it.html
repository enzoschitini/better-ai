Document Parse - /parse-content/document-parse

Riceve un file e uno schema JSON per estrarre e strutturare il suo contenuto tramite LLM. Usalo quando hai bisogno di trasformare documenti non strutturati (PDF, Word, testo) in dati organizzati e pronti per l'uso.

Parametri

ParametroTipoDescrizioneEsempio
metadatastring (JSON)Metadati ausiliari del documento, di libero utilizzo da parte del client.{"client": "Acme", "doc_type": "contract"}
document_schemastring (JSON)Schema che definisce i campi da estrarre. Ogni chiave riceve type e description.{"summary": {"type": "str", "description": "Resumo do documento"}}
filefile (upload)File da elaborare. Formati accettati: txt, md, pdf, docx. Limite: 50MB.contrato.pdf
configstring (JSON) — opzionaleConfigurazioni del parser: modello LLM, istruzioni personalizzate e modalità debug.{"model_provider": "OpenAI", "model_id": "gpt-4.1-mini", "debug_mode": false}

Nota: il job_id viene generato automaticamente dal server e restituito nella risposta.

Formati degli schemi: https://github.com/enzoschitini/better-ai/blob/production/doc/Modules/Content%20Parse/Json%20To%20Pydantic.md

Config (spiegazione di ogni parametro)

Il campo config è opzionale. Se non viene inviato, l'API usa il default_config interno del parser.

CampoTipoCosa faDefaultQuando modificarlo
model_providerstringDefinisce il provider del modello di linguaggio. Attualmente i flussi principali usano OpenAI e Groq."OpenAI"Cambialo quando vuoi cambiare provider per costo, latenza o disponibilità.
model_idstringIdentifica il modello usato per l'estrazione (gpt-4.1-mini, ad esempio)."gpt-4.1-mini"Modificalo quando ti serve più qualità, un costo inferiore o una finestra di contesto diversa.
max_input_tokensintegerLimite di token di input consentiti per validare la dimensione del contesto prima dell'esecuzione.1000000Riducilo per imporre un limite di costo o aumentalo in scenari con documenti molto lunghi.
debug_modebooleanAttiva log e informazioni di debug dell'agente di parsing.falseUsa true per il troubleshooting e torna a false in produzione.
instructionsstringIstruzioni operative su come estrarre i dati (stile, regole, focus)."Extraia dados do texto"Personalizzalo per orientare il modello verso formati e criteri specifici del tuo dominio.
descriptionstringRuolo/comportamento atteso dell'agente, che rafforza il formato della risposta e il fallback con null."Leia o texto e extraia as informações relevantes conforme o esquema definido..."Modificalo per scenari di business con politiche proprie di compilazione e validazione.

Esempio completo di config:


{
  "model_provider": "OpenAI",
  "model_id": "gpt-4.1-mini",
  "max_input_tokens": 1000000,
  "debug_mode": false,
  "instructions": "Extraia dados do texto",
  "description": "Leia o texto e extraia as informações relevantes conforme o esquema definido. Retorne um JSON estruturado com os dados extraídos. Caso não encontre alguma informação, retorne null para aquele campo."
}

Request


curl --location 'http://localhost:8000/parse-content/document-parse' \
--header 'X-API-Key: ******' \
--form 'metadata="{\"value1\": \"value3\"}"' \
--form 'document_schema="{
  \"summary\": {
    \"type\": \"str\",
    \"description\": \"Resumo do conteúdo do arquivo\"
  }
}"' \
--form 'config="{
  \"model_provider\": \"OpenAI\",
  \"model_id\": \"gpt-4.1-mini\",
  \"debug_mode\": true,
  \"instructions\": \"Extraia dados do texto\",
  \"description\": \"Leia o texto e extraia as informações relevantes conforme o esquema definido. Retorne um JSON estruturado com os dados extraídos. Caso não encontre alguma informação, retorne null para aquele campo.\"
}"' \
--form 'file=@"/path/to/file"'
