Visão geral

O arquivo define duas classes. RequestProcessor valida o que chega da requisição (configuração em JSON e imagens enviadas). ImageGenerate executa o fluxo de geração de imagens usando ImageGeneratorService e PayloadBuilder, e persiste o resultado.

O endpoint de geração em src/web_services_network/routes/davinci.py usa as duas classes.

RequestProcessor

Recebe a configuração como texto JSON (config) e a lista de arquivos (files), ambos opcionais. O método assíncrono process() devolve um dicionário com as chaves config (dicionário) e image_bytes (lista de bytes).

EtapaRegraErro
_process_configConverte o texto de config com json.loads. Sem config, nada é feito.HTTPException com status 400 quando o JSON é inválido.
_process_filesAceita apenas image/jpeg e image/png, com limite de 10 MB (max_mb=10), via FilesPayloadBuilder.RuntimeError com a mensagem "Erro ao carregar as imagens".

ImageGenerate

O construtor recebe user_input (obrigatório), instructions, config e image_bytes. Os métodos são:

MétodoDescrição
generateCria um ImageGeneratorService, monta as partes e a configuração, chama o modelo e faz o parse das respostas.
build_payloadsUsa PayloadBuilder com um jobId gerado por IDGenerator.timestamp(prefix="job_") e devolve mongo_payload, storage_payload e response_payload.
save_to_mongoDBGrava o mongo_payload em DATABASE_NAME / COLLECTION_NAME com DocumentStore.
save_to_supabaseEnvia cada imagem do storage_payload ao bucket com StorageRepository.upload_to_supabase, usando o id da imagem como nome do arquivo.
save_results_localSalva as imagens geradas na pasta local img_test, para testes. Não faz parte do runner.
runnerExecuta o fluxo completo e devolve o response_payload.

Fluxo do runner

  1. generate: gera as imagens e agrega as respostas.
  2. build_payloads: separa o resultado em três payloads.
  3. save_to_mongoDB: persiste o registro (sem os bytes das imagens).
  4. save_to_supabase: persiste os arquivos de imagem.
  5. Devolve o response_payload, com text_response e a lista de URLs em images.

Exemplo de uso


from src.image_generation.module import ImageGenerate

# Cria o gerador com o prompt e a configuração opcional
generator = ImageGenerate(
    user_input="Uma borboleta no estilo de Da Vinci",
    instructions=None,
    config={"aspect_ratio": "16:9", "number_of_images": 2},
    image_bytes=None,
)

# Executa o fluxo completo e recebe as URLs
response = generator.runner()
print(response["images"])

Observações

Erros genéricos. build_payloads, save_to_mongoDB e save_to_supabase capturam qualquer exceção e levantam um RuntimeError com mensagem fixa, sem encadear a causa original.
