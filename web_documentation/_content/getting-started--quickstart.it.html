1. Aggiorna il Progetto

Per prima cosa, assicurati di essere sul branch corretto e che il tuo codice sia aggiornato:


git checkout production
git pull
git checkout -b nome-da-sua-branch

2. Crea l'Ambiente Virtuale

Requisito: Python 3.14 o superiore (versione fissata in .python-version).

Crea un ambiente virtuale per isolare le dipendenze del progetto:


python -m venv .venv

3. Attiva l'Ambiente Virtuale


.\.venv\Scripts\Activate.ps1


.venv\Scripts\activate.bat

Dopo l'attivazione, il tuo terminale dovrebbe apparire così:


(.venv) PS C:\Users\nome_do_usuario\better-ai>

4. Installa le Dipendenze

Puoi installare le dipendenze in due modi:

Usando uv (consigliato)


uv sync

6. Esegui l'applicazione

Il progetto espone due servizi indipendenti, che possono essere eseguiti separatamente o in parallelo (in terminali distinti):

ServizioComandoPortaQuando usarlo
API (FastAPI)uvicorn web_services:app --reload8000Consumo programmatico dei moduli di IA via HTTP
Interfaccia (Streamlit)streamlit run web_app.py8501Uso visuale delle applicazioni (Acquarello, Content Generator)

Prerequisiti: ambiente virtuale attivato (passo 3), dipendenze installate (passo 4) e file .env configurato (passo 5).

6.3. Risoluzione dei problemi

SintomoCausa probabileCosa fare
ModuleNotFoundError all'avvioAmbiente virtuale non attivato o dipendenze mancantiRiattiva il .venv (passo 3) ed esegui uv sync (passo 4)
Errore di autenticazione nei provider di IAChiavi mancanti o non valide nel .envRivedi il passo 5 e conferma i valori delle chiavi
Errore di connessione a MongoDB/Supabase/PineconeCredenziali o host errati nel .envVerifica le variabili del database e la connettività di rete
Porta già in usoUn'altra istanza del servizio è attivaTermina il processo precedente o usa un'altra porta (--port)

Se l'ambiente virtuale diventa inconsistente, ricrealo da zero:


deactivate
Remove-Item -Recurse -Force .\.venv
python -m venv .venv
