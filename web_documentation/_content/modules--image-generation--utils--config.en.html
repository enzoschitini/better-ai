Next to max_output_tokens, the code carries the annotation that gemini-2.5-flash-image uses 1024 or 2048 and gemini-3-pro-image-preview uses 4096 or 8192.

Base prompt

BASE_PROMPT is the text, in English, that opens every prompt sent to Gemini. It defines the agent's role (visual creation and transformation) and the constraints: follow the user's request, apply the style of the reference images, preserve what was not asked to change, not add or remove elements without instruction, and prioritize consistency and quality.
