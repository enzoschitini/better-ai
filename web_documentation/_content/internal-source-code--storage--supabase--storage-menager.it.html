1. Panoramica

Il modulo è composto da due classi principali che lavorano insieme per astrarre la complessità dell'API di Supabase. L'idea centrale è separare la configurazione della connessione (infrastruttura) dalla manipolazione dei file (logica di business).

  • SupabaseConnection: Garantisce che la connessione con il server venga stabilita correttamente usando le variabili d'ambiente.
  • StorageManager: Offre un'interfaccia semplificata per inviare, eliminare e recuperare i link dei file all'interno di uno specifico "bucket" (secchio/repository).

2. Flusso di Esecuzione

Per capire come interagiscono le classi, immagina il seguente flusso:

  1. Caricamento dell'Ambiente: Lo script legge il file .env per acquisire l'URL e la Chiave del progetto.
  2. Istanziazione: Quando crei uno StorageManager, questo verifica se hai già una connessione. In caso contrario, chiama automaticamente la SupabaseConnection.
  3. Accesso al Bucket: Il client si connette allo specifico bucket indicato all'inizio.
  4. Operazione: Chiami metodi semplici (come upload_bytes), e la classe gestisce la logica interna della libreria ufficiale di Supabase.

3. Riepilogo dei Metodi

MetodoClasseBreve Descrizione
__init__SupabaseConnectionValida le credenziali e crea il client Client.
__init__StorageManagerDefinisce il bucket di destinazione e garantisce l'esistenza di un client attivo.

4. Architettura e Insight

  • Singleton Implicito vs Dependency Injection: La classe StorageManager accetta un supabase_client opzionale. Questo è ottimo per i test unitari o per riutilizzare una connessione già aperta in un'altra parte del sistema, evitando connessioni multiple non necessarie.
  • Gestione degli errori: L'uso di blocchi try/except nei metodi di scrittura (upload/delete) evita che l'applicazione si blocchi in caso di errore di rete o di permessi.
  • Sicurezza: L'uso di dotenv e os.getenv garantisce che le chiavi sensibili non siano mai esposte direttamente nel codice sorgente.

5. Documentazione Dettagliata

Classe SupabaseConnection

Descrizione

Responsabile di centralizzare l'autenticazione. Funge da "fabbrica" di connessioni, garantendo che il client di Supabase sia correttamente configurato prima di qualsiasi operazione.

Argomenti

  • Non ha argomenti diretti (utilizza le variabili d'ambiente .env).

Metodi

1. __init__

  • Descrizione: Individua le variabili SUPABASE_URL e SUPABASE_SECRET_KEY, validandole prima di istanziare il client ufficiale.
  • Argomenti: Nessuno.
  • Valori di ritorno: Nessuno (inizializza l'attributo self.client).
  • Raises: ValueError se le chiavi non vengono trovate nell'ambiente.
  • Esempi:

conn = SupabaseConnection()
client = conn.client # Cliente pronto para uso

Classe StorageManager

Descrizione

Incapsula la logica di manipolazione dei bucket. È la classe "front-end" che lo sviluppatore userà per la maggior parte del tempo per gestire i file.

Argomenti

  • bucket_name (str): Il nome della cartella/repository in Supabase.
  • supabase_client (Optional[Client]): Un'istanza esistente del client Supabase.

Metodi

1. upload_bytes

  • Descrizione: Invia un file allo storage a partire da dati in memoria (bytes).
  • Argomenti:
    • path_on_storage (str): Percorso/nome del file nella destinazione.
    • file_bytes (bytes): Il contenuto binario del file.
    • content_type (str): Tipo di file (es: image/png).
  • Valori di ritorno: dict con i metadati dell'upload o None in caso di errore.
  • Raises: Cattura le eccezioni generiche e le stampa sulla console.
  • Esempi:

manager.upload_bytes("docs/perfil.jpg", foto_bytes, "image/jpeg")

2. delete_files

  • Descrizione: Elimina uno o più file contemporaneamente.
  • Argomenti:
    • paths (List[str]): Lista di percorsi (es: ["img1.jpg", "img2.jpg"]).
  • Valori di ritorno: dict con lo stato della rimozione o None.
  • Raises: Cattura le eccezioni di rete o di permessi.
  • Esempi:

manager.delete_files(["velho/foto1.png", "velho/foto2.png"])

3. get_url

  • Descrizione: Ottiene l'indirizzo web pubblico per accedere a un file.
  • Argomenti:
    • path (str): Percorso del file all'interno del bucket.
  • Valori di ritorno: str contenente l'URL completo.
  • Raises: ValueError se il percorso è vuoto.
  • Esempi:

link = manager.get_url("produtos/celular.png")
print(link) # https://xyz.supabase.co/storage/v1/object/public/...
