Panoramica

La classe FieldMetadataParser è responsabile dell'interpretazione dei metadati definiti in dizionari per i campi di dati e della loro conversione in tipi e campi compatibili con la libreria Pydantic. Analizza informazioni come tipo del campo, obbligatorietà, descrizione, esempi e vincoli, generando così una rappresentazione pronta per la validazione e l'uso nei modelli Pydantic.

Questo processo è fondamentale per i sistemi che ricevono schemi di dati dinamici o configurazioni esterne e devono costruire modelli di validazione in modo automatizzato e coerente. Con questa classe è possibile trasformare una specifica di tipo JSON direttamente in tipi Pydantic, garantendo validazione automatica e documentazione generata a partire dai metadati.

In pratica, può essere utilizzata in framework di dati, importazioni dinamiche di schemi o in qualsiasi applicazione che modelli dati a partire da definizioni flessibili.

Flusso di Esecuzione

  1. Il metodo parse riceve un valore arbitrario che può essere o meno un metadato di campo.
  2. Verifica se il valore è un dizionario contenente la chiave "type", identificandolo come metadato valido per l'analisi.
  3. Se è un metadato, delega al metodo privato _parse_metadata che esegue la trasformazione dettagliata.
  4. _parse_metadata estrae il tipo indicato e verifica se il campo è obbligatorio (required).
  5. Se il tipo è "list", cerca la definizione del tipo degli elementi (items), potendo generare un tipo generico o un modello annidato per oggetti complessi.
  6. Mappa il tipo stringa nel corrispondente tipo Python, utilizzando il metodo _map_type.
  7. Se il campo non è obbligatorio, il tipo viene incapsulato in Optional per supportare l'assenza di valore.
  8. Crea un Field di Pydantic con parametri come valore predefinito, descrizione, esempi e vincoli di dimensione.
  9. Restituisce una tupla formata dal tipo finale e dall'oggetto Field da usare direttamente nei modelli Pydantic.
  10. Se il valore non è un metadato riconosciuto, restituisce None.
  11. Se si verifica un errore nel parsing, solleva un'eccezione di tipo RuntimeError con i dettagli.

Variabili d'Ambiente

Nessuna variabile d'ambiente è necessaria per il funzionamento di questa classe.

Punti Importanti dell'Architettura e Insights

  • La classe utilizza l'incapsulamento, limitando le funzioni ausiliarie all'ambito privato (_parse_metadata e _map_type).
  • Utilizza la creazione dinamica di modelli Pydantic (create_model) per rappresentare tipi complessi annidati (oggetti all'interno di liste), consentendo flessibilità ed estensibilità.
  • Il parser interpreta una struttura di tipo JSON per produrre tipi annotati e informazioni complete per la validazione — facilitando l'integrazione con dati dinamici.
  • Supporta attributi opzionali, valori predefiniti, descrizioni ed esempi, promuovendo la documentazione automatica tramite Pydantic.
  • La gestione esplicita degli errori con messaggi chiari facilita il debug.
  • Il metodo _map_type è facilmente estensibile a nuovi tipi, bastando aggiungerli al dizionario.

Descrizione della Classe e dei Metodi

Classe FieldMetadataParser

Descrizione

Classe per analizzare i metadati forniti in dizionari e trasformarli in tipi e campi configurati per l'uso con Pydantic. Facilita la creazione dinamica di modelli di validazione a partire da specifiche esterne, interpretando tipi, obbligatorietà e metadati descrittivi.

Argomenti del Costruttore

Nessun parametro nel costruttore.

Metodi

1. parse

Descrizione

Riceve un valore qualsiasi e, se si tratta di un dizionario che definisce metadati di campo (con la chiave "type"), restituisce una tupla contenente il tipo Pydantic risultante e un oggetto Field configurato con le proprietà. In caso contrario, restituisce None.

Argomenti

  • value (Any): Valore da analizzare come metadato di campo.

Valori di ritorno

  • Tuple[Any, Any] | None: Tupla con il tipo del campo e l'oggetto Field, oppure None se non è un metadato.

Raises

  • RuntimeError: Se si verifica un qualsiasi errore durante l'analisi dei metadati, viene sollevata un'eccezione con un messaggio esplicativo.

Esempi


# Metadado válido para um campo inteiro obrigatório
result = parser.parse({"type": "int", "required": True, "description": "Idade do usuário"})
# result será algo como (int, Field(..., description="Idade do usuário"))

# Metadado inválido ou não seguindo o padrão retorna None
result = parser.parse("apenas uma string")
# result será None

2. _parse_metadata

Descrizione

Metodo ausiliario privato che riceve un dizionario di metadati validato, ne estrae il tipo, configurando il tipo e le proprietà del campo, trattando in particolare liste e oggetti annidati, e restituendo la tupla con il tipo Pydantic e l'oggetto Field.

Argomenti

  • value (Dict[str, Any]): Dizionario contenente le proprietà del campo, come tipo, obbligatorietà, esempi, tra le altre.

Valori di ritorno

  • Tuple[Any, Any]: Tupla con il tipo del campo e le informazioni di Field.

Raises

  • ValueError: Se il tipo è "list" e non contiene la definizione obbligatoria della chiave "items".

Esempi


# Parse de um campo do tipo lista de inteiros não obrigatória
type_, field = parser._parse_metadata({
    "type": "list",
    "items": {"type": "int"},
    "required": False,
    "description": "Lista de números"
})
# type_ será Optional[List[int]]
# field conterá description e configurações

# Parse de um campo objeto aninhado dentro da lista
type_, field = parser._parse_metadata({
    "type": "list",
    "items": {
        "type": "object",
        "properties": {
            "nome": {"type": "str", "description": "Nome do item"}
        }
    }
})
# type_ será List[ModeloDinâmico]
# field configurado conforme descrito

3. _map_type

Descrizione

Mappa il nome di un tipo rappresentato da una stringa nel corrispondente tipo Python, utilizzato nella modellazione Pydantic. Se il tipo non viene riconosciuto, restituisce Any come fallback.

Argomenti

  • type_name (str): Stringa che rappresenta il tipo, ad esempio "str", "int", "list".

Valori di ritorno

  • tipo: Tipo Python corrispondente (es: str, int, list) oppure Any se non riconosciuto.

Esempi


if __name__ == "__main__":
    parser = FieldMetadataParser()

    test_cases = [
        {
            "input": {
                "type": "str",
                "description": "Nome do personagem",
                "example": "John"
            }
        },
        {
            "input": {
                "type": "int",
                "default": 10
            }
        },
        {
            "input": "valor simples"
        }
    ]

    for i, case in enumerate(test_cases, 1):
        result = parser.parse(case["input"])
        print(f"\nTeste {i}")
        print("Input:", case["input"])
        print("Output:", result)
