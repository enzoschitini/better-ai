Visão geral

Web Service Network - API faz parte da plataforma BetterAI. Este parágrafo ocupa o lugar do texto que vem da fonte, para que o espaçamento, a medida de linha e o índice lateral possam ser conferidos.

Uso

O bloco abaixo mostra a chamada típica, com realce de sintaxe:


from better_ai import WebServiceNetworkApi

client = WebServiceNetworkApi()
result = client.run(model_id="claude-sonnet-5-5")
print(result)

Parâmetros

NomeTipoDescrição
model_idstrIdentificador do modelo a usar.
timeoutintLimite em segundos para a resposta.
