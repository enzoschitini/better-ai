Panoramica

Use fa parte della piattaforma BetterAI. Questo paragrafo prende il posto del testo che arriva dalla sorgente, così da poter verificare spaziatura, misura di riga e indice laterale.

Uso

Il blocco qui sotto mostra la chiamata tipica, con evidenziazione della sintassi:


from better_ai import Use

client = Use()
result = client.run(model_id="claude-sonnet-5-5")
print(result)
