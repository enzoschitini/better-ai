Visão geral

A classe PayloadBuilder recebe o job_id e o dicionário produzido por parse_responses (veja Image Generator Service). Chaves ausentes têm valor padrão: text_input e text_responses viram vazios e generate_config usa DEFAULT_CONTENT_CONFIG.

generate_payloads

Devolve a tupla (mongo_payload, storage_payload, response_payload).

PayloadDestinoConteúdo
mongo_payloadMongoDBjobId, user_input, text_response, image_response, generate_config e cost_information. Não inclui os bytes das imagens.
storage_payloadSupabase StorageLista com id, url, mime_type e byte de cada imagem.
response_payloadCliente da APItext_response e images (lista de URLs).

Imagens

Para cada imagem com mime_type e data, o builder gera um id com IDGenerator.timestamp(prefix=ID_PREFIX) e monta a URL como BASE_URL/<id>. Imagens sem mime_type ou sem data são ignoradas. O campo text_response usa apenas o primeiro texto de text_responses, ou None se a lista estiver vazia.

Custo

cost_information vem de CostCalculator (veja Cost Calculator). Com uma única entrada em usage_metadata, ela é usada diretamente; com várias, são somadas por merge_cost_information; sem nenhuma, os tokens valem 0. O número de imagens vem de number_of_images da configuração. O resultado fica em cache durante a vida do objeto.

Exemplo de uso


from src.image_generation.utils.payload_builder import PayloadBuilder
from src.utils.unique_id_factory import IDGenerator

# Resultado agregado de ImageGeneratorService.parse_responses
parsed = {
    "text_responses": ["Aqui está a imagem."],
    "images": [{"mime_type": "image/png", "data": b"..."}],
    "generate_config": {"model": "gemini-2.5-flash-image", "number_of_images": 1},
    "usage_metadata": [{"prompt_tokens": 587, "output_tokens": 1320, "total_tokens": 1907}],
}

builder = PayloadBuilder(IDGenerator.timestamp(prefix="job_"), parsed)
mongo_payload, storage_payload, response_payload = builder.generate_payloads()

print(response_payload["images"])

Observações

URL e nome do arquivo. A URL usa o id sem extensão, e save_to_supabase também envia o arquivo com o id como nome. A variável ext é calculada no builder, mas não entra na URL.

O arquivo termina com um bloco if __name__ == "__main__" com dados de exemplo, executável com python -m src.image_generation.utils.payload_builder.
