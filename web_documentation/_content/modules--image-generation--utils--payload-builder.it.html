Panoramica

La classe PayloadBuilder riceve il job_id e il dizionario prodotto da parse_responses (vedi Image Generator Service). Le chiavi assenti hanno un valore predefinito: text_input e text_responses diventano vuoti e generate_config usa DEFAULT_CONTENT_CONFIG.

generate_payloads

Restituisce la tupla (mongo_payload, storage_payload, response_payload).

PayloadDestinazioneContenuto
mongo_payloadMongoDBjobId, user_input, text_response, image_response, generate_config e cost_information. Non include i byte delle immagini.
storage_payloadSupabase StorageLista con id, url, mime_type e byte di ogni immagine.
response_payloadClient dell'APItext_response e images (lista di URL).

Immagini

Per ogni immagine con mime_type e data, il builder genera un id con IDGenerator.timestamp(prefix=ID_PREFIX) e costruisce l'URL come BASE_URL/<id>. Le immagini senza mime_type o senza data vengono ignorate. Il campo text_response usa solo il primo testo di text_responses, oppure None se la lista è vuota.

Costo

cost_information proviene da CostCalculator (vedi Cost Calculator). Con una sola voce in usage_metadata, viene usata direttamente; con più voci, vengono sommate da merge_cost_information; senza alcuna voce, i token valgono 0. Il numero di immagini proviene da number_of_images della configurazione. Il risultato resta in cache per la vita dell'oggetto.

Esempio d'uso


from src.image_generation.utils.payload_builder import PayloadBuilder
from src.utils.unique_id_factory import IDGenerator

# Risultato aggregato di ImageGeneratorService.parse_responses
parsed = {
    "text_responses": ["Aqui está a imagem."],
    "images": [{"mime_type": "image/png", "data": b"..."}],
    "generate_config": {"model": "gemini-2.5-flash-image", "number_of_images": 1},
    "usage_metadata": [{"prompt_tokens": 587, "output_tokens": 1320, "total_tokens": 1907}],
}

builder = PayloadBuilder(IDGenerator.timestamp(prefix="job_"), parsed)
mongo_payload, storage_payload, response_payload = builder.generate_payloads()

print(response_payload["images"])

Osservazioni

URL e nome del file. L'URL usa l'id senza estensione, e anche save_to_supabase invia il file con l'id come nome. La variabile ext viene calcolata nel builder, ma non entra nell'URL.

Il file termina con un blocco if __name__ == "__main__" con dati di esempio, eseguibile con python -m src.image_generation.utils.payload_builder.
