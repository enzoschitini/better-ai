Panoramica

La classe WebServiceAPI agisce come un involucro configurabile per creare e gestire un'applicazione FastAPI. Il suo scopo è semplificare il processo di inizializzazione dell'applicazione web, configurare i middleware essenziali, registrare le rotte predefinite e integrare automaticamente router aggiuntivi in modo dinamico a partire da pacchetti Python.

Risolve il problema della ripetizione e della dispersione delle configurazioni comuni nelle API FastAPI, riunendo in un unico punto tutta la configurazione iniziale, il middleware CORS, le rotte di base per salute e autenticazione, oltre a facilitare l'estensione dell'API con router esterni. In pratica, può essere usata per accelerare lo sviluppo di API RESTful, garantendo una base coerente e consentendo un'integrazione modulare e test facilitati.

La classe è particolarmente utile nei progetti che vogliono mantenere un'architettura pulita e scalabile, con log chiari del ciclo di vita dell'applicazione e controllo centralizzato della configurazione tramite dizionario e variabili d'ambiente.

Flusso di Esecuzione

  1. Istanziazione della classe
    Lo sviluppatore crea un'istanza di WebServiceAPI, passando opzionalmente un dizionario di configurazioni personalizzato. Se non viene passato alcun dizionario, viene usato un valore predefinito tramite l'import CONFIG.
  2. Inizializzazione dell'applicazione con initialize()
    Chiamando il metodo initialize(), l'applicazione FastAPI viene creata con le configurazioni di nome, descrizione, versione, gestione del ciclo di vita e middleware CORS configurati, oltre alla registrazione delle rotte predefinite (/health, /, /health-authorization).
  3. Inclusione di router aggiuntivi
    Dopo aver inizializzato l'applicazione, lo sviluppatore può includere router aggiuntivi utilizzando i metodi include_routers() o test_routers() passando liste di router FastAPI. Ogni inclusione viene registrata nei log per facilitare il tracciamento.
  4. Scoperta dinamica dei router
    Se si desidera, si può usare il metodo collect_routers(package_name) per caricare dinamicamente i router definiti nei moduli di un determinato pacchetto, consentendo un'estensibilità modulare.
  5. Ottenimento dell'istanza FastAPI
    Infine, per eseguire o manipolare l'applicazione al di fuori della classe, il metodo get_app() restituisce l'istanza FastAPI già inizializzata.
  6. Esecuzione e log del ciclo di vita
    Al momento dell'inizializzazione dell'applicazione, un banner e informazioni importanti vengono mostrati nei log. Vengono inoltre registrati gli eventi di arresto dell'applicazione.

Variabili d'Ambiente

  • DOMAIN: Definisce il dominio di base dell'applicazione, usato per mostrare URL e documentazione. Se non definita, assume "http://localhost:8000".

Punti Importanti dell'Architettura e Insights

  • La classe incapsula la configurazione di FastAPI sulla base di un dizionario esterno, facilitando la parametrizzazione senza modificare il codice.
  • Uso di asynccontextmanager per controllare il ciclo di vita dell'applicazione FastAPI, con log chiari all'avvio e all'arresto.
  • L'inclusione dinamica dei router con collect_routers utilizza l'introspezione tramite pkgutil e importlib, consentendo la modularizzazione delle API.
  • Netta separazione tra configurazione di base (middleware, rotte predefinite) ed espansione tramite rotte aggiuntive.
  • Il logger predefinito è collegato al server uvicorn, garantendo l'integrazione con i log di runtime di ASGI.
  • Le rotte predefinite includono una rotta di autorizzazione che dipende da una validazione tramite chiave API, usando il metodo statico Authorization.validate_api_key.

Descrizione della Classe e dei Metodi

Classe WebServiceAPI

Descrizione

Questa classe rappresenta un wrapper configurabile per applicazioni FastAPI, che permette di inizializzare un'API web sulla base di configurazioni esterne, aggiungere middleware e rotte predefinite, gestire il ciclo di vita dell'applicazione e ampliare l'API tramite l'inclusione dinamica di router provenienti da pacchetti Python.

Argomenti del Costruttore

ArgomentoTipoDescrizioneValore Predefinito
configdictDizionario con le configurazioni per il servizio webCONFIG

1. __init__

Descrizione

Inizializza la classe, definendo configurazioni, logger e dominio di base per l'applicazione.

Argomenti

  • config (dict): configurazioni per l'API.

Valori di ritorno

  • Non restituisce alcun valore.

Raises

  • Nessuna.

Esempi


ws_api = WebServiceAPI()  # Usa CONFIG padrão
ws_api_custom = WebServiceAPI(config=my_config_dict)

2. initialize

Descrizione

Crea e configura un'istanza FastAPI con titolo, descrizione, versione e il ciclo di vita definito. Aggiunge il middleware CORS e registra le rotte predefinite per l'health check e la rotta radice.

Argomenti

  • Nessuno.

Valori di ritorno

  • FastAPI: istanza dell'applicazione FastAPI inizializzata.

Raises

  • Nessuna.

Esempi


app = ws_api.initialize()
# app agora está pronta para uso em um servidor ASGI

3. include_routers

Descrizione

Include nell'applicazione una lista di router FastAPI, garantendo che l'applicazione sia già stata inizializzata. Registra nei log l'inclusione di ciascun router.

Argomenti

  • routers (list): lista di oggetti router di FastAPI.

Valori di ritorno

  • Non restituisce alcun valore.

Raises

  • RuntimeError: se l'applicazione non è inizializzata.

Esempi


ws_api.include_routers([user_router, product_router])

4. test_routers

Descrizione

Simile a include_routers, include una lista di router per eventuali test o uso ad-hoc, con log dell'inclusione.

Argomenti

  • routers (list): lista di router da includere.

Valori di ritorno

  • Non restituisce alcun valore.

Raises

  • RuntimeError: se l'applicazione non è inizializzata.

Esempi


ws_api.test_routers([test_router])

5. collect_routers

Descrizione

Scopre e importa dinamicamente tutti i router chiamati router all'interno dei moduli del pacchetto indicato, restituendoli in una lista.

Argomenti

  • package_name (str): nome del pacchetto (dotted path) in cui cercare moduli con router.

Valori di ritorno

  • list: lista di istanze di router FastAPI trovate.

Raises

  • Nessuna.

Esempi


routers = ws_api.collect_routers("src.api.v1")
# Retorna todos os routers em src/api/v1/*

6. get_app

Descrizione

Restituisce l'istanza FastAPI inizializzata da usare esternamente.

Argomenti

  • Nessuno.

Valori di ritorno

  • FastAPI: istanza FastAPI.

Raises

  • RuntimeError: se chiamato prima dell'inizializzazione dell'applicazione.

Esempi


app = ws_api.get_app()

Esempi pratici completi:


ws_api = WebServiceAPI()
app = ws_api.initialize()

routers = ws_api.collect_routers("src.api.v1")
ws_api.include_routers(routers)

# Agora app está pronto para ser executado

Un altro esempio semplificato:


ws_api = WebServiceAPI()
ws_api.initialize()

ws_api.include_routers([user_router])

app = ws_api.get_app()
