Image Generation - /davinci/image-generation

Genera immagini a partire da un prompt testuale, con supporto per istruzioni di stile, configurazioni del modello e immagini di riferimento. Usalo quando hai bisogno di creare o trasformare immagini in modo programmatico tramite LLM multimodale.

Parametri

ParametroTipoDescrizioneEsempio
user_inputstringPrompt principale che descrive l'immagine da generare."Uma pizzaria napolitana à noite"
instructionsstring — opzionaleIstruzioni aggiuntive di stile o linee guida creative per la generazione."Estilo de animação 3D como as da Disney"
configstring (JSON) — opzionaleConfigurazioni del modello: model, temperature, top_p, max_output_tokens, aspect_ratio, number_of_images.{"model": "gemini-2.5-flash-image", "aspect_ratio": "9:16"}
filesfile[] — opzionaleImmagini di riferimento per guidare la generazione. Accetta upload multipli.reference.png

Config (spiegazione di ogni parametro)

Il campo config è opzionale. Se non viene inviato, l'API usa il DEFAULT_CONTENT_CONFIG interno del modulo di generazione. I campi inviati sovrascrivono soltanto i valori corrispondenti.

CampoTipoCosa faDefaultQuando modificarlo
modelstringModello multimodale usato nella generazione (gemini-2.5-flash-image, gemini-3-pro-image-preview)."gemini-2.5-flash-image"Passa al modello pro quando ti serve una qualità maggiore o più token di output.
temperaturefloat (0.0–2.0)Controlla la creatività della generazione. Valori bassi = risultati più prevedibili.0.75Riducilo per una maggiore fedeltà al prompt, aumentalo per più variazione creativa.
top_pfloat (0.0–1.0)Nucleus sampling: limita l'insieme dei token considerati.0.85Riducilo per output più conservativi e coerenti.
max_output_tokensintegerLimite di token di output. gemini-2.5-flash-image: 1024 o 2048. gemini-3-pro-image-preview: 4096 o 8192.1024Aumentalo quando usi modelli pro o quando la risposta testuale viene troncata.
aspect_ratiostringProporzione dell'immagine generata. Vedi i valori accettati qui sotto."1:1"Modificalo in base alla destinazione dell'immagine (feed, stories, banner).
number_of_imagesinteger (≥ 1)Quantità di immagini generate. Ogni immagine è una chiamata indipendente al modello.1Aumentalo per ottenere variazioni, ricordando che costo e latenza crescono in proporzione.

Valori accettati per aspect_ratio

ValoreFormatoUso tipico
1:1QuadratoPost del feed, avatar, thumbnail
3:4RitrattoRitratti, catalogo prodotti
4:3PaesaggioImmagini classiche, presentazioni
9:16Ritratto a schermo interoStories, Reels, TikTok
16:9WidescreenBanner, copertine, video/hero

Request


curl --location 'http://localhost:8000/davinci/image-generation' \
--form 'user_input="Crie a imagem de uma pizzaria napolitana"' \
--form 'instructions="O estilo deve ser uma animação 3D como as da Disney"' \
--form 'config="{
  \"model\": \"gemini-2.5-flash-image\",
  \"temperature\": 0.75,
  \"top_p\": 0.85,
  \"max_output_tokens\": 1024,
  \"aspect_ratio\": \"9:16\",
  \"number_of_images\": 2
}"' \
--form 'files=@"/path/to/file"'
