Panoramica

La classe ModelPricing è stata creata per rappresentare un modello di prezzi dei linguaggi naturali basati su token, permettendo di calcolare il costo associato all'elaborazione di input e output in diversi modelli di linguaggio. Risolve il problema di determinare il prezzo dell'uso dei modelli di linguaggio, convertendo i costi per milione di token in costi unitari, facilitando la stima finanziaria per le chiamate alle API o l'uso dei modelli.

In pratica, questa classe può essere usata per ottenere in modo rapido e diretto il costo di una richiesta che coinvolge una certa quantità di token di input e output, bastando indicare il modello desiderato. Questo è utile per chi lavora con API di elaborazione del linguaggio, permettendo di stimare le spese e controllare l'uso basato sui token.

Flusso di Esecuzione

  1. Si inizializza un'istanza della classe ModelPricing passando il nome del modello come parametro. Se il modello non è supportato, viene sollevata un'eccezione.
  2. Tramite i metodi input_rate_per_token e output_rate_per_token, si ottiene il costo unitario per token di input e di output, rispettivamente, convertendo i valori che sono originariamente definiti per milione di token.
  3. Questi valori vengono moltiplicati per il numero reale di token elaborati per calcolare il costo totale di input e output.
  4. Il risultato finale è il costo stimato in dollari per l'uso del modello in relazione alla quantità di token indicata.

Punti Importanti dell'Architettura e Insights

  • I prezzi sono memorizzati in COST_MODELS, un dizionario che associa il nome del modello ai costi per milione di token per input e output.
  • Il metodo di calcolo converte il costo per milione in costo per token dividendo il valore per 1.000.000, garantendo flessibilità per diverse scale.
  • Questo approccio incapsula la definizione dei prezzi in una classe, facilitando la manutenzione e l'estensione a nuovi modelli, bastando aggiungere voci al dizionario.
  • Validando il modello all'inizializzazione, si evitano errori successivi durante il calcolo, garantendo sicurezza nell'uso della classe.

Descrizione della Classe e dei Metodi

Classe ModelPricing

Descrizione

Classe per il calcolo del costo di utilizzo dei modelli di linguaggio, basato sulla quantità di token di input e output e sui prezzi definiti per modello. Offre un'interfaccia semplice per convertire i prezzi per milione di token in prezzi unitari.

Argomenti del Costruttore

ArgomentoTipoDescrizioneValore Predefinito
modelstrIl nome del modello per il quale calcolare i costi.Nessuno

Metodi

1. __init__

Descrizione

Inizializza l'istanza della classe verificando se il modello indicato esiste nella base dei prezzi supportati, e assegna i prezzi corrispondenti.

Argomenti

  • model (str): nome del modello di linguaggio utilizzato per consultare i prezzi.

Valori di ritorno

  • Non restituisce alcun valore.

Raises

  • ValueError: Se il modello indicato non è presente tra i modelli supportati.

Esempi


model_pricing = ModelPricing("gpt-4.1-mini")

2. input_rate_per_token

Descrizione

Calcola e restituisce il costo per token di input, basato sul prezzo per milione di token configurato.

Argomenti

  • Nessuno.

Valori di ritorno

  • float: costo in dollari per token di input.

Raises

  • Nessuna.

Esempi


input_cost_per_token = model_pricing.input_rate_per_token()
# Retorna algo como 0.0000004 para "gpt-4.1-mini"

3. output_rate_per_token

Descrizione

Calcola e restituisce il costo per token di output, basato sul prezzo per milione di token configurato.

Argomenti

  • Nessuno.

Valori di ritorno

  • float: costo in dollari per token di output.

Raises

  • Nessuna.

Esempi


output_cost_per_token = model_pricing.output_rate_per_token()
# Retorna algo como 0.0000016 para "gpt-4.1-mini"

Esempio Completo di Utilizzo


model = "gpt-4.1-mini"
input_token_count = 946
output_token_count = 255

model_pricing = ModelPricing(model)
input_cost = model_pricing.input_rate_per_token() * input_token_count
output_cost = model_pricing.output_rate_per_token() * output_token_count

print(f"Custo de entrada (USD): {input_cost:.6f}")
print(f"Custo de saída (USD): {output_cost:.6f}")

# python -m src.tokens_calculate.model_pricing
