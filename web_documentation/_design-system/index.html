Design System

Os tokens, componentes e regras que mantêm todas as páginas da documentação com o mesmo visual.

Princípios

Este catálogo é a fonte da verdade do visual da documentação. Ele usa os próprios componentes, então o que você vê aqui é o que as páginas entregam.

  • Conteúdo primeiro. Fundo branco, texto quase preto e uma coluna de leitura estreita. Nada compete com o que a pessoa veio ler.
  • Uma cor de ação. O índigo da BetterAI aparece só em botão principal, link e destaque de seleção.
  • Estrutura previsível. Toda página tem a mesma moldura: abas de área, menu lateral, artigo e índice da página.
  • Claro e escuro por tokens. Nenhum componente define cor própria. Tudo vem de variáveis que trocam com o tema.
  • Funciona em qualquer tela. Abaixo de 1024 px o menu vira gaveta, e abaixo de 1280 px o índice vira um bloco recolhido.

Para criar uma página nova, copie templates/page-template.html. Para mudar o visual, edite os tokens em css/tokens.css, nunca o CSS de uma página.

Cores

Todas as cores são variáveis CSS definidas em css/tokens.css, com um valor para o tema claro e outro para o escuro. Alterne o tema no canto superior direito para ver os dois.

Raios

Cinco valores, definidos como tokens. Use o menor que combine com o tamanho do elemento: quanto maior a peça, maior o raio.

--radius-xs6 px. Código inline
--radius-sm10 px. Botões pequenos
--radius-md12 px. Botões e links do menu
--radius-lg16 px. Cartões, código e avisos
--radius-pillCampo de busca

Botões e controles

O botão principal (.btn-cta) é o único elemento preenchido com a cor de ação. Use um por área da tela.

Seletor de idioma

Fica ao lado do botão de tema. Mostra o código do idioma atual e abre um menu com o nome de cada idioma escrito na própria língua. Ao escolher, dispara o evento ds:lang no document; a troca do conteúdo é feita pelo site.

Menu lateral

Mostra só a área ativa. O título do grupo fica em Inter 600, 12 px. Pastas abrem e fecham, e subníveis recuam com uma linha à esquerda. A página atual usa aria-current="page". O selo .badge marca páginas sem conteúdo.

Abas de área

Uma aba por área da documentação, logo abaixo do cabeçalho. A aba ativa fica em negrito com um traço de 1,5 px embaixo. Em telas menores que 1024 px elas saem e o seletor de áreas passa para dentro da gaveta do menu.

Busca

Abre em um diálogo centralizado com Ctrl K ou /. O resultado selecionado usa o mesmo preenchimento do item ativo do menu. Este exemplo é estático; a lógica de busca é de cada site.

Cabeçalho da página

Categoria em índigo, título, botão para copiar a página e um resumo de uma ou duas linhas. O resumo é obrigatório em páginas de conteúdo.

Model Gateway

Uma fábrica única para criar modelos e agentes Agno de qualquer provedor, com os parâmetros validados antes da chamada.

Texto corrido

Todo o conteúdo do artigo vive dentro de .prose. Títulos de seção ganham um link # ao passar o mouse e alimentam o índice da página à direita.

Visão geral

A ModelGateway esconde as diferenças entre as APIs. Veja o Quickstart para começar.

  • Um ponto de entrada: o mesmo método cria modelos de qualquer provedor.
  • Validação de parâmetros: argumentos inválidos geram erro antes da chamada.

  2. Chame create_model.

Código

Três formas. O bloco simples leva só o botão de copiar. O bloco com título serve para arquivos. O bloco com abas agrupa variações do mesmo exemplo e já é a forma usada para provedores, sistemas operacionais e linguagens. Realce de sintaxe usa as classes t-k (palavra-chave), t-s (texto), t-n (número), t-f (função) e t-c (comentário).

Moldura de mídia

Imagens e vídeos entram em uma moldura com fundo cinza e cantos de 18 px. Vídeos têm proporção 16:9. Use figure com figcaption quando houver legenda, e sempre escreva o texto alternativo.

Estrutura da página

Toda página usa a mesma moldura. O arquivo templates/page-template.html já vem montado assim; troque só o conteúdo de .prose e os textos do cabeçalho.

body
├─ a.skip                       link "Ir para o conteúdo"
├─ header.header#header         fixo no topo
│  ├─ div.banner#banner         aviso opcional
│  └─ div.bar
│     ├─ div.row1               logo, busca, botões, idioma, tema
│     ├─ nav.tabs-row           uma aba por área
│     └─ div.subbar             só no celular: botão do menu
├─ div.shell
│  ├─ aside.side-wrap#side      menu lateral da área

Regras

Faça
  • Comece pelo template e troque só o conteúdo.
  • Use variáveis de tokens.css para toda cor, raio e fonte.
  • Escreva títulos em frase, com a primeira letra maiúscula só no início.
  • Dê um resumo a toda página de conteúdo.
  • Use o tipo de aviso que combina com o efeito para quem lê.
  • Escreva texto alternativo em toda imagem.
Não faça
  • Escrever cor em hexadecimal ou rgb() dentro de uma página.
  • Criar um componente parecido com um que já existe aqui.
  • Usar o índigo como fundo fora do botão principal.
  • Pular níveis de título: h2 vai direto para h3.
  • Colocar mais de um botão principal na mesma área.
  • Estilizar com style no HTML, salvo valores de demonstração.
