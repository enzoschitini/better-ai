Generate Pydantic Schema

La classe GeneratePydanticSchema è stata sviluppata per facilitare la creazione dinamica di modelli Pydantic a partire da dizionari Python annidati.

    #Panoramica

    La classe GeneratePydanticSchema è stata sviluppata per facilitare la creazione dinamica di modelli Pydantic a partire da dizionari Python annidati. In scenari in cui vengono ricevuti dati complessi e strutturati, come nelle API o nei sistemi che gestiscono diverse strutture JSON, questa classe automatizza la generazione di schemi Pydantic, usati per la validazione, la conversione e la documentazione di tali strutture.

    Il problema che la classe risolve è la necessità manuale e ripetitiva di creare modelli Pydantic per ogni struttura di dati complessa, che spesso varia in profondità e formato. Utilizzando questa classe, lo sviluppatore passa un dizionario di dati e riceve un modello Pydantic che riflette esattamente la struttura e i tipi di tali dati, inclusi schemi annidati per gli oggetti interni e le liste.

    In pratica, può essere usata per validare i dati di input, generare esempi per la documentazione automatica o costruire interfacce adattive in sistemi che consumano dati dinamici.

    #Flusso di Esecuzione

    1. L'utente istanzia la classe GeneratePydanticSchema, potendo opzionalmente indicare un oggetto FieldMetadataParser per personalizzare l'estrazione dei metadati dei campi.
    2. Il metodo convert() viene chiamato con un dizionario Python che rappresenta i dati da modellare e un nome radice per il modello (predefinito "RootModel").
    3. La classe analizza ricorsivamente ogni chiave e valore del dizionario:
      • Per i campi scalari, determina il tipo di base.
      • Per i dizionari annidati, genera un nuovo modello Pydantic con un nome automatico univoco.
      • Per le liste, analizza il tipo del primo elemento per definire il tipo degli elementi nella lista, generando modelli per gli oggetti se necessario.
    4. I campi ricevono metadati (descrizione) generati automaticamente o tramite l'analisi del metadata_parser.
    5. Tutti i modelli generati vengono archiviati internamente e possono essere recuperati con il metodo get_models().
    6. In caso di errore durante la conversione, viene sollevata un'eccezione RuntimeError con i dettagli dell'errore.

    #Punti Importanti dell'Architettura e Insights

    • La generazione dinamica sfrutta il metodo create_model di Pydantic per creare classi a runtime, facilitando la creazione di modelli non noti in fase di codifica.
    • L'uso ricorsivo consente la creazione di modelli annidati che riflettono la struttura complessa dei dati di input.
    • Il conteggio incrementale garantisce nomi univoci per i modelli ausiliari, evitando collisioni.
    • La classe dipende da FieldMetadataParser per arricchire i campi con metadati, creando una separazione che favorisce la personalizzazione e l'estensibilità dell'analisi dei campi.
    • La gestione specifica per le liste, con il tentativo di singolarizzare i nomi (presumibilmente usando inflector.singular_noun), mostra attenzione alla nomenclatura dei modelli.
    • Gestione attenta delle eccezioni durante il parsing e la conversione, registrando il messaggio di errore e mantenendo l'usabilità esponendo errori chiari all'utente.
    • Internamente, l'archiviazione dei modelli in un dizionario consente la consultazione e il riutilizzo successivi.

    #Descrizione della Classe e dei Metodi

    #Classe GeneratePydanticSchema

    #Descrizione

    Questa classe ha il ruolo di convertire dizionari complessi e annidati in modelli Pydantic in modo programmatico. Automatizza la generazione di schemi di validazione che riflettono fedelmente la struttura dei dati di input, con supporto per campi annidati, liste e l'integrazione con un parser di metadati per arricchire la descrizione dei campi.

    Il suo uso è indicato per scenari di validazione dinamica e per la costruzione di API o sistemi che ricevono dati JSON diversi e necessitano di una validazione forte ed esplicita.

    #Argomenti del Costruttore

    ArgomentoTipoDescrizioneValore Predefinito
    metadata_parserFieldMetadataParserOggetto per l'analisi e l'estrazione dei metadati dei campi.Nuova istanza di FieldMetadataParser

    #Metodi

    #1. __init__

    Descrizione

    Inizializza l'istanza della classe, definendo il parser di metadati e preparando l'archiviazione interna per i modelli generati.

    Argomenti

    • metadata_parser (FieldMetadataParser): Parser opzionale per l'estrazione dei metadati.

    Valori di ritorno

    • Non restituisce alcun valore.

    Raises

    • Nessuna.

    Esempi

    schema_generator = GeneratePydanticSchema()

    #2. convert

    Descrizione

    Riceve un dizionario Python e lo converte in un modello Pydantic radice, generando automaticamente tutti i modelli annidati necessari per la validazione completa della struttura.

    Argomenti

    • data (Dict[str, Any]): Dizionario di dati da convertire in modello.
    • root_name (str): Nome del modello radice da creare. Il valore predefinito è "RootModel".

    Valori di ritorno

    • Type[BaseModel]: Modello Pydantic generato per il dizionario indicato.

    Raises

    • RuntimeError: Nel caso in cui si verifichi un errore durante la conversione dei dati.

    Esempi

    data = {
    "nome": "João",
    "idade": 30,
    "endereco": {
        "rua": "Av. Brasil",
        "numero": 100
    }
}

model = schema_generator.convert(data, root_name="Pessoa")
# model agora é uma classe Pydantic com campos nome, idade e endereco (que é outro modelo)

    #3. get_models

    Descrizione

    Restituisce tutti i modelli Pydantic creati fino a questo momento, inclusi i modelli annidati generati durante la conversione dei dati.

    Argomenti

    Nessuno.

    Valori di ritorno

    • Dict[str, Type[BaseModel]]: Dizionario con i nomi dei modelli come chiave e le classi Pydantic come valore.

    Raises

    Nessuna.

    Esempi

    all_models = schema_generator.get_models()
# Pode acessar, por exemplo, all_models["Pessoa1"] para um modelo aninhado

    #4. _generate_name

    Descrizione

    Genera un nome univoco per i modelli Pydantic annidati, combinando una base di nome con un contatore incrementale.

    Argomenti

    • base (str): Nome di base per il modello.

    Valori di ritorno

    • str: Nome univoco generato, es: "Endereco1".

    Raises

    Nessuna.

    Esempi

    nome = schema_generator._generate_name("endereco")
# "Endereco1"

    #5. _create_model

    Descrizione

    Crea dinamicamente un modello Pydantic a partire da un nome e da campi specificati, archiviandolo nel dizionario interno.

    Argomenti

    • name (str): Nome del modello.
    • fields (Dict[str, Tuple[Any, Any]]): Mappatura dei campi in tuple (tipo, metadati).

    Valori di ritorno

    • Type[BaseModel]: Modello Pydantic creato.

    Raises

    Nessuna.

    Esempi

    fields = {
    "nome": (str, ...),
    "idade": (int, ...)
}

model = schema_generator._create_model("Pessoa", fields)

    #6. _resolve_type

    Descrizione

    Determina il tipo Pydantic di base di un semplice valore Python.

    Argomenti

    • value (Any): Valore di cui va dedotto il tipo.

    Valori di ritorno

    • Any: Tipo Python corrispondente (str, bool, int, float, list, dict oppure Any come fallback).

    Raises

    Nessuna.

    Esempi

    t = schema_generator._resolve_type(10)   # int
t2 = schema_generator._resolve_type("hi") # str

    #7. _parse_object

    Descrizione

    Analizza un dizionario e crea un modello Pydantic per esso, elaborando ricorsivamente tutti i campi dell'oggetto.

    Argomenti

    • obj (Dict[str, Any]): Dizionario di cui eseguire il parsing.
    • name (str): Nome del modello da creare.

    Valori di ritorno

    • Type[BaseModel]: Modello Pydantic creato per l'oggetto analizzato.

    Raises

    Nessuna.

    Esempi

    model = schema_generator._parse_object({"a": 1, "b": "x"}, "SimpleModel")

    #8. _parse_field

    Descrizione

    Determina il tipo e i metadati per un singolo campo, gestendo i casi di dizionari, liste, valori scalari e applicando un'analisi personalizzata tramite metadata_parser.

    Argomenti

    • key (str): Nome del campo.
    • value (Any): Valore del campo per dedurne il tipo.

    Valori di ritorno

    • Tuple[Any, Any]: Tupla con il tipo del campo e l'istanza Field contenente i metadati per Pydantic.

    Raises

    • RuntimeError: Se si verifica un errore durante il parsing, incapsula l'errore originale.

    Esempi

    if __name__ == "__main__":
    json_data = {
        "script": {
            "setting": {
                "type": "str",
                "description": "Onde o filme acontece",
                "example": "Tokyo"
            },
            "genre": {
                "type": "str",
                "description": "Gênero do filme",
                "example": "Heist"
            },
            "storyline": "A big robbery"
        },
        "context": {
            "year": {
                "type": "int",
                "description": "Ano da história",
                "example": 2025
            }
        },
        "people": {
            "characters": [
                {
                    "name": {
                        "type": "str",
                        "description": "Nome do personagem"
                    },
                    "role": "protagonist"
                }
            ]
        }
    }

    converter = JsonToPydantic()
    Movie = converter.convert(json_data, "Movie")

    print(Movie.schema_json(indent=2))
