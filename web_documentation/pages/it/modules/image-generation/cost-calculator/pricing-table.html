Image Generation / Cost Calculator

Pricing Table

Tabella dei prezzi dei modelli Gemini usata per calcolare il costo delle generazioni, con valori in dollari per milione di token e per immagine.

In questa pagina

    Fonte: src/image_generation/cost_calculator/pricing_table.py. Il notebook originale di questa pagina era vuoto; il contenuto è stato scritto a partire dal codice.

    #Panoramica

    Il file definisce la dataclass ModelPricing, la classe PricingTable e la lista BEST_TO_WORST_MODELS. I prezzi seguono la pagina dei prezzi dell'API di Gemini, citata in un commento nel codice. La versione della tabella si trova in PricingTable.VERSION (2026-02-11).

    #ModelPricing

    CampoTipoDescrizione
    input_per_million_tokensfloatPrezzo per milione di token di input.
    output_per_million_tokensfloatPrezzo per milione di token di output.
    image_price_per_unitfloat o NonePrezzo per immagine generata.
    cache_input_per_million_tokensfloat o NonePrezzo per milione di token di input letti dalla cache.
    cache_storage_per_million_tokens_per_hourfloat o NonePrezzo dell'archiviazione in cache, per milione di token all'ora.

    La dataclass è frozen: i valori non cambiano dopo la creazione.

    #Prezzi registrati

    ModelloInputOutputPer immagineCache (input)Cache (archiviazione/ora)
    gemini-3-flash-preview0.503.00-0.051.00
    gemini-3-pro-image-preview2.0012.000.134--
    gemini-2.5-flash0.302.50-0.031.00
    gemini-2.5-flash-preview-09-20250.302.50-0.031.00
    gemini-2.5-flash-lite0.100.40-0.011.00
    gemini-2.5-flash-lite-preview-09-20250.100.40-0.011.00
    gemini-2.5-flash-image0.300.00.039--
    gemini-2.0-flash0.100.400.0390.0251.00

    Valori in dollari: input, output e cache per milione di token; immagine per unità. Il trattino indica None.

    In gemini-2.5-flash-image, l'output è un'immagine; per questo il prezzo di output per token è 0.0 e il costo deriva dal prezzo per immagine.

    Risoluzione unica. Il prezzo di gemini-3-pro-image-preview (0.134) vale per 1K e 2K. Il commento nel codice registra che 4K costa 0.24 e che la tabella non distingue ancora la risoluzione.

    #get

    PricingTable.get(model) è un classmethod che restituisce il ModelPricing del modello. Se il modello non è registrato, solleva ValueError ("Modelo sem precificação cadastrada").

    from src.image_generation.cost_calculator.pricing_table import PricingTable

# Cerca il prezzo di un modello
pricing = PricingTable.get("gemini-2.5-flash-image")
print(pricing.image_price_per_unit)

# Versione della tabella dei prezzi
print(PricingTable.VERSION)
