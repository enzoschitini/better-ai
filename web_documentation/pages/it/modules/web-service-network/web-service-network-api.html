Web Service Network - API

La BetterAI Web Service Network è un'API modulare ad alte prestazioni progettata per orchestrare servizi di intelligenza artificiale in produzione.

In questa pagina

    La BetterAI Web Service Network è un'API modulare ad alte prestazioni progettata per orchestrare servizi di intelligenza artificiale in produzione. Espone un insieme di router specializzati — ricerca approfondita sul web, parsing di documenti, generazione di immagini e gestione di vector store — tutti accessibili via HTTP con autenticazione tramite chiave API.

    L'API è costruita su FastAPI ed eseguita con Uvicorn, offrendo documentazione interattiva automatica tramite Swagger UI (/docs) e supporto nativo per le richieste asincrone. Ogni endpoint restituisce risposte standardizzate con job_id, status, payload (result o content) e metriche dei tempi di esecuzione, facilitando la tracciabilità e l'integrazione con le pipeline di dati.

    Base URL: http://localhost:8000
    Autenticazione: X-API-Key nell'header di tutte le rotte protette
    Versione attuale: 1.0.0

    #3. Context Builder - /deep-research/context-builder

    POST/deep-research/context-builder

    Costruisce un contesto ricco in markdown a partire da una ricerca approfondita sul web, usando TavilyDeepResearch come motore di ricerca. Ideale per alimentare pipeline RAG, generazione di report o arricchimento dei prompt.

    #Parametri

    ParametroTipoDescrizioneEsempio
    querystringDomanda o tema centrale della ricerca. Definisce cosa verrà cercato."Principais tendências de IA em 2026?"
    search_depth"basic" | "advanced"Profondità della ricerca. basic per una visione rapida, advanced per una ricerca più ampia e dettagliata."advanced"
    max_resultsinteger (1–100)Numero massimo di risultati da recuperare e includere nel contesto.35
    topicstringCategoria o dominio della ricerca. Orienta il tipo di fonte privilegiata. Valori comuni: general, news, finance."news"
    include_answerbooleanSe true, include nel contesto una risposta generata automaticamente in base ai risultati trovati.true
    min_scorefloat (0.0–1.0)Punteggio minimo di rilevanza. I risultati al di sotto di questa soglia vengono scartati. Valori più alti = contesto più preciso, ma più piccolo.0.5

    #Request

    curl --location 'http://localhost:8000/deep-research/context-builder' \
--header 'Content-Type: application/json' \
--header 'X-API-Key: ******' \
--data '{
    "query": "Principais tendências de IA em 2026?",
    "search_depth": "advanced",
    "max_results": 35,
    "topic": "general",
    "include_answer": true,
    "min_score": 0.5
}'

    #Response

    "job_id": "job_1779392104064657200TsJh",
    "status": "success",
    "status_code": 200,
    "result": {
        "markdown": "...",

            "https://example.com"
        ]

        "start": "2026-05-21 16:35:04",
        "end": "2026-05-21 16:35:11",
        "duration_seconds": 7.0
    }
}

    #4. Document Parse - /parse-content/document-parse

    POST/parse-content/document-parse

    Riceve un file e uno schema JSON per estrarre e strutturare il suo contenuto tramite LLM. Usalo quando hai bisogno di trasformare documenti non strutturati (PDF, Word, testo) in dati organizzati e pronti per l'uso.

    #Parametri

    ParametroTipoDescrizioneEsempio
    metadatastring (JSON)Metadati ausiliari del documento, di libero utilizzo da parte del client.{"client": "Acme", "doc_type": "contract"}
    document_schemastring (JSON)Schema che definisce i campi da estrarre. Ogni chiave riceve type e description.{"summary": {"type": "str", "description": "Resumo do documento"}}
    filefile (upload)File da elaborare. Formati accettati: txt, md, pdf, docx. Limite: 50MB.contrato.pdf
    configstring (JSON) — opzionaleConfigurazioni del parser: modello LLM, istruzioni personalizzate e modalità debug.{"model_provider": "OpenAI", "model_id": "gpt-4.1-mini", "debug_mode": false}

    Nota: il job_id viene generato automaticamente dal server e restituito nella risposta.

    Formati degli schemi: https://github.com/enzoschitini/better-ai/blob/production/doc/Modules/Content%20Parse/Json%20To%20Pydantic.md

    #Config (spiegazione di ogni parametro)

    Il campo config è opzionale. Se non viene inviato, l'API usa il default_config interno del parser.

    CampoTipoCosa faDefaultQuando modificarlo
    model_providerstringDefinisce il provider del modello di linguaggio. Attualmente i flussi principali usano OpenAI e Groq."OpenAI"Cambialo quando vuoi cambiare provider per costo, latenza o disponibilità.
    model_idstringIdentifica il modello usato per l'estrazione (gpt-4.1-mini, ad esempio)."gpt-4.1-mini"Modificalo quando ti serve più qualità, un costo inferiore o una finestra di contesto diversa.
    max_input_tokensintegerLimite di token di input consentiti per validare la dimensione del contesto prima dell'esecuzione.1000000Riducilo per imporre un limite di costo o aumentalo in scenari con documenti molto lunghi.
    debug_modebooleanAttiva log e informazioni di debug dell'agente di parsing.falseUsa true per il troubleshooting e torna a false in produzione.
    instructionsstringIstruzioni operative su come estrarre i dati (stile, regole, focus)."Extraia dados do texto"Personalizzalo per orientare il modello verso formati e criteri specifici del tuo dominio.
    descriptionstringRuolo/comportamento atteso dell'agente, che rafforza il formato della risposta e il fallback con null."Leia o texto e extraia as informações relevantes conforme o esquema definido..."Modificalo per scenari di business con politiche proprie di compilazione e validazione.

    Esempio completo di config:

    {
  "model_provider": "OpenAI",
  "model_id": "gpt-4.1-mini",
  "max_input_tokens": 1000000,
  "debug_mode": false,
  "instructions": "Extraia dados do texto",
  "description": "Leia o texto e extraia as informações relevantes conforme o esquema definido. Retorne um JSON estruturado com os dados extraídos. Caso não encontre alguma informação, retorne null para aquele campo."
}

    #Request

    curl --location 'http://localhost:8000/parse-content/document-parse' \
--header 'X-API-Key: ******' \
--form 'metadata="{\"value1\": \"value3\"}"' \
--form 'document_schema="{
  \"summary\": {
    \"type\": \"str\",
    \"description\": \"Resumo do conteúdo do arquivo\"
  }
}"' \
--form 'config="{
  \"model_provider\": \"OpenAI\",
  \"model_id\": \"gpt-4.1-mini\",
  \"debug_mode\": true,
  \"instructions\": \"Extraia dados do texto\",
  \"description\": \"Leia o texto e extraia as informações relevantes conforme o esquema definido. Retorne um JSON estruturado com os dados extraídos. Caso não encontre alguma informação, retorne null para aquele campo.\"
}"' \
--form 'file=@"/path/to/file"'

    #Response

    {
    "job_id": "job_1788198742619260200fKBY",
    "status": "success",
    "status_code": 200,
    "content": {
        "summary": "..."
    },
    "time": {
        "start": "2026-08-31 14:52:22",
        "end": "2026-08-31 14:52:30",
        "duration_seconds": 8.0

    #5. Image Generation - /davinci/image-generation

    POST/davinci/image-generation

    Genera immagini a partire da un prompt testuale, con supporto per istruzioni di stile, configurazioni del modello e immagini di riferimento. Usalo quando hai bisogno di creare o trasformare immagini in modo programmatico tramite LLM multimodale.

    #Parametri

    ParametroTipoDescrizioneEsempio
    user_inputstringPrompt principale che descrive l'immagine da generare."Uma pizzaria napolitana à noite"
    instructionsstring — opzionaleIstruzioni aggiuntive di stile o linee guida creative per la generazione."Estilo de animação 3D como as da Disney"
    configstring (JSON) — opzionaleConfigurazioni del modello: model, temperature, top_p, max_output_tokens, aspect_ratio, number_of_images.{"model": "gemini-2.5-flash-image", "aspect_ratio": "9:16"}
    filesfile[] — opzionaleImmagini di riferimento per guidare la generazione. Accetta upload multipli.reference.png

    #Config (spiegazione di ogni parametro)

    Il campo config è opzionale. Se non viene inviato, l'API usa il DEFAULT_CONTENT_CONFIG interno del modulo di generazione. I campi inviati sovrascrivono soltanto i valori corrispondenti.

    CampoTipoCosa faDefaultQuando modificarlo
    modelstringModello multimodale usato nella generazione (gemini-2.5-flash-image, gemini-3-pro-image-preview)."gemini-2.5-flash-image"Passa al modello pro quando ti serve una qualità maggiore o più token di output.
    temperaturefloat (0.0–2.0)Controlla la creatività della generazione. Valori bassi = risultati più prevedibili.0.75Riducilo per una maggiore fedeltà al prompt, aumentalo per più variazione creativa.
    top_pfloat (0.0–1.0)Nucleus sampling: limita l'insieme dei token considerati.0.85Riducilo per output più conservativi e coerenti.
    max_output_tokensintegerLimite di token di output. gemini-2.5-flash-image: 1024 o 2048. gemini-3-pro-image-preview: 4096 o 8192.1024Aumentalo quando usi modelli pro o quando la risposta testuale viene troncata.
    aspect_ratiostringProporzione dell'immagine generata. Vedi i valori accettati qui sotto."1:1"Modificalo in base alla destinazione dell'immagine (feed, stories, banner).
    number_of_imagesinteger (≥ 1)Quantità di immagini generate. Ogni immagine è una chiamata indipendente al modello.1Aumentalo per ottenere variazioni, ricordando che costo e latenza crescono in proporzione.

    #Valori accettati per aspect_ratio

    ValoreFormatoUso tipico
    1:1QuadratoPost del feed, avatar, thumbnail
    3:4RitrattoRitratti, catalogo prodotti
    4:3PaesaggioImmagini classiche, presentazioni
    9:16Ritratto a schermo interoStories, Reels, TikTok
    16:9WidescreenBanner, copertine, video/hero

    #Request

    curl --location 'http://localhost:8000/davinci/image-generation' \
--form 'user_input="Crie a imagem de uma pizzaria napolitana"' \
--form 'instructions="O estilo deve ser uma animação 3D como as da Disney"' \
--form 'config="{
  \"model\": \"gemini-2.5-flash-image\",
  \"temperature\": 0.75,
  \"top_p\": 0.85,
  \"max_output_tokens\": 1024,
  \"aspect_ratio\": \"9:16\",
  \"number_of_images\": 2
}"' \
--form 'files=@"/path/to/file"'

    #Response

    {
    "job_id": "job_1788272755499472800EkNu",
    "status": "success",
    "status_code": 200,
    "result": {
        "text_response": "Com certeza! Aqui está uma pizzaria napolitana em estilo de animação 3D da Disney:\n\n \n",
        "images": [
            "https://hsenyunovbrmjejxqvjn.supabase.co/storage/v1/object/public/images/image_generations/img_1788272774157403200z8UW",
            "https://hsenyunovbrmjejxqvjn.supabase.co/storage/v1/object/public/images/image_generations/img_17882727741574032007MBY"
        ]
    },
