    #Panoramica

    Web Service Network - API fa parte della piattaforma BetterAI. Questo paragrafo prende il posto del testo che arriva dalla sorgente, così da poter verificare spaziatura, misura di riga e indice laterale.

    #Uso

    Il blocco qui sotto mostra la chiamata tipica, con evidenziazione della sintassi:

    from better_ai import WebServiceNetworkApi

client = WebServiceNetworkApi()
result = client.run(model_id="claude-sonnet-5-5")
print(result)

    #Parametri

    La tabella qui sotto serve a validare lo scorrimento orizzontale su schermi stretti:

    NomeTipoDescrizione
    model_idstrIdentificatore del modello da usare.
    timeoutintLimite in secondi per la risposta.
    streamboolRestituisce la risposta a pezzi.
