Curl Compiler

La classe CurlCompiler è stata creata per facilitare l'interpretazione e l'esecuzione programmatica di comandi curl nell'ambiente Python, utilizzando la libreria requests.

In questa pagina

    #Panoramica

    La classe CurlCompiler è stata creata per facilitare l'interpretazione e l'esecuzione programmatica di comandi curl nell'ambiente Python, utilizzando la libreria requests. Risolve il problema di automatizzare richieste HTTP che normalmente verrebbero eseguite dal terminale, consentendo il parsing dettagliato del comando curl per identificare metodo HTTP, intestazioni, autenticazione, corpo della richiesta e URL.

    In pratica, questa classe permette agli sviluppatori di prendere qualsiasi comando curl e:

    • ottenere i suoi componenti in forma strutturata (metodo, header, dati),
    • eseguire la richiesta HTTP direttamente tramite codice Python,
    • stampare le risposte in forma leggibile,
    • generare snippet Python equivalenti da riutilizzare.

    Questo è particolarmente utile in scenari di test di API, integrazione di sistemi o quando il comando curl viene generato da altri strumenti e deve essere usato in modo programmatico.

    #Flusso di Esecuzione

    1. Inizializzazione dell'oggetto: Si crea un'istanza della classe CurlCompiler, potendo definire il timeout e se la verifica SSL è attiva o meno.
    2. Compilare il comando curl: Passando il comando curl come stringa al metodo compile, questo verrà suddiviso in token per estrarre metodo HTTP, header, body, autenticazione e URL.
    3. Validazione della compilazione: Il comando viene validato per garantire che abbia URL e metodo HTTP validi.
    4. Esecuzione della richiesta: Usando il metodo execute, la classe compila il comando e invia la richiesta HTTP in base ai dati estratti.
    5. Gestire la risposta: La risposta HTTP ricevuta può essere convertita in dizionario per le manipolazioni tramite response_to_dict, stampata in forma formattata con pretty_print_response o ispezionata manualmente.
    6. Generazione di codice Python: È possibile generare uno snippet Python equivalente al comando curl con generate_python_code per il riutilizzo o la documentazione.

    #Tabella dei Metodi della Classe

    #Punti Importanti dell'Architettura e Insights

    • La classe usa il parsing lessicale tramite shlex per gestire correttamente stringhe e spazi nel comando curl.
    • Implementa un incapsulamento chiaro: parsing, esecuzione, manipolazione della risposta e generazione di codice sono separati in metodi.
    • La decisione di impostare automaticamente il metodo POST se è presente un body in un comando originariamente GET è una pratica comune e facilita l'uso.
    • Utilizza direttamente la libreria requests per l'esecuzione, garantendo compatibilità e robustezza.
    • Il metodo compile copre le opzioni principali di curl (metodo, header, auth di base, dati) ed è estensibile.
    • La generazione di codice Python permette di integrare rapidamente comandi curl esterni senza rielaborazione manuale.

    #Descrizione della Classe e dei Metodi

    #Classe CurlCompiler

    #Descrizione

    Classe che permette di interpretare comandi curl per eseguire richieste HTTP tramite Python, facilitando automazione, test e integrazione di API. Esegue il parsing completo del comando per recuperare metodo, URL, intestazioni, autenticazione e dati, ed eseguire la chiamata usando la libreria requests. Consente inoltre una facile manipolazione e visualizzazione della risposta.

    #Argomenti del Costruttore

    ArgomentoTipoDescrizioneValore Predefinito
    timeoutintTempo limite in secondi per le richieste HTTP30
    verify_sslboolDefinisce se viene eseguita la verifica del certificato SSLTrue

    #1. __init__

    Descrizione

    Inizializza l'oggetto CurlCompiler configurando il timeout per le richieste HTTP e se la verifica SSL deve essere eseguita.

    Argomenti

    • timeout (int): tempo massimo in secondi per la richiesta (default 30).
    • verify_ssl (bool): attiva/disattiva la verifica SSL (default True).

    Valori di ritorno

    • Non restituisce alcun valore.

    Raises

    • Non applicabile.

    Esempi

    client = CurlCompiler(timeout=10, verify_ssl=False)

    #2. compile

    Descrizione

    Riceve un comando curl (stringa), esegue il parsing completo per estrarre metodo HTTP, URL, header, autenticazione e corpo della richiesta. Restituisce un dizionario strutturato con queste informazioni pronte per l'uso.

    Argomenti

    • curl_command (str): stringa contenente il comando curl completo.

    Valori di ritorno

    • dict: dizionario contenente le chiavi method, url, headers, params, data, json, auth.

    Raises

    • ValueError: se il comando non inizia con "curl" o se non contiene URL/metodo HTTP validi.

    Esempi

    curl = 'curl -X POST https://api.exemplo.com -H "Content-Type: application/json" -d \'{"key":"value"}\''
compiled = client.compile(curl)
print(compiled['method'])  # "POST"
print(compiled['url'])     # "https://api.exemplo.com"
print(compiled['json'])    # {"key": "value"}

    #3. execute

    Descrizione

    Compila il comando curl ed esegue la richiesta HTTP restituendo l'oggetto requests.Response.

    Argomenti

    • curl_command (str): comando curl da eseguire.

    Valori di ritorno

    • requests.Response: risposta ricevuta dal server.

    Raises

    • Propaga le eccezioni della compilazione e dell'esecuzione HTTP (es: ValueError, requests exceptions).

    Esempi

    response = client.execute('curl -X GET https://httpbin.org/get')
print(response.status_code)  # 200
print(response.text)         # Conteúdo da resposta

    #4. call_endpoint

    Descrizione

    Esegue una chiamata HTTP diretta usando parametri espliciti (metodo, url, header, body, autenticazione).

    Argomenti

    • method (str): metodo HTTP ('GET', 'POST', ecc.)
    • url (str): URL dell'endpoint
    • headers (dict, opzionale): header HTTP
    • data (qualsiasi, opzionale): corpo della richiesta in formato raw/testo
    • json_data (qualsiasi, opzionale): corpo della richiesta in JSON serializzabile
    • auth (tuple, opzionale): coppia (username, password) per l'autenticazione di base

    Valori di ritorno

    • requests.Response: risposta della richiesta HTTP.

    Raises

    • Propaga le eccezioni di requests.

    Esempi

    resp = client.call_endpoint(
    method='POST',
    url='https://api.exemplo.com',
    headers={'Content-Type': 'application/json'},
    json_data={'msg': 'oi'}
)
print(resp.status_code)

    #5. response_to_dict

    Descrizione

    Converte l'oggetto requests.Response in un dizionario contenente status, header, corpo (JSON o testo) e flag di successo.

    Argomenti

    • response (requests.Response): oggetto di risposta HTTP.

    Valori di ritorno

    • dict: dizionario contenente le chiavi status_code, headers, body, success.

    Raises

    • Non applicabile.

    Esempi

    resp_dict = client.response_to_dict(response)
print(resp_dict['status_code'])  # Exemplo: 200
print(resp_dict['body'])         # Conteúdo da resposta

    #6. pretty_print_response

    Descrizione

    Stampa in forma formattata e leggibile i dettagli della risposta HTTP, inclusi status, header e corpo.

    Argomenti

    • response (requests.Response): risposta HTTP da stampare.

    Valori di ritorno

    • None

    Raises

    • Non applicabile.

    Esempi

    client.pretty_print_response(response)
# Status: 200
# Headers: { ... }
# Body: { ... }

    #7. get_domain

    Descrizione

    Estrae il dominio (host) da un URL completo.

    Argomenti

    • url (str): URL da cui estrarre il dominio.

    Valori di ritorno

    • str: dominio estratto, ad esempio "httpbin.org".

    Raises

    • Non applicabile.

    Esempi

    domain = client.get_domain("https://httpbin.org/post")
print(domain)  # httpbin.org

    #8. generate_python_code

    Descrizione

    Genera uno snippet di codice Python usando requests che implementa lo stesso comportamento del comando curl ricevuto.

    Argomenti

    • curl_command (str): comando curl da convertire.

    Valori di ritorno

    • str: codice Python formattato e indentato.

    Raises

    • Propaga gli errori della compilazione del comando curl.

    Esempi

    code = client.generate_python_code('curl -X POST https://api.exemplo.com -H "Content-Type: application/json" -d \'{"key":"value"}\'')
print(code)

    Esempio atteso dell'output:

    # =========================================================
# EXEMPLO DE USO
# =========================================================

if __name__ == "__main__":

    curl = '''
    curl -X POST "https://httpbin.org/post" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer TOKEN_123" \
    -d '{"message":"hello world","value":123}'
    '''

    curl = '''
    curl --location --request POST 'http://localhost:8000/embedding'
    '''

    client = CurlCompiler(timeout=15)

    # Compilar CURL
    compiled = client.compile(curl)

    print("\nCURL COMPILADO:")
    print(json.dumps(compiled, indent=4, ensure_ascii=False))

    # Executar
    response = client.execute(curl)

    # Mostrar resposta
    client.pretty_print_response(response)

    # Gerar código equivalente
    print("\nCÓDIGO PYTHON GERADO:\n")
    print(client.generate_python_code(curl))
