Database

    #Panoramica

    La classe Database agisce come una fabbrica di connessioni ai database, fornendo un'interfaccia unificata per connettersi sia a un database SQLite locale sia a un database Postgres ospitato su Supabase. Astrae i dettagli di configurazione e le scelte di implementazione, permettendo allo sviluppatore di selezionare il tipo di database passando semplici parametri, senza dover gestire configurazioni complesse.

    Questo design è utile quando si hanno ambienti diversi, come lo sviluppo locale e la produzione nel cloud, e si desidera un modo coerente ed elegante di inizializzare le connessioni a database diversi, mantenendo il resto dell'applicazione disaccoppiato dal livello di persistenza.

    #Flusso di Esecuzione

    1. Quando istanzi la classe Database, chiami il suo costruttore (in realtà usa il metodo __new__ personalizzato).
    2. Il parametro local decide se la connessione sarà con SQLite locale (local=True) o con Supabase Postgres (local=False).
    3. Se è locale, viene chiamato il metodo _local_database, che costruisce la connessione di tipo SqliteDb usando il file .db.
    4. Altrimenti, viene chiamato _supabase, che crea la connessione di tipo PostgresDb, costruendo l'URL del database usando le variabili d'ambiente o il parametro passato.
    5. I metodi statici ausiliari generano nomi di schema, percorsi o URL in base ai parametri e agli standard interni.
    6. Infine, viene restituito l'oggetto della rispettiva classe di database (SqliteDb o PostgresDb), pronto all'uso.

    #Tabella dei Metodi della Classe

    MetodoDescrizione
    __new__Controlla la creazione dell'oggetto, decide quale database usare
    _get_schema_nameRestituisce il nome dello schema per Postgres
    _get_database_local_storageCostruzione del percorso del file SQLite
    _get_database_urlGenera o restituisce l'URL del database Postgres
    _supabaseCrea e configura l'oggetto di connessione Postgres
    _local_databaseCrea e configura l'oggetto SQLite

    #Variabili d'Ambiente

    • SUPABASE_PROJECT_HOST: Host del progetto Supabase per la costruzione dell'URL di connessione.
    • SUPABASE_DATABASE_PASSWORD: Password del database Postgres di Supabase.

    #Punti Importanti dell'Architettura e Spunti

    • Usa il metodo magico __new__ per implementare il pattern Factory, restituendo diversi tipi di oggetti in base ai parametri.
    • L'incapsulamento garantisce che i dettagli specifici del database (URL, nomi delle tabelle) restino centralizzati, facilitando la manutenzione.
    • I metodi statici sono usati per la logica di composizione delle stringhe, separando le responsabilità.
    • La classe dipende dalle classi SqliteDb e PostgresDb, che rappresentano le connessioni effettive ai database.
    • Le variabili d'ambiente sono usate per tenere i dati sensibili fuori dal codice, seguendo le buone pratiche.
    • Permette l'iniezione di parametri per maggiore flessibilità (es: nome del database, URL personalizzato).

    #Descrizione della Classe e dei Metodi

    #Classe Database

    #Descrizione

    Classe fabbrica per facilitare la connessione a database SQLite locali o Supabase Postgres, astraendo la complessità di configurazione e connessione.

    #Argomenti del Costruttore

    ArgomentoTipoDescrizioneValore Predefinito
    localboolDefinisce se connettersi localmente (SQLite), altrimenti Supabase PostgresFalse
    database_namestr | NoneNome del database o dello schema, opzionaleNone
    database_urlstr | NoneURL completo per la connessione remota, opzionaleNone

    #Metodi

    #1. __new__

    #Descrizione

    Metodo speciale che controlla la creazione dell'istanza della classe. Decide, in base ai parametri, se creare un oggetto SqliteDb per il database locale o PostgresDb per Supabase.

    #Argomenti

    • local (bool): indica uso locale o remoto.
    • database_name (str | None): nome del database/schema.
    • database_url (str | None): URL del database remoto.

    #Valori di ritorno

    • SqliteDb o PostgresDb: oggetto configurato per interagire con il database corrispondente.

    #Raises

    Nessuna.

    #Esempi

    # Conecta a banco SQLite local padrão
db_local = Database(local=True)

# Conecta a banco Supabase com nome específico
db_supabase = Database(local=False, database_name="test_schema")

    #2. _get_schema_name

    #Descrizione

    Restituisce il nome dello schema per la connessione Postgres, usando il nome passato o il default "agent_db".

    #Argomenti

    • database_name (str | None): nome dello schema.

    #Valori di ritorno

    • str: nome dello schema da usare.

    #Raises

    Nessuna.

    #Esempi

    Database._get_schema_name("prod_schema")  # Retorna "prod_schema"
Database._get_schema_name(None)           # Retorna "agent_db"

    #3. _get_database_local_storage

    #Descrizione

    Costruisce il percorso del file .db per il database SQLite locale in base al nome fornito.

    #Argomenti

    • database_name (str | None): nome del file senza estensione.

    #Valori di ritorno

    • str: percorso completo del file SQLite.

    #Raises

    Nessuna.

    #Esempi

    Database._get_database_local_storage("testdb")  # "src/agents/database/testdb.db"
Database._get_database_local_storage(None)      # "src/agents/database/agno.db"

    #4. _get_database_url

    #Descrizione

    Restituisce l'URL di connessione per il database Postgres di Supabase. Usa l'URL passato, se fornito, oppure lo costruisce a partire dalle variabili d'ambiente.

    #Argomenti

    • database_url (str | None): URL completo opzionale.

    #Valori di ritorno

    • str: URL di connessione al database.

    #Raises

    Nessuna.

    #Esempi

    # Usando URL direta
Database._get_database_url("postgresql://user:pass@host:5432/db")

# Usando ENV-SUPABASE_PROJECT_HOST e SUPABASE_DATABASE_PASSWORD
Database._get_database_url(None)  # Exemplo: "postgresql://postgres:password@db.projecthost:5432/postgres"

    #5. _supabase

    #Descrizione

    Crea un'istanza di PostgresDb configurata per Supabase, con nome dello schema e URL definiti.

    #Argomenti

    • database_url (str | None): URL della connessione remota.
    • database_name (str | None): nome dello schema.

    #Valori di ritorno

    • PostgresDb: oggetto configurato per l'uso con Supabase.

    #Raises

    Nessuna.

    #Esempi

    db = Database._supabase(database_url=None, database_name="my_schema")
# db é uma instância de PostgresDb pronta para manipular o banco remoto

    #6. _local_database

    #Descrizione

    Crea un'istanza di SqliteDb configurata per l'uso locale, definendo il percorso del file .db e le tabelle.

    #Argomenti

    • database_name (str | None): nome del file del database locale.

    #Valori di ritorno

    • SqliteDb: oggetto configurato per il database SQLite locale.

    #Raises

    Nessuna.

    #Esempi

    db = Database._local_database(database_name="localdb")
# db é uma instância de SqliteDb pronta para manipulação local
