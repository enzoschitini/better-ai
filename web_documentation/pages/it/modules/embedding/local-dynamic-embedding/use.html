Embedding / Local Dynamic Embedding

Use

Modulo per generare embedding di testo in locale con una API fluente (concatenabile), cambio dinamico del provider e recupero per similarità.

In questa pagina

    Modulo per generare embedding di testo in locale con una API fluente (concatenabile), cambio dinamico del provider e recupero per similarità.

    Il flusso tipico è: configurare → elaborare il testo → accedere ai chunk → recuperare per similarità → esportare.

    #Come eseguire

    Il modulo usa import relativi (EmbeddingFactory), quindi deve essere eseguito come modulo, con il flag -m:

    python -m src.embedding.modules.local_embedding

    Eseguire direttamente il file (python arquivo.py) si rompe a causa dell'import relativo.

    #Avvio rapido

    from src.embedding.modules.local_embedding.module import (
    LocalDynamicEmbedding,
    EmbeddingFactory,
)

# Monta o pipeline (encadeando as configurações)
pipeline = (
    LocalDynamicEmbedding()
    .with_fake_embeddings(size=384)          # embeddings falsos p/ testes
    .with_splitter(chunk_size=120, chunk_overlap=20)
    .with_top_k(3)
)

# Processa um texto e recebe a quantidade de chunks gerados
qtd = pipeline.process_text("seu texto...", metadata={"fonte": "exemplo"})

# Recupera os trechos mais similares a uma consulta
resultados = pipeline.retrieve("sua pergunta?", include_embedding=True)

    #Provider disponibili

    EmbeddingFactory.available()   # -> lista os provedores registrados

    Usa questo metodo per scoprire quali backend di embedding sono installati/registrati nell'ambiente.

    #Costruire la pipeline (API fluente)

    Ogni metodo with_* restituisce la stessa istanza, permettendo la concatenazione. Se non definisci un provider di embedding, la classe ricade automaticamente su fake.

    MetodoEffettoParametri
    .with_fake_embeddings(size=384)Usa embedding finti (vettori di dimensione size) — ideale per test senza dipendenze esternesize: dimensione del vettore
    .with_splitter(chunk_size, chunk_overlap)Configura come il testo viene diviso in chunkchunk_size: dimensione del chunk; chunk_overlap: sovrapposizione tra i chunk
    .with_top_k(k)Definisce il numero predefinito di risultati restituiti nel recuperok: numero di risultati

    #Costruttori di fabbrica (cambio di provider in 1 riga)

    Per usare un provider reale esistono costruttori alternativi, per esempio:

    pipeline_openai = LocalDynamicEmbedding.from_openai_embeddings(
    model="text-embedding-3-large",
    chunk_size=3000,
    chunk_overlap=300,
    top_k=5,
)

    Richiede che le dipendenze del provider (es.: OpenAI) siano installate e configurate.

    #Elaborare il testo

    qtd = pipeline.process_text(texto, metadata={"fonte": "apostila_energia"})
    • Valore di ritorno: numero di chunk generati in questa chiamata (int).
    • metadata (opzionale): dizionario allegato a ogni chunk generato da questo testo.
    • Può essere chiamato più volte; i chunk si accumulano.
    pipeline.total_chunks   # total acumulado de chunks em todas as chamadas

    #Accedere ai chunk

    pipeline.chunks è la lista di oggetti chunk. Ogni chunk espone:

    AttributoDescrizione
    chunk.indexIndice del chunk
    chunk.contentTesto del chunk
    chunk.lengthLunghezza del testo
    chunk.dimDimensione del vettore di embedding
    chunk.metadataMetadati associati
    chunk.embeddingVettore di embedding (lista di float)

    Esempio:

    for chunk in pipeline.chunks:
    preview = chunk.content[:60].replace("\n", " ")
    print(f"[{chunk.index}] len={chunk.length} dim={chunk.dim} meta={chunk.metadata}")
    print(f"     texto: {preview}...")
    print(f"     embedding[:3]: {chunk.embedding[:3]}")

    #Recupero per similarità

    resultados = pipeline.retrieve("como gerar eletricidade a partir do vento?",
                               include_embedding=True)
    • Valore di ritorno: lista di dizionari ordinati per rilevanza. Ogni elemento contiene:
      • score — punteggio di similarità (float)
      • content — testo del brano recuperato
      • embedding — vettore del brano (solo se include_embedding=True)
    • Il numero di risultati segue il top_k configurato.
    for i, r in enumerate(pipeline.retrieve(consulta, include_embedding=True), 1):
    print(f"#{i} score={r['score']:.4f} | dim={len(r['embedding'])}")
    print(f"   {r['content'][:70]}...")

    #Esportare i chunk (pronti per JSON)

    dados = pipeline.get_chunks(include_embedding=False)
    • Valore di ritorno: lista di dizionari serializzabili (ideale per json.dumps).
    • Usa include_embedding=False per omettere i vettori e ottenere un output snello.
    import json
exemplo = pipeline.get_chunks(include_embedding=False)[0]
print(json.dumps(exemplo, ensure_ascii=False, indent=2))

    #Esempio completo

    from src.embedding.modules.local_embedding.module import (
    LocalDynamicEmbedding, EmbeddingFactory,
)
import json

print("Provedores disponíveis:", EmbeddingFactory.available())

texto = (
    "A energia solar é uma fonte renovável...\n\n"
    "A energia eólica aproveita a força dos ventos...\n\n"
    "Já os combustíveis fósseis são fontes não renováveis...\n\n"
    "O uso de baterias é essencial para armazenar energia..."
)

# 1) Configuração (sem embeddings -> usa fake automaticamente)
pipeline = (
    LocalDynamicEmbedding()
    .with_fake_embeddings(size=384)
    .with_splitter(chunk_size=120, chunk_overlap=20)
    .with_top_k(3)
)

# 2) Processamento
qtd = pipeline.process_text(texto, metadata={"fonte": "apostila_energia"})
print(f"Chunks gerados: {qtd} | total: {pipeline.total_chunks}")

# 3) Inspeção dos chunks
for chunk in pipeline.chunks:
    print(f"[{chunk.index}] dim={chunk.dim} meta={chunk.metadata}")

# 4) Recuperação
for i, r in enumerate(pipeline.retrieve("energia do vento?", include_embedding=True), 1):
    print(f"#{i} score={r['score']:.4f} -> {r['content'][:60]}...")

# 5) Exportação JSON
print(json.dumps(pipeline.get_chunks(include_embedding=False)[0],
                 ensure_ascii=False, indent=2))

    #Riferimento rapido dell'API

    EmbeddingFactory

    • EmbeddingFactory.available() → lista di provider

    LocalDynamicEmbedding

    • LocalDynamicEmbedding() → istanza vuota (fallback: fake)
    • .with_fake_embeddings(size=384) → self
    • .with_splitter(chunk_size, chunk_overlap) → self
    • .with_top_k(k) → self
    • .from_openai_embeddings(model, chunk_size, chunk_overlap, top_k) → nuova istanza (classmethod)
    • .process_text(texto, metadata=None) → int (chunk generati)
    • .total_chunks → int (cumulativo)
    • .chunks → lista di oggetti chunk (.index, .content, .length, .dim, .metadata, .embedding)
    • .retrieve(consulta, include_embedding=False) → lista di dict (score, content, [embedding])
    • .get_chunks(include_embedding=False) → lista di dict serializzabili

    #Osservazioni

    • Senza un provider configurato, la pipeline usa fake embeddings — perfetto per testare il flusso senza dipendere da API esterne.
    • Cambiare provider richiede una sola riga (tramite costruttore di fabbrica), senza modificare il resto del codice.
    • Esegui sempre come modulo (python -m ...) a causa degli import relativi.

    Questa documentazione descrive l'API pubblica osservabile a partire dal file di dimostrazione. I dettagli interni di implementazione (algoritmo di similarità, formato esatto dello splitter, provider registrati) dipendono dal codice sorgente del modulo. Se vuoi, inviami module.py e io integro con questi dettagli.
