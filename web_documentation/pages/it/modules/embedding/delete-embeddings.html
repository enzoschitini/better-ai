Delete Embeddings

La classe DeleteEmbeddings è stata sviluppata per gestire l'eliminazione degli embedding archiviati in un database vettoriale (vector database).

    #Panoramica

    La classe DeleteEmbeddings è stata sviluppata per gestire l'eliminazione degli embedding archiviati in un database vettoriale (vector database). Permette di rimuovere voci specifiche in base a chiavi e valori target forniti, garantendo un controllo preciso sui dati da eliminare. Questa classe è particolarmente utile nei sistemi che archiviano rappresentazioni vettoriali per le ricerche semantiche, dove mantenere la base aggiornata è fondamentale.

    Risolve il problema di ottimizzare la pulizia e la manutenzione dei dati vettoriali, rendendo possibile l'eliminazione selettiva in più namespace, incluso uno scope globale, con sicurezza e validazione dei target che possono essere interessati. In pratica, uno sviluppatore può usarla per cancellare dati relativi a specifiche basi di conoscenza, mantenendo l'integrità dei dati in altri contesti.

    #Flusso di Esecuzione

    1. Inizializzazione: La classe viene istanziata con le configurazioni del database vettoriale (opzionale). Se non viene passata alcuna configurazione, i valori predefiniti vengono caricati dalla configurazione generale.
    2. Validazione dei Target: Prima di qualsiasi eliminazione, le chiavi target (target keys) vengono validate per garantire che rientrino nei limiti consentiti, evitando eliminazioni fuori dall'ambito desiderato.
    3. Stabilire la Connessione: Viene creata la connessione con il database vettoriale, inizializzando i client necessari per eseguire le operazioni.
    4. Esecuzione dell'Eliminazione: Per ogni coppia chiave-valore target, esegue l'eliminazione nei namespace configurati (principale e, opzionalmente, globale), raccogliendo eventi che dettagliano i vettori eliminati.
    5. Aggregazione dei Risultati: Gli eventi vengono aggregati per namespace, sommando le quantità di vettori eliminati e preparando un riepilogo.
    6. Valore di Ritorno: Al termine, viene restituito un dizionario con l'esito dell'operazione, il totale dei vettori eliminati e i dettagli per namespace.

    #Variabili d'Ambiente

    Non ci sono variabili d'ambiente utilizzate direttamente da questa classe. Le configurazioni del database vettoriale vengono ottenute tramite l'oggetto di configurazione GetConfig.

    #Punti Importanti dell'Architettura e Insight

    • Design Modulare e Privato: La classe utilizza metodi privati per organizzare le fasi (validazione, connessione, eliminazione, aggregazione), garantendo coesione e chiarezza nel flusso.
    • Iniezione della Configurazione: Permette di sovrascrivere le configurazioni predefinite, facilitando l'uso in più ambienti e nei test.
    • Trace e Log: Integrazione con il sistema di tracing (ApplicationTracing) per la registrazione dettagliata delle azioni, utile per audit e debugging.
    • Gestione di Più Namespace: La classe supporta l'eliminazione in namespace distinti, incluso uno scope globale opzionale, il che indica flessibilità per scenari di archiviazione più complessi.
    • Gestione Robusta degli Errori: Le eccezioni vengono catturate e rilanciate con messaggi chiari, mantenendo il controllo del flusso e la trasparenza degli errori.
    • Uso di Classi Esterne: Dipende dalle classi GetConfig, VectorDBConnection e ApplicationTracing, il che indica integrazione con moduli di configurazione, accesso al database e sistema di log/tracing.

    #Descrizione della Classe e dei Metodi

    #Classe DeleteEmbeddings

    Descrizione

    Classe responsabile della gestione dell'eliminazione selettiva di embedding in un database vettoriale, con supporto per più namespace e rigorosa validazione delle chiavi target per garantire eliminazioni sicure e controllate.

    Argomenti del Costruttore

    ArgomentoTipoDescrizioneValore Predefinito
    vector_db_settingsdictConfigurazioni per la connessione al database vettoriale. Se non indicate, usa i valori predefiniti della configurazione globale.None

    #1. __init__

    Descrizione

    Inizializza l'istanza della classe definendo le configurazioni del database vettoriale a partire dai valori predefiniti e impostando le variabili interne per la connessione futura.

    Argomenti

    • vector_db_settings (dict): Configurazioni personalizzate per il database vettoriale.

    Valori di ritorno

    • Non restituisce alcun valore.

    Raises

    • Nessuno.

    Esempi

    # Instancia com configurações padrão
de = DeleteEmbeddings()

# Instancia com configuração personalizada
custom_settings = {"index_name": "my_index", "main_namespace": "app_main"}
de_custom = DeleteEmbeddings(vector_db_settings=custom_settings)

    #2. _get_vector_db

    Descrizione

    Stabilisce la connessione con il database vettoriale utilizzando le configurazioni correnti dell'istanza, impostando gli attributi interni di client e servizio per le operazioni future.

    Argomenti

    • Nessuno.

    Valori di ritorno

    • Non restituisce alcun valore.

    Raises

    • RuntimeError: se non è possibile stabilire la connessione con il database vettoriale.

    Esempi

    # Uso interno para garantir conexão antes das operações
delete_embeddings._get_vector_db()

    #3. _validate_targets

    Descrizione

    Verifica che le chiavi target per l'eliminazione rientrino tra le chiavi consentite per limitare l'ambito dell'operazione, generando un errore in caso contrario.

    Argomenti

    • target_keys (list): Lista dei nomi delle chiavi target da validare.
    • targets_to_limit (list o None): Lista delle chiavi consentite per l'eliminazione. Se None, non applica alcuna restrizione.

    Valori di ritorno

    • Non restituisce alcun valore.

    Raises

    • ValueError: se nessun valore di target_keys è contenuto in targets_to_limit.

    Esempi

    # Valida que "knowledge_base_id" está entre os alvos permitidos
_delete._validate_targets(["knowledge_base_id"], ["knowledge_base_id"])

# Levanta erro se sem correspondência
# _delete._validate_targets(["user_id"], ["knowledge_base_id"])  # ValueError

    #4. _delete_from_namespaces

    Descrizione

    Esegue l'eliminazione dei documenti che possiedono una chiave e un valore target nel namespace principale e, opzionalmente, nel namespace globale, restituendo eventi dettagliati.

    Argomenti

    • target_name (str): Nome della chiave target per l'eliminazione.
    • target_value (str): Valore associato per filtrare i documenti da eliminare.
    • main_ns (str): Namespace principale in cui verrà eseguita l'eliminazione.
    • global_ns (str): Namespace globale per l'eliminazione opzionale.
    • save_global (bool): Definisce se eliminare anche nel namespace globale.

    Valori di ritorno

    • list: Lista di eventi con i dettagli dell'eliminazione in ciascun namespace.

    Raises

    • Nessuno direttamente (le eccezioni interne verrebbero propagate).

    Esempi

    events = delete_embeddings._delete_from_namespaces(
    "knowledge_base_id", "kb_001", "main_ns", "global_ns", True
)
# events contém detalhes de vetores deletados em cada namespace

    #5. _aggregate_events

    Descrizione

    Aggrega una lista di eventi di eliminazione, sommando le quantità e organizzandole per namespace per facilitare l'analisi e la strutturazione del risultato.

    Argomenti

    • events (list): Lista dei singoli eventi di eliminazione.

    Valori di ritorno

    • list: Lista aggregata per namespace contenente totali ed elementi dettagliati.

    Raises

    • Nessuno.

    Esempi

    aggregated = delete_embeddings._aggregate_events(events)
# aggregated terá estrutura resumida por namespaces

    #6. delete

    Descrizione

    Metodo pubblico principale che orchestra l'intera operazione di eliminazione: valida i target, si connette al database, esegue le eliminazioni su tutte le coppie chiave-valore, aggrega e restituisce i risultati consolidati.

    Argomenti

    • target_keys (list): Lista dei nomi delle chiavi per l'eliminazione.
    • target_values (list): Lista dei valori corrispondenti per filtrare le eliminazioni.
    • targets_to_limit (list o None): Lista opzionale per restringere le chiavi utilizzabili per l'eliminazione.

    Valori di ritorno

    • dict: Dizionario contenente:
      • success (bool): Indica il successo dell'operazione.
      • summary (dict): Riepilogo con il totale dei vettori eliminati e il numero di namespace coinvolti.
      • deleted_by_namespace (list): Elenco dettagliato per namespace.

    Raises

    • ValueError: Se le chiavi target non sono consentite.
    • RuntimeError: Se la connessione o l'operazione sul database vettoriale fallisce.

        },
        "target_keys": ["knowledge_base_id"],
        "target_values": ["kb_12345"],
        "targets_to_limit": ["knowledge_base_id"]

    delete_embeddings = DeleteEmbeddings()
    result = delete_embeddings.delete(
        target_keys=payload["target_keys"],
        target_values=payload["target_values"],
        targets_to_limit=payload["targets_to_limit"]
    )

    print(json.dumps(result, indent=2))
