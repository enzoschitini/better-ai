Quickstart

Guida rapida per configurare l'ambiente, installare le dipendenze ed eseguire i servizi di BetterAI per la prima volta.

In questa pagina

    #1. Aggiorna il Progetto

    Per prima cosa, assicurati di essere sul branch corretto e che il tuo codice sia aggiornato:

    git checkout production
git pull
git checkout -b nome-da-sua-branch

    #2. Crea l'Ambiente Virtuale

    Requisito: Python 3.14 o superiore (versione fissata in .python-version).

    Crea un ambiente virtuale per isolare le dipendenze del progetto:

    python -m venv .venv

    #3. Attiva l'Ambiente Virtuale

    .\.venv\Scripts\Activate.ps1
    .venv\Scripts\activate.bat

    Dopo l'attivazione, il tuo terminale dovrebbe apparire così:

    (.venv) PS C:\Users\nome_do_usuario\better-ai>

    #4. Installa le Dipendenze

    Puoi installare le dipendenze in due modi:

    #Usando uv (consigliato)

    uv sync

    #5. Configura le Variabili d'Ambiente

    Crea un file .env nella radice del progetto con le seguenti variabili:

    VariabileDescrizione
    BETTERAI_API_KEYChiave API interna di BetterAI
    OPENAI_API_KEYChiave API di OpenAI
    OPENAI_EMBEDDING_MODELModello di embeddings di OpenAI utilizzato
    GEMINI_API_KEYChiave API di Google Gemini
    GROQ_API_KEYChiave API di Groq
    ANTHROPIC_API_KEYChiave API di Anthropic (Claude)
    TAVILY_API_KEYChiave API di Tavily (ricerca web)
    FAL_API_KEYChiave API di Fal (generazione di media)
    EXCHANGE_RATE_API_KEYChiave API per le quotazioni di cambio
    HUGGINGFACEHUB_API_TOKENToken di accesso a Hugging Face Hub
    PINECONE_API_KEYChiave API di Pinecone (base vettoriale)
    PINECONE_ENVIRONMENTRegione/ambiente di Pinecone
    PINECONE_INDEX_NAMENome dell'indice vettoriale in Pinecone
    PINECONE_NAMESPACENamespace della knowledge base
    PINECONE_GLOBAL_NAMESPACENamespace globale della knowledge base
    MONGO_URIStringa di connessione completa di MongoDB
    MONGO_USERUtente di MongoDB
    MONGO_PASSWORDPassword di MongoDB
    MONGO_HOSTHost di MongoDB
    MONGO_PORTPorta di MongoDB
    NOSQL_BACKENDBackend NoSQL utilizzato (local o remoto)
    SUPABASE_URLURL del progetto Supabase
    SUPABASE_SECRET_KEYChiave segreta di servizio di Supabase
    SUPABASE_DATABASE_URLStringa di connessione del database Postgres di Supabase
    SUPABASE_PROJECT_NAMENome del progetto Supabase
    SUPABASE_PROJECT_HOSTHost del progetto Supabase
    SUPABASE_DATABASE_PASSWORDPassword del database Supabase
    SHOW_INFO_LOGSMostra i log informativi (true/false)
    SHOW_METADATAMostra i metadati nelle risposte (true/false)
    FORMAT_METADATAFormatta i metadati mostrati (true/false)
    SAVE_LOGSSalva i log di esecuzione (true/false)
    SAVE_MONGOSalva i dati di esecuzione in MongoDB (true/false)
    LOCALFlag per l'esecuzione locale (true/false)

    #6. Esegui l'applicazione

    Il progetto espone due servizi indipendenti, che possono essere eseguiti separatamente o in parallelo (in terminali distinti):

    ServizioComandoPortaQuando usarlo
    API (FastAPI)uvicorn web_services:app --reload8000Consumo programmatico dei moduli di IA via HTTP
    Interfaccia (Streamlit)streamlit run web_app.py8501Uso visuale delle applicazioni (Acquarello, Content Generator)

    Prerequisiti: ambiente virtuale attivato (passo 3), dipendenze installate (passo 4) e file .env configurato (passo 5).

    #6.1. API (FastAPI + Uvicorn)

    uvicorn web_services:app --reload

    Convalida l'avvio

    Conferma che l'API abbia risposto correttamente prima di proseguire:

    curl -X GET "http://127.0.0.1:8000/health"

    Endpoint principali

    EndpointDescrizione
    GET /healthVerifica della disponibilità del servizio
    GET /health-authorizationVerifica della disponibilità con autenticazione
    POST /deep-research/context-builderCostruzione del contesto a partire da una ricerca approfondita

    Ogni risposta segue un formato standardizzato con job_id, status, result e metriche del tempo di esecuzione. I parametri e gli esempi completi di request/response si trovano in Web Service Network - API.ipynb.

    #6.2. Interfaccia Streamlit

    streamlit run web_app.py

    L'applicazione sarà disponibile su http://localhost:8501, con le seguenti pagine:

    ApplicazioneURLDocumentazione
    Acquarellohttp://localhost:8501/acquarelloAcquarello.ipynb
    Content Generatorhttp://localhost:8501/content_generatorContent Generator.ipynb

    #6.3. Risoluzione dei problemi

    SintomoCausa probabileCosa fare
    ModuleNotFoundError all'avvioAmbiente virtuale non attivato o dipendenze mancantiRiattiva il .venv (passo 3) ed esegui uv sync (passo 4)
    Errore di autenticazione nei provider di IAChiavi mancanti o non valide nel .envRivedi il passo 5 e conferma i valori delle chiavi
    Errore di connessione a MongoDB/Supabase/PineconeCredenziali o host errati nel .envVerifica le variabili del database e la connettività di rete
    Porta già in usoUn'altra istanza del servizio è attivaTermina il processo precedente o usa un'altra porta (--port)

    Se l'ambiente virtuale diventa inconsistente, ricrealo da zero:

    deactivate
Remove-Item -Recurse -Force .\.venv
python -m venv .venv
