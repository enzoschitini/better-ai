Dependences

Questo progetto utilizza un solido insieme di librerie per la costruzione di API, l'orchestrazione di agenti di IA, l'elaborazione dei dati, l'archiviazione e l'integrazione con servizi esterni.

In questa pagina

    Le dipendenze sono organizzate per responsabilità per facilitare manutenzione, scalabilità e comprensione dell'architettura.

    Progetto: better-ai · Versione: 0.1.0 · Python richiesto: >=3.12

    Fonte di verità: pyproject.toml. Installazione consigliata con uv sync (oppure uv pip install -e .).

    #1. Core & API Infrastructure

    Responsabili della struttura dell'applicazione backend e della comunicazione HTTP.

    LibreriaVersioneDescrizione
    dotenv~0.9.9Gestione delle variabili d'ambiente tramite .env
    fastapi~0.120.4Framework moderno per creare API veloci in Python
    uvicorn~0.23.2Server ASGI per eseguire applicazioni FastAPI
    python-multipart~0.0.20Supporto al caricamento di file nelle API
    requests~2.32.5Client HTTP per consumare API esterne

    #Convenzioni di versionamento

    OperatoreSignificatoEsempio
    ~=X.Y.ZConsente aggiornamenti di patch, fissa major e minor~=0.3.27 → >=0.3.27, <0.4.0
    >=X.Y.ZAccetta qualsiasi versione uguale o superiore>=1.56.0

    Le librerie con ~= sono quelle che incidono direttamente sul comportamento degli agenti e delle pipeline RAG — mantenerle fissate per minor evita rotture silenziose delle API. Quelle contrassegnate con >= sono periferiche o abbastanza stabili da seguire le versioni più recenti.
