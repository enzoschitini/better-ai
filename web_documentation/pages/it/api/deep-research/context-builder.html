    #Context Builder - /deep-research/context-builder

    POST/deep-research/context-builder

    Costruisce un contesto ricco in markdown a partire da una ricerca approfondita sul web, usando TavilyDeepResearch come motore di ricerca. Ideale per alimentare pipeline RAG, generazione di report o arricchimento dei prompt.

    #Parametri

    ParametroTipoDescrizioneEsempio
    querystringDomanda o tema centrale della ricerca. Definisce cosa verrà cercato."Principais tendências de IA em 2026?"
    search_depth"basic" | "advanced"Profondità della ricerca. basic per una visione rapida, advanced per una ricerca più ampia e dettagliata."advanced"
    max_resultsinteger (1–100)Numero massimo di risultati da recuperare e includere nel contesto.35
    topicstringCategoria o dominio della ricerca. Orienta il tipo di fonte privilegiata. Valori comuni: general, news, finance."news"
    include_answerbooleanSe true, include nel contesto una risposta generata automaticamente in base ai risultati trovati.true
    min_scorefloat (0.0–1.0)Punteggio minimo di rilevanza. I risultati al di sotto di questa soglia vengono scartati. Valori più alti = contesto più preciso, ma più piccolo.0.5

    #Request

    curl --location 'http://localhost:8000/deep-research/context-builder' \
--header 'Content-Type: application/json' \
--header 'X-API-Key: ******' \
--data '{
    "query": "Principais tendências de IA em 2026?",
    "search_depth": "advanced",
    "max_results": 35,
    "topic": "general",
    "include_answer": true,
    "min_score": 0.5
}'
