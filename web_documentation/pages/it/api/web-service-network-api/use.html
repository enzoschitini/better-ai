Web Service Network - API

Use

La BetterAI Web Service Network è un'API modulare ad alte prestazioni progettata per orchestrare servizi di intelligenza artificiale in produzione.

In questa pagina

    La BetterAI Web Service Network è un'API modulare ad alte prestazioni progettata per orchestrare servizi di intelligenza artificiale in produzione. Espone un insieme di router specializzati — ricerca approfondita sul web, parsing di documenti, generazione di immagini e gestione di vector store — tutti accessibili via HTTP con autenticazione tramite chiave API.

    L'API è costruita su FastAPI ed eseguita con Uvicorn, offrendo documentazione interattiva automatica tramite Swagger UI (/docs) e supporto nativo per le richieste asincrone. Ogni endpoint restituisce risposte standardizzate con job_id, status, payload (result o content) e metriche dei tempi di esecuzione, facilitando la tracciabilità e l'integrazione con le pipeline di dati.

    Base URL: http://localhost:8000
    Autenticazione: X-API-Key nell'header di tutte le rotte protette
    Versione attuale: 1.0.0
