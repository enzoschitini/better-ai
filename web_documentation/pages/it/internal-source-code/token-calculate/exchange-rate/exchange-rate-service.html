Exchange Rate Service

La classe ExchangeRateService è responsabile della gestione dei cambi del dollaro statunitense, combinando l'ottenimento di dati aggiornati dall'API della Banca Centrale del Brasile (BCB) con l'archiviazione locale di tali record per consultazioni future.

    #Panoramica

    La classe ExchangeRateService è responsabile della gestione dei cambi del dollaro statunitense, combinando l'ottenimento di dati aggiornati dall'API della Banca Centrale del Brasile (BCB) con l'archiviazione locale di tali record per consultazioni future. Mantiene uno storico limitato delle quotazioni per ottimizzare il database locale, evitando l'archiviazione eccessiva di dati vecchi.

    Questo servizio è utile per le applicazioni che hanno bisogno del cambio del dollaro aggiornato, ma devono anche garantire un accesso rapido ai dati recenti anche nei momenti in cui l'API esterna non funziona. Archiviando localmente e limitando i dati conservati, la classe offre una soluzione efficiente e resiliente per i sistemi che dipendono da questa informazione.

    In pratica, la classe può essere usata per ottenere il cambio del dollaro in tempo reale, con fallback automatico sull'ultimo valore disponibile e persistenza del dato per consultazioni future.

    #Flusso di Esecuzione

    1. Si istanzia un oggetto della classe ExchangeRateService.
    2. Si chiama il metodo get_usd_rate() per ottenere il cambio del dollaro.
    3. Il metodo verifica se esiste già un record della quotazione del giorno nel database locale.
    4. Se il record del giorno è già disponibile, restituisce quel valore direttamente dal database.
    5. In caso contrario, consulta la quotazione più recente sull'API del BCB.
    6. Se l'API restituisce un valore valido:
      • Il valore viene memorizzato nel database locale.
      • Viene applicata una regola per limitare il numero di record salvati (mantenendo fino a 5 record).
      • Il valore viene restituito.
    7. Se l'API fallisce e ci sono dati precedenti nel database, viene restituito l'ultimo valore memorizzato.
    8. Se non ci sono dati, viene restituito un valore base di default e questa base viene memorizzata localmente.
    9. Il database locale viene sempre mantenuto con al massimo 5 record, rimuovendo i più vecchi quando necessario.
    10. In caso di errore durante il processo, viene sollevato un RuntimeError.

    MetodoDescrizione
    __init__Inizializza il servizio, configura database locale e date.
    _get_bcb_rateCerca la quotazione più recente del dollaro sull'API del BCB.
    _get_last_db_recordOttiene l'ultimo record memorizzato localmente.
    _enforce_limitLimita il numero di record salvati, eliminando i più vecchi.
    get_usd_rateOttiene il cambio del dollaro con fallback e persistenza.

    #Punti Importanti dell'Architettura e Insights

    • Design basato su un fallback robusto: Il metodo get_usd_rate cerca di dare priorità ai dati aggiornati, ma gestisce con eleganza i guasti dell'API esterna usando dati locali o una base predefinita.
    • Incapsulamento: L'uso di metodi privati (_get_bcb_rate, _get_last_db_record, _enforce_limit) separa le responsabilità all'interno della classe, mantenendo pulita l'interfaccia per l'utente.
    • Limitazione dello storico: Mantenere un limite massimo di record evita la crescita incontrollata del database locale, il che è importante per prestazioni e spazio.
    • Integrazione con altre classi: La classe utilizza DocumentStore per la persistenza locale e BCBExchangeRateService per l'integrazione con l'API esterna dei cambi, dimostrando composizione e separazione delle responsabilità.
    • Uso del formato data standardizzato: Le date vengono sempre memorizzate e confrontate nel formato ISO %Y-%m-%d, garantendo coerenza.
    • Gestione delle eccezioni: Gli errori generici vengono catturati e incapsulati in un RuntimeError per segnalare errori specifici di questo servizio.

    #Descrizione della Classe e dei Metodi

    #Classe ExchangeRateService

    #Descrizione

    Classe per gestire i cambi del dollaro statunitense. Cerca le quotazioni sull'API della Banca Centrale del Brasile, memorizza le informazioni localmente, mantiene uno storico limitato dei dati e offre accesso alla quotazione attuale con meccanismi di fallback per garantire la continuità del servizio anche in caso di guasti esterni.

    #Metodi

    #1. __init__

    Descrizione

    Inizializza l'istanza del servizio, configurando il gestore del database locale, definendo una base predefinita di quotazione e memorizzando la data attuale formattata.

    Argomenti

    Nessuno.

    Valori di ritorno

    Non restituisce alcun valore.

    Raises

    Nessuna.

    Esempi

    service = ExchangeRateService()

    #2. _get_bcb_rate

    Descrizione

    Recupera la quotazione più recente del dollaro sull'API della Banca Centrale del Brasile utilizzando il servizio BCBExchangeRateService.

    Argomenti

    Nessuno.

    Valori di ritorno

    • float: Valore della quotazione più recente del dollaro ottenuta dall'API.

    Raises

    Nessuna (si assume che gli errori siano gestiti esternamente).

    Esempi

    rate = service._get_bcb_rate()
print(rate)  # Exemplo esperado: 5.25

    #3. _get_last_db_record

    Descrizione

    Cerca nel database locale il record più recente della quotazione del dollaro. Restituisce il record con la data maggiore, oppure None se non ci sono record.

    Argomenti

    Nessuno.

    Valori di ritorno

    • dict o None: Dizionario con il record più recente oppure None se il database è vuoto.

    Raises

    Nessuna.

    Esempi

    last_record = service._get_last_db_record()
if last_record:
    print(last_record["rate"])
else:
    print("Nenhum registro encontrado.")

    #4. _enforce_limit

    Descrizione

    Limita il numero massimo di record salvati nel database locale al valore specificato, rimuovendo i record più vecchi se il limite viene superato.

    Argomenti

    • limit (int): Numero massimo di record consentiti nel database. Il valore predefinito è 5.

    Valori di ritorno

    Non restituisce alcun valore.

    Raises

    Nessuna.

    Esempi

    service._enforce_limit(limit=5)
# Garante que no banco existam no máximo 5 registros recentes.

    #5. get_usd_rate

    Descrizione

    Ottiene il cambio attuale del dollaro statunitense. Verifica prima se la quotazione del giorno è già salvata nel database locale; in caso contrario, tenta di cercarla sull'API del BCB. Se l'API restituisce dati, li salva localmente limitando lo storico. Se l'API fallisce, restituisce l'ultimo valore salvato o un valore base predefinito. Gestisce gli errori generici sollevando RuntimeError.

    Argomenti

    Nessuno.

    Valori di ritorno

    • float: Quotazione attuale pronta all'uso.

    Raises

    • RuntimeError: Nel caso di un errore generale nell'ottenimento o nell'archiviazione della quotazione.

    Esempi

    try:
    rate = service.get_usd_rate()
    print(f"Cotação do dólar: {rate}")
except RuntimeError:
    print("Não foi possível obter a cotação.")
