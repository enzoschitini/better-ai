Token Counter

La classe TokenCounter ha come obiettivo principale calcolare la quantità di token presenti in un testo, utilizzando codificatori basati sui modelli di linguaggio di OpenAI.

    #Panoramica

    La classe TokenCounter ha come obiettivo principale calcolare la quantità di token presenti in un testo, utilizzando codificatori basati sui modelli di linguaggio di OpenAI. Questo è particolarmente utile per chi lavora con API che hanno limiti basati sulla quantità di token, come GPT-3 e GPT-4, permettendo di gestire meglio il costo e la dimensione delle richieste.

    Risolve il problema di avere bisogno di un conteggio preciso dei token per gli input di testo, qualcosa di cruciale per i limiti e le ottimizzazioni nelle applicazioni NLP che dipendono dai modelli OpenAI. In pratica, puoi usare questa classe per, ad esempio, verificare se un testo rientra nel limite massimo di token consentito dal modello prima di inviare una richiesta.

    #Flusso di Esecuzione

    1. Istanzia la classe TokenCounter, passando il nome del modello che vuoi usare per la codifica dei token (es.: "gpt-3.5-turbo"). Questo definisce lo standard di tokenizzazione adatto al modello.
    2. Se il nome del modello non viene riconosciuto, la classe usa automaticamente una codifica base predefinita (cl100k_base).
    3. Chiama il metodo count, passando il testo che vuoi conteggiare.
    4. Il metodo restituisce un numero intero che rappresenta la quantità di token nel testo.

    MetodoDescrizione

    #Variabili d'Ambiente

    Non ci sono variabili d'ambiente utilizzate dalla classe.

    #Punti Importanti dell'Architettura e Insights

    • La classe utilizza la libreria tiktoken, specifica per la tokenizzazione dei modelli OpenAI, garantendo alta compatibilità e precisione.
    • La scelta della codifica è dinamica, basata sul nome del modello indicato. Se il modello non è noto, viene usato uno standard sicuro per evitare errori.
    • Incapsula il funzionamento interno del codificatore, offrendo un'interfaccia semplice per contare i token, facilitando l'integrazione in progetti più grandi.
    • La classe non dipende da altre classi oltre al modulo esterno tiktoken.
    • Il suo design è minimalista, focalizzato su un unico scopo, seguendo il principio di responsabilità unica.

    #Descrizione della Classe e dei Metodi

    #Classe TokenCounter

    #Descrizione

    Classe responsabile del conteggio della quantità di token nei testi, utilizzando i codificatori della libreria tiktoken, che riproducono il modo in cui i modelli OpenAI interpretano e segmentano le parole in token.

    #Argomenti del Costruttore

    ArgomentoTipoDescrizioneValore Predefinito
    modelstrNome del modello OpenAI per definire la codifica dei token (es.: "gpt-3.5-turbo").Nessuno

    #Metodi

    #1. __init__

    Descrizione

    Inizializza un codificatore di token basato sul modello specificato. Se il modello non viene riconosciuto, usa una codifica predefinita.

    Argomenti

    • model (str): nome del modello per definire la codifica

    Valori di ritorno

    • Non restituisce alcun valore.

    Raises

    • Nessuna in modo esplicito, ma ignora KeyError durante la ricerca del codificatore per il modello.

    Esempi

    counter = TokenCounter("gpt-3.5-turbo")

    #2. count

    Descrizione

    Conta quanti token contiene il testo fornito, convertendo il testo con il codificatore associato al modello.

    Argomenti

    • text (str): Testo di cui verrà calcolata la quantità di token.

    Valori di ritorno

    • int: numero totale di token trovati nel testo. Restituisce 0 se il testo è vuoto o None.

    Raises

    • Nessuna.

    Esempi

    counter = TokenCounter("gpt-3.5-turbo")
num_tokens = counter.count("Hello, how are you?")
print(num_tokens)  # Saída provável: 6

# python -m src.tokens_calculate.token_counter

    Questo esempio mostra il conteggio approssimativo dei token per la frase "Hello, how are you?", che in generale contiene 6 token secondo la tokenizzazione del modello indicato.
