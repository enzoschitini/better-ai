Storage Menage Repository

Questa è la documentazione didattica per la classe StorageRepository, un componente essenziale per la gestione ibrida dei file nella tua applicazione.

In questa pagina

    #1. Panoramica

    La classe StorageRepository agisce come un livello di astrazione (o Repository) per l'archiviazione delle immagini. Il suo obiettivo principale è unificare due mondi: l'archiviazione locale (disco rigido del server) e l'archiviazione in cloud (Supabase Storage).

    Utilizzando questa classe, il resto del tuo codice non deve preoccuparsi di dettagli tecnici come la manipolazione dei percorsi dei file o i protocolli di rete; si limita a richiedere che un'immagine venga salvata, e il repository decide come e dove farlo.

    #2. Flusso di Esecuzione

    Il ciclo di vita di una normale operazione in questa classe segue questi passi:

    1. Configurazione: L'oggetto viene creato ricevendo un base_path (dove salvare in locale) e un bucket_name (dove salvare nel cloud).
    2. Preparazione dei Dati: Alla ricezione di una lista di oggetti GeneratedImage, la classe estrae i byte e identifica il formato (MIME type).
    3. Persistenza Locale: Se viene chiamato il metodo local_repository, la classe genera nomi univoci basati sulla data e sull'ora correnti per evitare conflitti tra file e scrive i byte su disco.
    4. Sincronizzazione Remota: Se viene chiamato il metodo upload_to_supabase, la classe utilizza internamente lo StorageManager per inviare i dati al cloud e recupera immediatamente il link pubblico di accesso.

    #4. Architettura e Insight

    • Pattern Repository: Questa classe isola la logica di infrastruttura. Se domani decidi di sostituire Supabase con Amazon S3, dovrai modificare solo questo file, senza rompere il resto del sistema.
    • Generazione di Nomi Univoci: L'uso di datetime.utcnow() nel salvataggio locale garantisce che, anche se due immagini vengono generate in sequenza, abbiano nomi distinti, evitando la sovrapposizione accidentale dei dati.
    • Gestione delle Estensioni: Il metodo _mime_to_extension agisce come un guardiano dell'integrità, garantendo che vengano elaborati solo i tipi di immagine supportati (JPEG e PNG), evitando file corrotti o sconosciuti.

    #5. Dettaglio della Classe

    #Classe StorageRepository

    Descrizione

    Gestisce la persistenza delle immagini in modo ibrido. Permette che le immagini generate dall'applicazione vengano archiviate sia in directory locali sia nel servizio Storage di Supabase, standardizzando l'accesso ai file.

    Argomenti

    • base_path (str): Directory base locale o prefisso di cartella nello storage remoto.
    • bucket_name (str): Nome del bucket configurato nella console di Supabase.

    #Metodi

    #1. local_repository

    Descrizione

    Itera su una lista di immagini, genera nomi di file basati su un marcatore di data/ora (timestamp) e le salva sul disco locale.

    Argomenti

    • images (List[GeneratedImage]): Lista di oggetti contenenti i byte e il MIME type.
    • prefix (str): Nome iniziale del file (es: "avatar", "post"). Il default è "image".

    Valori di ritorno

    • List[str]: Una lista contenente il percorso completo (path) di ogni file salvato con successo.

    Raises

    • ValueError: Se un'immagine possiede un MIME type non mappato.
    • IOError: In caso di errore di permessi o di spazio su disco durante la scrittura.

    Esempi

    repo = StorageRepository(base_path="./data/exports")
paths = repo.local_repository(lista_de_imagens, prefix="geracao_ia")
# Retorno: ["./data/exports/geracao_ia_20240101_120000_1.jpg", ...]

    #2. upload_to_supabase

    Descrizione

    Fa da ponte tra l'applicazione e Supabase. Invia i byte grezzi al bucket e restituisce il link diretto per la visualizzazione.

    Argomenti

    • file_name (str): Nome che il file avrà all'interno del bucket.
    • byte_data (bytes): Il contenuto binario dell'immagine.

    Valori di ritorno

    • str: L'URL pubblico (HTTP) per accedere al file nel cloud.

    Raises

    • ConnectionError: In caso di errore di rete o delle credenziali di Supabase.
    • ValueError: Se i parametri del nome del file non sono validi.

    Esempi

    repo = StorageRepository(base_path="galeria", bucket_name="bucket_oficial")
url_publica = repo.upload_to_supabase("foto_perfil.png", dados_em_bytes)
print(url_publica)
Saída: https://projeto.supabase.co/storage/v1/object/public/bucket_oficial/galeria/foto_perfil.png

    #3. _mime_to_extension

    Descrizione

    Metodo interno di supporto che traduce il tipo MIME dell'immagine in un'estensione di file adatta al sistema operativo.

    Argomenti

    • mime_type (str): Il tipo MIME (es: "image/jpeg").

    Valori di ritorno

    • str: L'estensione breve (es: "jpg" o "png").

    Raises

    • ValueError: Se il MIME type non è "image/jpeg" o "image/png".
