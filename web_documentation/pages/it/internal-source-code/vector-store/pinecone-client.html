Pinecone Client

La classe PineconeClient è un'astrazione per gestire la connessione e le operazioni con il servizio Pinecone, una soluzione di archiviazione e ricerca vettoriale ad alte prestazioni.

In questa pagina

    #Panoramica

    La classe PineconeClient è un'astrazione per gestire la connessione e le operazioni con il servizio Pinecone, una soluzione di archiviazione e ricerca vettoriale ad alte prestazioni. Facilita l'integrazione con API esterne (Pinecone e OpenAI), occupandosi della configurazione delle chiavi API, della definizione dei namespace e dell'inizializzazione del modello di embedding per lavorare con vettori di testo.

    Questa classe risolve il problema della configurazione manuale e ripetitiva di queste integrazioni, fornendo un'interfaccia unificata e sicura per creare e manipolare vector store usando namespace personalizzati e modelli di embedding specifici. In pratica, può essere usata per archiviare e cercare vettori generati a partire da testi, fondamentale per sistemi come la ricerca semantica, la raccomandazione basata sulla similarità e l'NLP.

    #Flusso di Esecuzione

    1. Inizializzazione del Client:
      • Alla creazione di un'istanza di PineconeClient, le chiavi API di OpenAI e Pinecone vengono caricate dalle variabili d'ambiente.
      • Vengono definiti index_name, main_namespace e global_namespace sia tramite i parametri del costruttore sia tramite variabili d'ambiente o configurazione predefinita.
      • Il modello di embedding da usare viene selezionato allo stesso modo.
      • Inizializza internamente la connessione con Pinecone e il modello di embedding OpenAI.
    2. Configurazione delle Connessioni:
      • _init_pinecone crea il client Pinecone e istanzia l'index specificato.
      • _init_embeddings inizializza il modello di embedding OpenAI in base alla configurazione.
    3. Risoluzione del Namespace:
      • Il metodo get_namespace() restituisce il namespace da usare nelle operazioni, dando priorità a un valore passato al metodo, se fornito, oppure al namespace principale dell'istanza.
    4. Creazione della Vector Store:
      • create_vector_store() costruisce l'istanza di PineconeVectorStore, associando l'index e il modello di embedding appropriati al namespace desiderato.
      • L'oggetto restituito permette di eseguire operazioni di similarità vettoriale.

    #Variabili d'Ambiente

    • OPENAI_API_KEY: Chiave API OpenAI per la generazione degli embedding.
    • PINECONE_API_KEY: Chiave API Pinecone per l'accesso al servizio.
    • PINECONE_INDEX_NAME: Nome dell'indice Pinecone da utilizzare.
    • PINECONE_NAMESPACE: Namespace principale predefinito per archiviare i vettori.
    • PINECONE_GLOBAL_NAMESPACE: Namespace globale opzionale per vettori condivisi.
    • OPENAI_EMBEDDING_MODEL: Nome del modello di embedding OpenAI da usare.

    #Punti Importanti dell'Architettura e Insight

    • La classe usa l'incapsulamento per nascondere i dettagli di inizializzazione di Pinecone e del modello di embedding.
    • L'uso di variabili d'ambiente con fallback sui parametri del costruttore aumenta flessibilità e riuso.
    • Il pattern di "dependency injection" è presente nella creazione della vector store, permettendo di sovrascrivere embedding e namespace nella chiamata.
    • Integrazione con moduli esterni specializzati (langchain_openai, langchain_pinecone), a dimostrazione dell'uso della composizione.
    • La classe utilizza un sistema di tracing personalizzato (ApplicationTracing) per facilitare debug e monitoraggio, generando log dettagliati in ogni fase.
    • Netta separazione tra configurazione, inizializzazione e creazione della vector store, a favore di manutenzione e test.

    #Descrizione della Classe e dei Metodi

    #Classe PineconeClient

    Descrizione

    Classe per il controllo e la facilitazione della connessione con il servizio Pinecone e per la gestione dei vettori archiviati. Integra le API di Pinecone e OpenAI per creare una base vettoriale personalizzata, che può essere interrogata o aggiornata a partire dai modelli di embedding forniti. Permette di configurare namespace e modelli in modo flessibile, semplificando le operazioni vettoriali nelle applicazioni.

    Argomenti del Costruttore

    ArgomentoTipoDescrizioneValore Predefinito
    index_nameOptional[str]Nome dell'indice Pinecone da utilizzareNone
    main_namespaceOptional[str]Namespace primario per archiviare i vettoriNone
    global_namespaceOptional[str]Namespace globale opzionale per vettori condivisiNone
    embedding_modelOptional[str]Nome del modello OpenAI per gli embeddingNone

    #1. __init__

    Descrizione

    Inizializza il client Pinecone caricando le chiavi API e le configurazioni, definendo i namespace e il modello di embedding, oltre a stabilire le connessioni.

    Argomenti

    • index_name (Optional[str]): nome dell'indice Pinecone (opzionale)
    • main_namespace (Optional[str]): namespace primario (opzionale)
    • global_namespace (Optional[str]): namespace globale (opzionale)
    • embedding_model (Optional[str]): nome del modello OpenAI (opzionale)

    Valori di ritorno

    • Non restituisce alcun valore.

    Raises

    • EnvironmentError: se le chiavi API non sono definite.
    • ValueError: se index_name non è definito.
    • RuntimeError: per errori generici di inizializzazione.

    Esempi

    client = PineconeClient(index_name="meu_indice", main_namespace="app_namespace")

    #2. _init_pinecone

    Descrizione

    Stabilisce la connessione con il servizio Pinecone e istanzia l'indice con il nome configurato.

    Argomenti

    • Nessuno.

    Valori di ritorno

    • Non restituisce alcun valore.

    Esempi

    client._init_pinecone()
# Internamente conecta ao Pinecone e configura o index para operações

    #3. _init_embeddings

    Descrizione

    Inizializza il modello OpenAI per la generazione degli embedding, potendo usare un nome di modello personalizzato.

    Argomenti

    • model_name (Optional[str]): nome del modello di embedding (opzionale)

    Valori di ritorno

    • Non restituisce alcun valore.

    Esempi

    client._init_embeddings("text-embedding-ada-002")
# Atualiza o modelo de embedding usado pelo cliente

    #4. get_namespace

    Descrizione

    Restituisce il namespace da usare per le operazioni, dando priorità all'argomento passato, oppure restituendo quello principale configurato.

    Argomenti

    • namespace (Optional[str]): namespace opzionale sostitutivo.

    Valori di ritorno

    • str: namespace risolto per l'uso.

    Esempi

    ns = client.get_namespace()  # retorna o main_namespace configurado
ns2 = client.get_namespace("namespace_alternativo")  # retorna "namespace_alternativo"

    #5. create_vector_store

    Descrizione

    Crea e restituisce un'istanza PineconeVectorStore configurata con l'indice, l'embedding e il namespace selezionati.

    Argomenti

    • namespace (Optional[str]): namespace per la store (opzionale).
    • embedding_model (Optional[OpenAIEmbeddings]): istanza del modello di embedding (opzionale).

    Valori di ritorno

    • PineconeVectorStore: oggetto per la manipolazione dell'archiviazione vettoriale.

    Esempi

    vector_store = client.create_vector_store()
# Usa main_namespace e modelo configurado

vector_store_custom = client.create_vector_store(namespace="ns_custom")
# Cria store com namespace customizado

    #Uso

    if __name__ == "__main__":
    client = PineconeClient()
    vector_store = client.create_vector_store()
    print("Pinecone Client initialized and VectorStore created successfully.")
