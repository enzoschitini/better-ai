Unique ID Factory

Questa è una documentazione dettagliata e didattica della classe IDGenerator, progettata per offrire una visione chiara delle sue capacità e del suo funzionamento interno.

In questa pagina

    #Panoramica

    La classe IDGenerator è uno strumento di utilità robusto sviluppato in Python per la creazione di identificatori univoci. Nei sistemi software, la scelta dell'ID giusto è cruciale: alcuni devono essere ordinabili nel tempo (come i log), altri devono essere impossibili da indovinare (come i token di recupero della password) e altri ancora devono seguire formati di business specifici (come i protocolli di assistenza).

    Questa classe centralizza queste esigenze in un'interfaccia semplice, utilizzando librerie standard di Python focalizzate sulla sicurezza (secrets) e sull'unicità (uuid).

    #Flusso di Esecuzione

    Il flusso di funzionamento della classe si basa sul pattern Static Utility. Poiché tutti i metodi sono decorati con @classmethod, non serve istanziare la classe (fare gen = IDGenerator()) per usarla.

    1. Chiamata del Metodo: L'utente richiede un tipo di ID (es: IDGenerator.token()).
    2. Validazione dell'Input: Il metodo verifica che i parametri (come lunghezza o versione) siano validi.
    3. Elaborazione/Generazione:
      • Per gli UUID, consulta il modulo uuid.
      • Per i Timestamp, cattura il tempo in nanosecondi (time.time_ns()).
      • Per Custom/Token, usa secrets per selezionare caratteri casuali in modo crittograficamente sicuro.
    4. Ritorno: L'identificatore viene formattato come string e restituito al chiamante.

    #Tabella dei Metodi

    MetodoFinalità PrincipaleCaratteristica Chiave
    uuid(version)Identificazione universale univoca.Standard RFC 4122 (128 bit).
    timestamp(...)ID che seguono un ordine cronologico.Basato su nanosecondi + suffisso casuale.
    token(len, safe)Sicurezza e autenticazione.Crittograficamente forte e sicuro per gli URL.
    custom(pattern)Identificatori con regole di business.Usa maschere per definire numeri e lettere.

    #Architettura e Spunti

    • Sicurezza Crittografica: L'uso di secrets al posto di random garantisce che gli ID generati per i token non possano essere previsti con attacchi a forza bruta o analisi statistica.
    • Alta Granularità: Usando time.time_ns() nel metodo timestamp, la probabilità di collisione (due ID uguali generati nello stesso momento) si riduce drasticamente, perché la precisione è di miliardesimi di secondo.
    • Flessibilità tramite Maschere: Il metodo custom funziona come un "Mini-Template Engine", permettendo agli sviluppatori di creare formati come NF-2024-#### senza dover riscrivere la logica di generazione casuale.

    #Dettaglio Tecnico

    #Classe IDGenerator

    Descrizione

    Una classe di utilità di metodi di classe orientata alla generazione di stringhe di identificazione. Non richiede stato interno e si concentra sulla purezza delle funzioni di generazione.

    Argomenti

    La classe in sé non riceve argomenti di inizializzazione (è una classe statica).

    Metodi

    #1. uuid

    Descrizione: Genera un Identificatore Univoco Universale (UUID). È la scelta migliore per le chiavi primarie di database distribuiti.

    Argomenti:

    • version (int): La versione dell'UUID. Supporta 1 (tempo + MAC address) o 4 (totalmente casuale). Predefinito: 4.

    Valori di ritorno:

    • str: L'UUID formattato (es: 8f3...).

    Raises:

    • ValueError: Se la versione indicata è diversa da 1 o 4.

    Esempi:

    IDGenerator.uuid(version=4) # '784a0d9b-2b41-4c12-8877-6f8d92305381'

    #2. timestamp

    Descrizione: Crea un ID basato sul momento esatto dell'esecuzione. Eccellente per i log e per i sistemi in cui l'ordine di creazione conta.

    Argomenti:

    • prefix (str): Testo iniziale.
    • separator (str): Carattere di collegamento.
    • as_hex (bool): Se True, converte il tempo in base esadecimale (più corto).
    • suffix_len (int): Quantità di caratteri casuali extra alla fine per evitare collisioni.

    Valori di ritorno:

    • str: Stringa temporale formattata.

    Raises:

    • ValueError: Se suffix_len è negativo.

    Esempi:

    IDGenerator.timestamp(prefix="PEDIDO", separator="-", as_hex=True)
# 'PEDIDO-18f74d0a2bc5f1a39aB3'

    #3. token

    Descrizione: Genera una sequenza casuale sicura. Consigliato per password temporanee, chiavi API e token di sessione.

    Argomenti:

    • length (int): Lunghezza della stringa.
    • url_safe (bool): Se True, rimuove i caratteri che possono causare errori negli URL (come + o /).

    Valori di ritorno:

    • str: Token casuale.

    Raises:

    • ValueError: Se length è minore o uguale a zero.

    Esempi:

    IDGenerator.token(length=12, url_safe=True) # 'kL9_zP2mNx8A'

    #4. custom

    Descrizione: Genera un ID seguendo un modello visivo (maschera) definito dall'utente.

    Argomenti:

    • pattern (str): Stringa contenente i marcatori # (numero), ? (lettera) o (entrambi).

    Valori di ritorno:

    • str: Stringa formattata secondo il pattern.

    Raises:

    • ValueError: Se il pattern è vuoto.

    Esempi:

    IDGenerator.custom("PLA-####-??") # 'PLA-5521-XW'
