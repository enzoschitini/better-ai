Embedding Module

The TestPineconeVectorStore class offers a set of methods to interact conveniently with a vector database managed by the Pinecone platform.

On this page

    #Overview

    The TestPineconeVectorStore class offers a set of methods to interact conveniently with a vector database managed by the Pinecone platform. It encapsulates common operations such as client initialization, generating vector embeddings from texts, similarity search and deleting vectors based on metadata filters.

    This set of features solves the problem of complexity in handling Pinecone directly, providing a simple interface ready for typical operations in use cases such as semantic search over documents, organizing vector data and maintaining vector indexes.

    In practice, this class can be used to index documents, run smart text searches and keep the vector database up to date without having to directly manipulate the lower-level resources of the Pinecone API.

    #Execution Flow

    1. Client Initialization
      Call get_client() to create and configure a Pinecone client with the defined (or default) index and namespaces. This client is stored internally for use in the next operations.
    2. Generate and Save Embeddings
      Using the embedding() method, insert texts (or read an example file) that will be processed to generate embedding vectors. These vectors are sent for storage in Pinecone along with associated metadata to ease future searches.
    3. Similarity Search
      Run retriever() to search Pinecone based on a text query and filters applied to the stored metadata. The method returns the most relevant vectors according to the computed similarity.
    4. Vector Removal
      Finally, with the delete() method you can erase specific vectors filtered by a metadata field (such as source or file_id), ensuring index maintenance and cleanup as needed.

    #Class Methods Table

    MethodDescription
    __init__Initializes the class with settings for Pinecone and embeddings.
    get_clientInitializes and returns the configured Pinecone client.
    retrieverRuns a similarity search on the Pinecone index with filters.
    embeddingGenerates and saves embeddings in Pinecone from a given text.
    deleteDeletes vectors in Pinecone based on metadata filters.

    #Key Architecture Points and Insights

    • The class uses composition by instantiating objects of other specialized classes (PineconeClient, PineconeRetriever and PineconeEmbedding), clearly separating responsibilities.
    • Using distinct namespaces (main_namespace and global_namespace) allows organizing vectors into different "scopes" within the same index, easing management.
    • Handling metadata in embeddings and filters makes refined searches and deletions possible, increasing the precision and control of the data.
    • Methods implement print with a well-formatted JSON return to ease debugging and checking of results, very useful in tests.
    • There is support for parameter fallback using default values, which reduces the need for initial configuration.

    #Class and Methods Description

    #Class TestPineconeVectorStore

    Description

    Class to ease integration and testing with the Pinecone vector store, providing methods to connect to the service, index text vectors, run similarity searches and delete vectors based on metadata.

    Constructor Arguments

    ArgumentTypeDescriptionDefault Value
    index_namestrName of the Pinecone index to connect to."backai-vectorstore"
    main_namespacestrMain namespace for storing vectors."main_namespace"
    global_namespacestrGlobal namespace for storing vectors."global_namespace"
    embedding_model_namestrName of the model for generating embeddings."text-embedding-3-large"
    dimensionsintDimensionality of the embedding vectors.3072

    #1. __init__

    Description

    Initializes the class instance by defining the index name, namespaces, embedding model and vector dimensions, with default values if not provided.

    Arguments

    • index_name (str): Pinecone index name.
    • main_namespace (str): main namespace.
    • global_namespace (str): global namespace.
    • embedding_model_name (str): model for embeddings.
    • dimensions (int): size of the vectors.

    Returns

    Does not return a value.

    Raises

    None.

    Examples

    # Criar objeto com configurações padrão
tester = TestPineconeVectorStore()

# Criar objeto com parâmetros customizados
tester_custom = TestPineconeVectorStore(
    index_name="meu_indice",
    main_namespace="principal",
    embedding_model_name="modelo-custom",
    dimensions=1536
)

    #2. get_client

    Description

    Initializes and returns a Pinecone client configured with the internal indexes and namespaces. It keeps the client internally for reuse.

    Arguments

    None.

    Returns

    • PineconeClient: client object configured for interactions with Pinecone.

    Raises

    None.

    Examples

    cliente = tester.get_client()
# cliente pode ser usado para operações avançadas se necessário

    #3. retriever

    Description

    Runs a similarity search on the Pinecone index to retrieve the most relevant vectors/documents based on the query text and metadata filters.

    Arguments

    • query (str): text for the similarity search.
    • filter_search (dict): metadata filters to refine the search.
    • k (int): maximum number of results to return.

    Returns

    • list: list with the most similar results found.

    Raises

    None.

    Examples

    resultados = tester.retriever(
    query="Quais arquivos existem na base?",
    filter_search={"source": ["example_text.txt"]},
    k=3
)
for r in resultados:
    print(r["metadata"], r["score"])

    #4. embedding

    Description

    Generates embedding vectors for a given text (or an example file if none is given) and saves those vectors with metadata in Pinecone.

    Arguments

    • embedding_content (str): text to be embedded.
    • embedding_metadata (dict): metadata associated with those vectors.

    Returns

    • dict: Pinecone response confirming the status of saving the vectors.

    Raises

    None.

    Examples

    response = tester.embedding(
    embedding_content="Este é um exemplo de texto para embedding.",
    embedding_metadata={"file_id": "file_001", "user_id": "user_01", "source": "input.txt"}
)
print(response["status"])

    #5. delete

    Description

    Removes vectors from Pinecone by filtering on a specific metadata field and its value, within a namespace.

    Arguments

    • target_feature (str): metadata field for the deletion filter.
    • target_id (str): value of the field used to select the vectors.
    • namespace (str): namespace for the deletion action, uses the main one if empty.
    • features (list): list of metadata fields considered in the deletion.

    Returns

    • dict: Pinecone response indicating the result of the operation.

    Raises

    None.

    Examples

    delete_response = tester.delete(
    target_feature="source",
    target_id="example_text.txt",
    namespace="main_namespace",
    features=["file_id", "source"]
)
print(delete_response)
