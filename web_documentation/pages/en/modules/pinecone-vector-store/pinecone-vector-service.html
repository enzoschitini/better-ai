Pinecone Vector Service

On this page

    #Overview

    The PineconeVectorService class is a service responsible for turning texts into high-dimensional vectors for efficient storage and search in vector databases, specifically using Pinecone's infrastructure. It solves the problem of handling, storing and searching large volumes of text processed as embeddings, enabling advanced natural language processing applications such as semantic search, recommendation and similarity analysis.

    In practice, the class splits the text into smaller parts (chunks), generates embeddings for those parts using pre-trained models (for example, from OpenAI), and saves those vectors in organized namespaces for later searches or removals. It supports robust operations such as batch processing, rollback in case of failures and filters for conditional removal of documents. It is therefore ideal for developers who need to structure scalable and reliable vector databases with advanced contextual search features.

    #Execution Flow

    1. Service Initialization: When creating an instance of the class, a connection with the Pinecone client is configured (or a default one is created), along with the embeddings model and chunking settings.
    2. Text Splitting: With the split_text method, a text is fragmented into smaller pieces using configurable size and overlap, so that each chunk makes sense for processing.
    3. Document Creation: The chunks are converted into Document objects enriched with metadata, ready for vector generation.
    4. Vector Generation and Storage: Using generate_vectors, the chunks are turned into embeddings, which are written to the main namespace, optionally replicated to the global namespace, with batch control and the possibility of rollback if any operation fails.
    5. Query for Similar Vectors: Through document_search, searches are made for vectors similar to a text query, returning relevant documents from the chosen namespace.
    6. Conditional Removal: The delete_documents method allows removing specific vectors filtered by metadata, ensuring fine control over the stored data.

    #Class Methods Table

    MethodDescription
    __init__Initializes the instance, setting up client, model and parameters.
    split_textSplits text into smaller chunks with configurable size and overlap.
    build_documentsStatic, creates a list of Document objects from the chunks and metadata.

    #Important Architecture Points and Insights

    • Integration with PineconeClient and LangChain: The class uses PineconeClient to abstract all communication with the vector service, and LangChain's OpenAIEmbeddings to generate the vectors, reinforcing modularity and reuse.
    • Use of Decorators for Tracing: Applying a trace decorator to key methods makes it possible to instrument the code for structured logs, making monitoring and debugging in production easier.
    • Customizable and Optimized Chunking: Uses dynamic configuration for chunk size and overlap, as well as custom separators, ensuring that the text is fragmented into semantically coherent pieces for efficient embeddings.
    • Robustness with Batch Processing and Rollback: In the generate_vectors method, documents are added in controlled batches, and a rollback is executed when errors are detected, removing partially added documents to maintain consistency.
    • Distinct Namespaces: The separation between main and global namespace allows organizing different levels of vector data, isolating usage contexts and making permission or sharing management easier.

    #Class and Methods Description

    #PineconeVectorService Class

    #Description

    Class that provides integrated services for processing texts into vector data using Pinecone, including text splitting, embedding generation with a configurable model, storage in multiple namespaces and features for searching and removing documents by metadata. It makes working with vector databases in NLP projects easier by aggregating common operations into a single, extensible interface.

    #Constructor Arguments

    ArgumentTypeDescriptionDefault Value
    vector_clientOptional[PineconeClient]Custom client for communication with Pinecone.None
    embedding_model_namestrName of the embedding model for generating the vectors.None
    dimensionsintNumber of dimensions of the vectors in the embedding space.None

    #Methods

    #1. __init__

    #Description

    Initializes the service, setting up the Pinecone client, chunking parameters, embeddings model and creating the corresponding vectors for the main and global namespaces.

    #Arguments

    • vector_client (Optional[PineconeClient]): Optional Pinecone client to customize the connection.
    • embedding_model_name (str): Name of the model to be used for embeddings.
    • dimensions (int): Dimensionality of the final vectors.

    #Returns

    • Does not return a value.

    #Raises

    • May raise exceptions if the client initialization or vector store creation fails.

    #Examples

    service = PineconeVectorService(
    embedding_model_name="text-embedding-ada-002",
    dimensions=1536
)

    #2. split_text

    #Description

    Splits a long text into a list of smaller chunks, respecting the defined maximum size and overlap, using custom separators to maintain semantic coherence.

    #Arguments

    • text (str): Full text to be fragmented.
    • chunk_size (int | None): Maximum size of each chunk, uses the default configuration if None.
    • chunk_overlap (int | None): Amount of overlap between consecutive chunks, uses the default configuration if None.

    #Returns

    • List[str]: List with the pieces of the fragmented text.

    #Raises

    • None in particular.

    #Examples

    chunks = service.split_text(
    "Um texto muito longo que precisa ser dividido em partes menores.",
    chunk_size=500,
    chunk_overlap=50
)
print(len(chunks))

    #3. build_documents

    #Description

    Static method that receives chunks and metadata, building a list of Document objects for use in embedding generation.

    #Arguments

    • chunks (List[str]): List of fragmented texts.
    • metadata (Dict[str, Any]): Metadata to be associated with each document.

    #Returns

    • List[Document]: List of Document objects ready for processing.

    #Raises

    • None.

    #Examples

    docs = PineconeVectorService.build_documents(chunks, {"file_id": "1234"})
print(docs[0].metadata["file_id"])  # Saída: "1234"

    #4. delete_documents

    #Description

    Deletes documents stored in the vector within the specified namespace, filtering them by a metadata field (key and value), removing their associated vectors in batches.

    #Arguments

    • target_feature (str): Name of the metadata field to be filtered.
    • target_id (str): Value of the field to identify the documents to remove.
    • namespace (str): Namespace where the removal operation will take place.

    #Returns

    • dict: Information with the number of vectors deleted and the namespace used.

    #Raises

    • May raise exceptions if an error occurs in the query or deletion of the vectors.

    #Examples

    result = service.delete_documents(
    target_feature="file_id",
    target_id="1234",
    namespace="main"
)
print(result["deleted_vectors"])

    #5. document_search

    #Description

    Performs vector similarity search based on a text query, returning the most relevant documents from the indicated namespace, with the option of applying additional filters.

    #Arguments

    • query (str): Query text for semantic search.
    • k (int): Limit of results to return. Default = 3.
    • namespace (str): Namespace for the search. If None, uses the main one.
    • filter (dict): Optional filters to restrict the results.

    #Returns

    • dict: Structure with the document IDs and their metadata and contents.

    #Raises

    • May raise RuntimeError in case of search failure.

    #Examples

    results = service.document_search(
    query="Como funciona vector search?",
    k=5
)
print(list(results.keys()))

    #6. generate_vectors

    #Description

    Converts a full text into embeddings, splitting it into chunks, adding metadata and saving the vectors in Pinecone in batches. Supports saving to the global namespace and automatic rollback if any operation fails.

    #Arguments

    • text (str): Text for embedding generation.
    • metadata (dict): Metadata associated with the vectors created.
    • save_global (bool): Indicates whether to also save to the global namespace. Default False.
    • batch_size (int | None): Maximum number of documents per batch. Uses the default configuration if None.

    #Returns

    • dict: State of the operation with status, message, batch count and IDs of the chunks saved.

    #Raises

    • Does not propagate exceptions directly, captures them and returns the error in the response dictionary.

    #Examples

    response = service.generate_vectors(
    text="Conteúdo do documento a ser vetorizado.",
    metadata={"file_id": "file123"},
    save_global=True
)
print(response["status"])  # "success"
