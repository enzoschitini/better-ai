Web Service Network - API

Use

The BetterAI Web Service Network is a high-performance modular API designed to orchestrate artificial intelligence services in production.

On this page

    The BetterAI Web Service Network is a high-performance modular API designed to orchestrate artificial intelligence services in production. It exposes a set of specialized routers — deep web research, document parsing, image generation and vector store management — all accessible via HTTP with API key authentication.

    The API is built on FastAPI and served with Uvicorn, offering automatic interactive documentation via Swagger UI (/docs) and native support for asynchronous requests. Each endpoint returns standardized responses with job_id, status, payload (result or content) and execution time metrics, making traceability and integration with data pipelines easier.

    Base URL: http://localhost:8000
    Authentication: X-API-Key in the header of all protected routes
    Current version: 1.0.0
