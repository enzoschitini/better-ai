Image Generation / Cost Calculator

Cost Calculator

Calcula em dólares o custo de uma geração a partir dos tokens usados, do número de imagens e da tabela de preços do modelo.

Nesta página

    Fonte: src/image_generation/cost_calculator/cost_calculator.py. O notebook original desta página estava vazio; o conteúdo foi escrito a partir do código.

    #Visão geral

    A classe CostCalculator recebe uma tabela de preços no construtor (por padrão, PricingTable; veja Pricing Table) e oferece dois métodos: merge_cost_information e calculate.

    #merge_cost_information

    Soma prompt_tokens, output_tokens e total_tokens de uma lista de registros de uso, usada quando uma geração faz várias chamadas ao modelo.

    Mínimo de dois registros. Com uma lista vazia ou com menos de dois itens, o método levanta ValueError ("You must provide at least two cost_information objects."). PayloadBuilder só o chama quando há mais de um registro.

    #calculate

    ParâmetroTipoDescrição
    modelstrModelo usado, procurado em PricingTable.
    prompt_tokensintTokens de entrada.
    output_tokensintTokens de saída.
    total_tokensintTotal de tokens. Só é repassado ao resultado; não entra na conta.
    num_imagesintQuantidade de imagens (padrão 0).
    cached_prompt_tokensintTokens de entrada lidos do cache (padrão 0).
    cache_storage_tokensintTokens mantidos em cache (padrão 0).
    cache_storage_hoursfloatHoras de armazenamento em cache (padrão 0.0).

    #Fórmulas

    ParcelaCálculo
    Entradaprompt_tokens / 1_000_000 * input_per_million_tokens
    Saídaoutput_tokens / 1_000_000 * output_per_million_tokens, só se o preço e os tokens forem diferentes de zero
    Imagensnum_images * image_price_per_unit, só se o preço e a quantidade forem diferentes de zero
    Cache de entradacached_prompt_tokens / 1_000_000 * cache_input_per_million_tokens
    Armazenamento de cachecache_storage_tokens / 1_000_000 * cache_storage_per_million_tokens_per_hour * cache_storage_hours

    O total é a soma das cinco parcelas.

    #Retorno

    Um dicionário com os tokens recebidos e os valores em dólares arredondados a 6 casas decimais:

    {
  "prompt_tokens": 1174,
  "output_tokens": 2633,
  "total_tokens": 3807,
  "prompt_usd": 0.000352,
  "output_usd": 0.0,
  "images_usd": 0.078,
  "total_usd": 0.078352
}

    #Exemplo de uso

    from src.image_generation.cost_calculator.cost_calculator import CostCalculator

calculator = CostCalculator()

# Calcula o custo de duas imagens geradas com gemini-2.5-flash-image
cost = calculator.calculate(
    model="gemini-2.5-flash-image",
    prompt_tokens=1174,
    output_tokens=2633,
    total_tokens=3807,
    num_images=2,
)
print(cost["total_usd"])

    #Observações

    Modelo sem preço. Se o modelo não estiver em PricingTable, PricingTable.get levanta ValueError ("Modelo sem precificação cadastrada") e a geração falha ao montar os payloads.
