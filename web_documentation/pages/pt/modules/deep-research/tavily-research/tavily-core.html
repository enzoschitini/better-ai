Deep Research / Tavily Research

Tavily Core

Documentação da classe TavilyDeepResearch, o wrapper dinâmico sobre a API da Tavily usado pelo módulo Deep Research.

Nesta página

    #Visão Geral

    A classe TavilyDeepResearch é um wrapper dinâmico sobre o TavilyClient da biblioteca tavily. Em vez de definir uma assinatura própria para cada operação, cada método recebe um único dicionário de configuração (params) e o repassa, como argumentos nomeados, ao método correspondente do cliente Tavily.

    Na prática, isso dá máxima flexibilidade: qualquer parâmetro aceito pela Tavily pode ser enviado sem alterar a classe. Ela é a camada de acesso à Tavily usada pelo Context Builder, que transforma uma busca na web em contexto pronto para modelos de linguagem.

    #Fluxo de Execução

    1. Instanciação: a classe recebe uma chave de API opcional. Se ela não for informada, é lida da variável de ambiente TAVILY_API_KEY.
    2. Validação da chave: se nenhuma chave for encontrada, uma RuntimeError é levantada.
    3. Criação do cliente: um TavilyClient é criado com a chave e guardado em self.client.
    4. Chamada de um método: o usuário chama um método (por exemplo, start_search) passando um dicionário com os parâmetros da operação.
    5. Repasse dos parâmetros: o dicionário é descompactado com **params e enviado ao método homônimo do cliente Tavily, cujo retorno é devolvido sem alterações.

    #Variáveis de Ambiente

    • TAVILY_API_KEY: chave de API da Tavily. Usada quando api_key não é passada ao construtor. O módulo chama load_dotenv() ao ser importado, então a variável também pode vir de um arquivo .env.

    #Pontos Importantes da Arquitetura e Insights

    • Wrapper fino e dinâmico: a classe não valida nem transforma os parâmetros; ela só os repassa. Os nomes e os valores aceitos são os da biblioteca tavily.
    • Retorno sem tratamento: os métodos devolvem exatamente o que o cliente Tavily devolve. Tratamento, filtragem e formatação ficam por conta de quem chama, como o Context Builder.
    • Erros: além da verificação da chave no construtor, a classe não captura exceções. Qualquer erro da Tavily propaga para quem chamou.
    • Tópico da pesquisa autônoma: em start_research, o tópico é enviado na chave input, que é o nome usado pelo método research da biblioteca original.

    #Descrição da Classe e Métodos

    #Classe TavilyDeepResearch

    #Descrição

    Wrapper dinâmico para a Tavily AI. Recebe dicionários de configuração para máxima flexibilidade.

    #Argumentos do Construtor

    ArgumentoTipoDescriçãoValor Padrão
    api_keystr | NoneChave de API da Tavily. Se omitida, usa TAVILY_API_KEY.None

    #Métodos

    #1. __init__

    #Descrição

    Resolve a chave de API (argumento ou variável de ambiente) e cria o TavilyClient.

    #Argumentos

    • api_key (str | None): chave de API da Tavily.

    #Retornos

    • Não retorna valor.

    #Raises

    • RuntimeError: se a chave não for informada e TAVILY_API_KEY não estiver definida.

    #Exemplos

    # Usando a chave definida em TAVILY_API_KEY
researcher = TavilyDeepResearch()

# Informando a chave diretamente
researcher = TavilyDeepResearch(api_key="tvly-...")

    #2. start_search

    #Descrição

    Busca geral. Espera chaves como query, search_depth, max_results, entre outras aceitas pela Tavily.

    #Argumentos

    • params (Dict[str, Any]): parâmetros da busca, repassados a client.search.

    #Retornos

    • dict: resposta da busca.

    #Exemplos

    result = researcher.start_search({
    "query": "Quais as principais tendências de IA em 2026?",
    "search_depth": "advanced",
    "max_results": 5,
})

    #3. get_context

    #Descrição

    Retorna contexto para LLMs. Espera query, max_tokens, entre outros.

    #Argumentos

    • params (Dict[str, Any]): parâmetros repassados a client.get_search_context.

    #Retornos

    • str: contexto para uso em modelos de linguagem.

    #Exemplos

    context = researcher.get_context({"query": "tendências de IA em 2026", "max_tokens": 1500})

    #4. qna

    #Descrição

    Pergunta e resposta direta. Geralmente requer apenas {'query': 'sua pergunta'}.

    #Argumentos

    • params (Dict[str, Any]): parâmetros repassados a client.qna_search.

    #Retornos

    • str: resposta à pergunta.

    #Exemplos

    answer = researcher.qna({"query": "Quem criou a linguagem Python?"})

    #5. extract_content

    #Descrição

    Extração de conteúdo. Espera urls (lista ou string) e format.

    #Argumentos

    • params (Dict[str, Any]): parâmetros repassados a client.extract.

    #Retornos

    • dict: conteúdo extraído.

    #Exemplos

    content = researcher.extract_content({"urls": ["https://example.com"], "format": "markdown"})

    #6. map_site

    #Descrição

    Mapeia a estrutura de URLs de um site. Espera url e, opcionalmente, limit.

    #Argumentos

    • params (Dict[str, Any]): parâmetros repassados a client.map.

    #Retornos

    • dict: mapa de URLs do site.

    #Exemplos

    site_map = researcher.map_site({"url": "https://example.com", "limit": 50})

    #7. crawl_site

    #Descrição

    Explora um site recursivamente. Espera url, limit e max_depth.

    #Argumentos

    • params (Dict[str, Any]): parâmetros repassados a client.crawl.

    #Retornos

    • dict: resultado da exploração.

    #Exemplos

    crawl = researcher.crawl_site({"url": "https://example.com", "limit": 20, "max_depth": 2})

    #8. get_company

    #Descrição

    Dados firmográficos de uma empresa. Espera query.

    #Argumentos

    • params (Dict[str, Any]): parâmetros repassados a client.get_company_info.

    #Retornos

    • List[dict]: dados da empresa.

    #Exemplos

    company = researcher.get_company({"query": "Tavily"})

    #9. start_research

    #Descrição

    Inicia o agente autônomo de pesquisa. Espera input (o tópico) e model.

    #Argumentos

    • params (Dict[str, Any]): parâmetros repassados a client.research. A biblioteca original usa input para o tópico.

    #Retornos

    • dict: resposta da solicitação de pesquisa.

    #Exemplos

    research = researcher.start_research({"input": "Mercado de energia solar no Brasil", "model": "gpt-4o-mini"})

    #10. get_research_status

    #Descrição

    Consulta o status de uma pesquisa iniciada com start_research. Espera request_id.

    #Argumentos

    • params (Dict[str, Any]): parâmetros repassados a client.get_research.

    #Retornos

    • dict: status da pesquisa.

    #Exemplos

    status = researcher.get_research_status({"request_id": "..."})
