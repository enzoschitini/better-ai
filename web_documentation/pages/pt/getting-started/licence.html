Licence

Página de exemplo para Licence, usada para validar o layout.

Nesta página

    Conteúdo de exemplo. Este texto existe só para validar o layout. Na versão final, a página é gerada a partir de ipynb_contents/Getting Started/3. Licence.ipynb.

    #Visão geral

    Licence faz parte da plataforma BetterAI. Este parágrafo ocupa o lugar do texto que vem da fonte, para que o espaçamento, a medida de linha e o índice lateral possam ser conferidos.

    #Uso

    O bloco abaixo mostra a chamada típica, com realce de sintaxe:

    from better_ai import Licence

client = Licence()
result = client.run(model_id="claude-sonnet-5-5")
print(result)

    #Parâmetros

    A tabela abaixo existe para validar o scroll horizontal em telas estreitas:

    NomeTipoDescrição
    model_idstrIdentificador do modelo a usar.
    timeoutintLimite em segundos para a resposta.
    streamboolDevolve a resposta em pedaços.
