# BetterAi Back-end

O BetterAi Back-end é a base de inteligência e processamento do ecossistema BetterAi, responsável por integrar modelos de linguagem, fluxos de agentes e processamento multimodal (texto, imagem, áudio e PDF).

Este serviço foi projetado para oferecer uma arquitetura modular, escalável e segura, garantindo alta performance na execução de tarefas de IA.
